# כלי קישורים למאגר הספרים של אוצריא

ארבעה קבצי Python שעובדים בלי AI ובלי התקנת חבילות (Python 3.9 ומעלה, ספריות סטנדרטיות בלבד). הם בודקים ומעדכנים את קבצי הקישורים (`links.csv`) של המאגר.

## קבצים להפצה

| קובץ | תפקיד |
|---|---|
| `config.py` | הגדרת נתיבים (תיקיית הספרים, `seforim.db`, תיקיית דוחות). אין צורך לערוך אותו |
| `audit_links.py` | הלוגיקה של כללי היצירה, וגם סיכום לפי ספר (`audit_links_details.csv`) |
| `fix_links.py` | מעדכן קישורים קיימים לפי הקבצים הנוכחיים, ומוסיף קישורים לספרים חדשים |
| `links_new_books.py` | יוצר קישורים לספר שהכלל הכללי לא מכסה, לפי אזכורי דף מפורשים בטקסט |

הקבצים האחרים בתיקייה (`links2.py`, `gen_dorot.py` ועוד) הם הסקריפטים המקוריים שנוצרו בשיחות קודמות. יש בהם נתיבים קבועים, והם לא מיועדים להפצה.

## מה צריך
- תיקיית הספרים של המאגר (זו שמכילה את `קבצי קישורים וסדר הדורות`).
- הקובץ `seforim.db` של אוצריא, לקריאה בלבד. הכלי מחפש אותו בנתיבי ברירת המחדל (`%APPDATA%\io.github.kdroidfilter.seforimapp\databases`), ואפשר לציין אותו ב-`--seforim`.
- אם בתיקייה יש קבצי git-lfs, להריץ קודם `git lfs checkout`. קובץ שהוא מצביע מדולג ומסומן כ"לא נבדק".

## שימוש

```
python -X utf8 fix_links.py --base "D:\books\ספרים"            # ניסוי יבש + דוח ב-output\
python -X utf8 fix_links.py --base "D:\books\ספרים" --apply    # כתיבה (לגבות את התיקייה קודם!)
python -X utf8 fix_links.py --base "D:\books\ספרים" --verify   # בדיקה אחרי כתיבה
python -X utf8 audit_links.py --base "D:\books\ספרים"          # סיכום לפי ספר
```

אפשר להשתמש במשתנים `LINKS_BOOKS_DIR`, `SEFORIM_DB` ו-`LINKS_OUT_DIR` במקום הדגלים `--base`, `--seforim` ו-`--out`.

## מה הכלי עושה
1. משחזר מכל קובץ ספר את הקישורים שהיו נוצרים לו היום, לפי כללי היצירה (`expected_for` ב-`audit_links.py`): כותרות דף (`ב.`, `יד, ב`, `דף ב ע"א`) בתלמוד הבבלי, פרקים בתנ"ך, פרק והלכה בירושלמי ובפסקי הרא"ש (הגהות אשרי), וסימנים בשולחן ערוך.
2. מתאים כל קבוצת קישורים קיימת (ספר מקור ומזהה קטגוריה) לקובץ הנכון לפי חפיפת מספרי שורות. כך מטפלים גם בספרים עם אותו שם בכמה תיקיות.
3. מחליף את השורות הישנות בחדשות, בלי לשנות את סדר הקבצים והקבוצות. הפורמט נשמר (UTF-8 עם BOM, CRLF).
4. ספר חדש שיש לו קישורים צפויים וגם אין לו קבוצה, מקבל קישורים ב-`קישורים/13/links.csv`.

## הוספת כלל יצירה חדש
כלל מוסיפים בקוד. ב-`audit_links.py`:
- פונקציה `expected_for` מחזירה לכל ספר `{מספר שורה: (ספר יעד, מיקום)}`. כלל חדש הוא בלוק `if` שמזהה את הספר לפי נתיב או שם, וממפה כותרות למיקום בספר היעד.
- היעד חייב להיות קיים ב-`seforim.db`, והמיקום חייב להיות כותרת קיימת בו. השתמשו ב-`hset` (פרק + הלכה), `chset` (פרק) או `dafset` (דף).
- ספרים שאינם עונים על אף כלל נשארים בלי קישורים.

## מה לא נתמך
- ספרים שאין בהם מיקום מפורש (שיעורים לפי נושא, שו"ת, ספרי מחשבה) לא מקושרים. אי אפשר לקשר בלי מיפוי אמיתי ליעד.
- כותרות ברמות שונות באותו ספר, או כותרות בפורמט שלא מוכר, ידלגו על הקישורים של אותו חלק.

## ייבוא לאוצריא
הכלי רק יוצר ומעדכן קבצי CSV. הייבוא לספרייה האישית של אוצריא נעשה מאוצריא עצמה (ייבוא קישורים), תיקייה אחת בכל פעם.
