<h1>תנחומא-ילמדנו, נוסח ארוך, קטעים, פרשת חיי שרה</h1>

<h2>חיי שרה</h2>
<small>[עמ' סט]</small> … כעס בנים. מעלי. הה'ד "ועלי זקן מאד ישמע …ן בניו". מפני המלחמות. מיהושע. שלאחר … עם ל' וא' מלך מה כתי' בו. "ויהושע זקן בא …". … אשה רעה. משלמה. הה'ד "ויהי לעת זקנת … הטו את לבבו".
אבל אברהם א…ו מכבדתו. הה'ד "ואדוני זקן". לפיכך ….
<small>[עמ' ע]</small> … "ואברהם זקן". זהש'ה "ברכי נפשי … את … קדשו". אמ'ר תנחומא. מה … "… נפשי". אלא הנפש הזו דומה לבוראה. היא … הוא. הנפש (ש)היא רואה ואינה נראית. … הוא רואה ואינו נראה. מה הנפש הזו משמרת את … אף הקב'ה משמר לעולמו.
הנפש הזו מלא כל הגוף … כל הארץ כבודו. תבא נפש שממלאה את הגוף … שמלא כל הארץ כבודו.
הנפש הזו זנה את כל הגוף והקב'ה זן את כל העו' כולו. תבא נפש שזנה כל הגוף ותקלס להקב'ה שזן את העולם כולו.
הנפש הזו טהורה והקב'ה טהור. תב' נפ' שהי' טהו' ותק' להק' ש' טהור.
לפי' הנפש הזו היא מברכת לבוראה. הה'ד "ברכי נפשי את …".
מלך בשר ודם עושה צורה גדולה ממנו. אבל הקב'ה אין בעליונים ולא בתחתונים … מכולן. … "… אלהי גדלת מאד". ואומ' "…ם … לא יכלכלוך".
אין שלשה עולמות … כלום. … בחצי השם נבראו. הה'ד "… עולמים".
מלך בשר ודם בונה בית ואחר …. והקב'ה משמתח את כסאו אחר כך …בנה עליה <small>[עמ' עא]</small> העמיד אותן על מה. על האויר. ואחר כך … התקין כנפים לישא בהן אמרתו. הה'ד "המקרה … עבים רכובו המהלך על כנפי רוח". שא…חות.
והרוחות מצוחים … לעבים. "המהלך …". … הה'ד "יסד ארץ על מכוניה".
… מ…ת אחד והלבישו לאחד … יכול לעמוד תמיד ולשמשו … "על הרים יעמדו מים".
"מן גערתך …". …לו מים במים והארץ שקעה …. … הקב'ה. תיראה … בתחתונים. אמרו המים. הרי … מלא והוא צר לנו. להיכן נלך. מה עשה …. הה'ד "קול רעמך בגלגל" וג'.
… לאיזה מקום. הה'ד "…" … פירושו שלדבר. "יקוו המים מתחת … מקום אחד". ואינן יודעין אם לצפון אם … וח… שאמר להם הקב'ה. למקומו שללויתן … …לו אמרתי לכם לילך. הה'ד "שם אניות …". … שלא יצרתיו אלא כדי שתראה גדולתי בו. "לצחק בו".
"גבול …". … הים והשביען שלא … "גבול שמת בל יעבורון" וג'. …הם "מנחל בדרך ישתה …" … "… הרים יהליכון" ….
