<h1>תרגום יונתן על נחום</h1>
<h2>פרק א</h2>
<h3>פסוק א</h3>
מַטַל כָּס דִּלוָט לְאַשׁקָאָה יָת נִינְוֵה מִלְקַדמִין אִתנַבִּי עֲלַהּ יוֹנָה בַר אֲמִתַּי נְבִיָא דְמִגַּת חֵפֶר וְתַבַת מֵחוֹבַהָא וְכַדּוּ דְאוֹסֵיפַת לְמִחטֵי תָּב וְאִתנַבִּי עֲלַהּ נַחוּם דְּמִבֵּית קוֹשִׁי כְּמָא דִכתִיב בְּסִפרָא הָדֵין : אֱלָהּ :
<h3>פסוק ב</h3>
דַּיָין וּפֻרעָן יְיָ מִתפְּרַע יְיָ וְסַגִּי חֵילָא קֳדָמוֹהִי עֲתִיד יְיָ לְאִתפְּרָעָא מִסָנְאֵי עַמֵיהּ וּבִרגַז חַסִין מִבַּעֲלֵי דְבָבוֹהִי :
<h3>פסוק ג</h3>
יְיָ מַרחֵיק רְגַז וְסַגִּי חֵילָא קֳדָמוֹהִי וְסָלַח לִדתָּיְבִין לְאוֹרָיתֵיהּ וְלִדלָא תָיְבִין לָא מְזַכֵּי יְיָ בְּעַלעוּל וּברוּחַ מְדַבַּר וַעֲנַן אֲמִטְתָא כֵּיבַשׁ קֳדָמוֹהִי :
<h3>פסוק ד</h3>
נָזֵיף בְּיַמָא וּמיַבֵּישׁ לֵיהּ וְכָל נַהרָוָתָא מַחרֵיב צְדִי מַתנַן וְכַרמְלָא וְאִילָנֵי לִבנָן נְתַרוּ :
<h3>פסוק ה</h3>
טוּרַיָא זָעוּ מִן קֳדָמוֹהִי וְרָמָתָא אִתפָּרַקָא וַחֲרוֹבַת אַרעָא מִן קֳדָמוֹהִי וְתֵבֵל וְכָל דְּיָתְבִין בַּהּ :
<h3>פסוק ו</h3>
אִם כַּד אִתגְּלִי בְרַחמְתָא לְמִתַּן אוֹרָיתָא לְעַמֵיהּ כֵּין זָע עָלְמָא מִן קֳדָמוֹהִי בְּכֵין כַּד יִתגְּלֵי רֻגזֵיהּ לְאִתפְּרָעָא מִסָנְאֵי עַמֵיהּ קֳדָם פּוֹרעָנוּתֵיהּ מַן יְקוּם וּמַן יְסוֹבַר בְּאַבאָשׁוּת רֻגזֵיהּ חִמתֵּהּ כְּאִישָׁתָא מַמסֵי וְטִנָרַיָא אִתפָּרַקוּ מִן קֳדָמוֹהִי :
<h3>פסוק ז</h3>
טָב יְיָ לְיִשׂרָאֵל לְאִסתְּמָכָא עֲלוֹהִי בְּעִדָּן עָקָא וּגלֵי קֳדָמוֹהִי דִּרחִיצִין עַל מֵימְרֵיהּ :
<h3>פסוק ח</h3>
וּבִרגַז חַסִין וּבִחמָא תַקִיפָא גְּמֵירָא יַעֲבֵיד עִם עַמְמַיָא דְקָמוּ וְאַחרִיבוּ לִגמֵירָא יָת בֵּית מַקדְּשָׁא וּבַעֲלֵי דְבָבוֹהִי יִמסַר לְגֵיהִנָם :
<h3>פסוק ט</h3>
עַמְמַיָא דְבַזוּ יָת יִשׂרָאֵל מָא אַתּוּן חֲשִׁיבִין קֳדָם יְיָ גְּמֵירָא הוּא עֲתִיד לְמֶעֱבַד עִמְכוֹן לָא תִתקַיַים עֲלֵיכוֹן כְּבֵית יִשׂרָאֵל תַּרתֵּין זִמנִין רְוַח בָּתַר עָקָא :
<h3>פסוק י</h3>
אֲרֵי שִׁלטוֹנֵי עַמְמַיָא דְבַזוּ יָת יִשׂרָאֵל וּכמָא דְּטָעַן בְּחַמרָא אַטעִיאוּנוּן שֵׁיצִיאוּנוּן כְּמָא דִמשֵׁיצְיָא אִישָׁתָא בְּקַשָׁא יַבִּישָׁא סַגִּי :
<h3>פסוק יא</h3>
מִנִיך נִינְוֵה נְפַק מַלכָּא דְּחַשֵׁיב עַל עַמֵיהּ דַּייָ בִּישָׁא מָלֵיך מֵילַך בִּרשַׁע :
<h3>פסוק יב</h3>
כִּדנָן אֲמַר יְיָ אִם יְהוֹן שַׁלמִין בְּעֵיצָא וְסַגִּיאִין בְּאִתמְנָיוּתָא עַמְמַיָא דְמִתכַּנשִׁין לְאַעָקָא לִיך יְרוּשׁלֶם יְגוּזוּן עַל דִּגלָת וְיִעבְּרוּן עַל פְּרָת וְיֵיתוֹן לְעַנָיוּתִיך וּדשַׁעבֵּידתִּיך לָא אֲשַׁעבְּדִנִיך עוֹד :
<h3>פסוק יג</h3>
וּכעַן אֶתבַּר נִיר עַמְמַיָא מִצַורֵיכוֹן וַחֲנָקֵיכוֹן אֲפַסֵיק :
<h3>פסוק יד</h3>
וִיפַקֵיד עֲלָך יְיָ יָת מַלכָּא דְאַתּוּר וְלָא יְהֵי דֻכרַן מִשְׁמָך עוֹד מִבֵּית טָעוּתָך אֲשֵׁיצֵי צֵילַם וּמַתְּכָא תַּמָן אֲשַׁוֵי קִברָך אֲרֵי קַלִילָא דָא קֳדָמָי :
<h2>פרק ב</h2>
<h3>פסוק א</h3>
הָא עַל טוּרֵי אַרעָא דְיִשׂרָאֵל רַגלֵי מְבַסַר מַשׁמַע שְׁלָם חָגִּי יְהוּדָה חַגַּך שַׁלִימִי נִדרַך אֲרֵי לָא יוֹסְפוּן עוֹד דְּיִעדּוֹן בִּיך רַשִׁיעִין כֻּלְהוֹן אִשׁתֵּיצִיאוּ :
<h3>פסוק ב</h3>
דַּהֲווֹ סָלְקִין וּמִתבַּדְּרִין עַל אַרעִיך צָיְרִין עֲלַך בִּציָר מְקִימִין סָכוֹאִין עַל אוֹרחָתִיך תַּקִיפִי קְדָל וְחַסִינִי חֵיל לַחדָּא :
<h3>פסוק ג</h3>
אֲרֵי אֲתֵיב יְיָ תּוּקפֵּיהּ לְיַעֲקֹב רְבוּתֵיהּ לְיִשׂרָאֵל אֲרֵי בַזוּנוּן בָּזוֹזִין וְקִרוֵי תֻשׁבְּחָתְהוֹן חַבִּילוּ :
<h3>פסוק ד</h3>
תְּרִיסֵי גִיבָּרֵיהוֹן מְסַמְקִין גֻּברֵי עָבְדֵי קְרָבָא לְבִישִׁין זְהוֹרִיתָא בְּאִישָׁתָא פְיֵילֵי רְתִכֵּיהוֹן זְמִינִין לְיוֹם קִשׁוּטְהוֹן וְרַבָּנֵי מַשׁרְיָתְהוֹן מְסַרבְּלִין בְּצִבעָנִין :
<h3>פסוק ה</h3>
בְּשׁוּקַיָא מִשׁתַּגשְׁגִין רְתִכַּיָא קָל נִיקוּשׁ זֵינְהוֹן מִשׁתְּמַע בִּרחוֹבֵי קִריָא חֶזוֵיהוֹן כְּבָעוֹרִין כְּבַרקִין טָרְדִין :
<h3>פסוק ו</h3>
יְמַנוֹן רֵישֵׁי מַשׁרְיָתְהוֹן יִתַּקלוּן בִּמהָכְהוֹן יֵיחוֹן יִכבְּשׁוּן שׁוּרַיָא וְיִבנוֹן מִגדְּלַיָא :
<h3>פסוק ז</h3>
גִּשׁרֵי נַהרְוָתָא אִתפְּסַקוּ וּמַלכָּא בְהֵיכְלֵיהּ זָע :
<h3>פסוק ח</h3>
וּמַלכְּתָא יָתְבָא צִיבָא בִגלַיָא נְפַקַת וְאַמהָתַהָא מִידַּבְּרָן אָזְלָן בָּתְרַהָא מְנַהֲמָן כְּקָל יוֹנִין מְטָרְפָן עַל לִבֵּיהוֹן :
<h3>פסוק ט</h3>
וְנִינְוֵה כְבֵית כְּנֵישַׁת מַיָא מִיוֹמֵי קְדַם הִיא וְאִנוּן עָרְקִין וְאָמְרִין קוּמוּ קוּמוּ וְלֵית דְּמִתפְּנֵי לִמקָם :
<h3>פסוק י</h3>
בּוֹזוּ כַספָּא בּוֹזוּ דַהבָּא וְלֵית סוֹף לְאוֹצְרַיָא סָפוּ כָּל מָנֵי חֶמדְּתָא :
<h3>פסוק יא</h3>
בְּזִיזָא וּבזִיזָא וּמִתבָּזְזָא וּפתִיַח תַּרעַהּ לְסָנְאָה וְלֵב מָסֵי וְנִיקוּשׁ רְכוּבִּין וּזיָע חַרצִין וְאַפֵּי כֻלְהוֹן אִתחֲפִיאוּ אִכְּרוּם אוּכָּמִין כְּקִדרָא :
<h3>פסוק יב</h3>
אָן מְדוֹרֵי מַלכַיָא וּבֵית מִשׁרֵי שִׁלטוֹנַיָא אֲתַר דַּהֲווֹ אָזְלִין מַלכַיָא תַמָן בְּנֵיהוֹן שָׁבְקִין הָא כְאַריָא דְּשָׁרֵי עַל צֵידֵיהּ לְרֻחצָן וְלֵית דְּמַנִיד :
<h3>פסוק יג</h3>
מַלכַיָא מֵיתַן חֲטוֹף לִנשֵׁיהוֹן וּבִיזָא לִבנֵיהוֹן וּמָלַן אוֹצְרֵיהוֹן חֲטוֹף וּבִירָניָתְהוֹן בִּיזָא :
<h3>פסוק יד</h3>
הָאֲנָא שָׁלַח רֻגזִי עֲלַך אֲמַר יְיָ צְבָאוֹת וְאַדלֵיק בְּאִישָׁתָא רְתִיכַּך וְשִׁלטוֹנַך תְּקַטֵיל חַרבָּא וְשֵׁיצִיתִי מֵאַרעָא סְחוֹרְתִיך וְלָא יִשׁתְּמַע עוֹד קָל אִזגַּדִּיך :
<h2>פרק ג</h2>
<h3>פסוק א</h3>
יֵי קַרתָּא אָשְׁדַת דַּם כּוּלַהּ כַּדבִּין בִּיזָא מַליָא לָא פָסִיק קְטוֹל :
<h3>פסוק ב</h3>
קָל נִיקוּשׁ מַחָא וְקָל זְיָע גַּלגַּלִין וְסוּסָוָון מְפֻנְכִין וּרתִכִּין מְקַפְּצִין :
<h3>פסוק ג</h3>
פָּרָשׁ מַסֵיק לְהוֹב וְצִלהוּב סֵיפִין וְצִחצוּח מוֹרָניָן וּסגֵי קְטִילִין וַהֲמוֹן פִּגרִין וְלֵית סוֹף לִקטִילַיָא יִתַּקלוּן בִּקטִילֵיהוֹן :
<h3>פסוק ד</h3>
מִדְּסַגִּיאוּת אִתרְגוֹשַׁת קַרתָּא דְּהִיא כְטָעִיתָא נָפְקַת בָּרָא שַׁפִּירַת רֵיו יָדְעָא חַרשִׁין מָסְרָא עַמְמַיָא בִּטעוּתַהּ וּמַלכְוָת בְּחַרשַׁהָא :
<h3>פסוק ה</h3>
הָאֲנָא שָׁלַח רֻגזִי עֲלַך אֲמַר יְיָ צְבָאוֹת וַאֲגַלֵי בַהתַּת חוֹבַך עַל אַפַּך וְאַחזִי עַמְמַיָא בַּהתְּתִיך וּמַלכְוָתָא קְלָנִיך :
<h3>פסוק ו</h3>
וְאֶרמֵי עֲלַך שִׁקוּצִין וַאֲנַבְּלִנִיך וַאֲשַׁוֵינִיך מְכַעֲרָא לְעֵינֵי כָל חָזַך :
<h3>פסוק ז</h3>
וִיהֵי כָל דְּיִחזֵינִיך יִתרַחַק מִנִיך וְיֵימַר אִתבְּזֵיזַת נִינְוֵה מַן יִדוֵי עֲלַך אֵיכָא אַשׁכַּח דִּמנַחֲמִין לִיך :
<h3>פסוק ח</h3>
הָא אַתּ טָבָא מֵאֲלַכסַנדַּריָא רַבְּתָא דְּיָתְבָא בֵּינֵי נַהרְוָתָא מַיָא סְחוֹר סְחוֹר לַהּ דְּשׁוּרַהּ יַמָא מֵי יַמָא שׁוּרַהָא :
<h3>פסוק ט</h3>
כּוּשׁ סֻמכָוָתַהּ וּמִצרַיִם וְלֵית סוֹף פּוּטָאֵי וְלוּבָאֵי הֲווֹ בְּסַעֲדִיך :
<h3>פסוק י</h3>
אַף הִיא לְגָלוּתָא תְּהָך בְּשִׁביָא אַף עוּלֵימַהָא יִטָרְפוּן בְּרֵישׁ כָּל שׁוּקַיָא וְעַל יַקִירַהָא רְמוֹ עַדבִּין וְכָל רַברְבַהָא יִדַּדקוּן בְּשֵׁישְׁלָן :
<h3>פסוק יא</h3>
אַף אַתּ דָּמיָא לְרָויָא מְסַלעֲמָא אַף אַתּ תִּבעַן סְעֵיד מִבְּעֵיל דְּבָבָא :
<h3>פסוק יב</h3>
כָּל כַּרכַך דָּמַן לְתֵינִין בַּכִּירָן דְּאִם יַרעֲדוּנוּנִין יִתְּרָן וְיִשׁתַּאֲרוּן בְּהוֹן צִמוּקִין דְּכָשְׁרִין לְמֵיכַל :
<h3>פסוק יג</h3>
הָא עַמִיך חַלָשִׁין כִּנשַׁיָא בְּגַוִיך לְבַעֲלֵי דְבָבַך אִתפַּתַּחָא יִתפַּתְּחוּן תַּרעֵי אַרעִיך שֵׁיצִיאַת אִישָׁתָא תֻּקפַּך :
<h3>פסוק יד</h3>
מַיָא בִציָרָא כְּנוּשִׁי לִיך תַּקִיפִי כַּרכַך אַסגַּא מַרוָא וְשַׁעֲבִידִי בְטִינָא אַתקִיפִי בִניָנִיך :
<h3>פסוק טו</h3>
לְתַמָן יֵיתוֹן עֲלַך עַמְמַיָא דְּתַקִיפִין כְּאִישָׁתָא יְשֵׁיצוֹנִיך קָטוֹלֵי חַרבָּא יִתכַּנשׁוּן עֲלַך מַשׁרְיָת עַמְמִין דְּסַגִּיאִין כְּזַחלָא יִחפּוֹנִיך כְּקִמצָא יַחסְנוּנִיך כְּגוֹבָא :
<h3>פסוק טז</h3>
אַסגִּית תַּגָּרַך כְּכוֹכְבֵי שְׁמַיָא הָא כְזַחלָא דְשָׁלַח וּפָרַח :
<h3>פסוק יז</h3>
הָא טַסַך מְצַלהֲבִין כְּגוֹבָא וְטַפסְרַך כִּזחֵיל גּוֹבַי דְּשָׁקַן בְּכֻתלַיָא בְּיוֹם קְרִיר דְּכַד שִׁמשָׁא דָנְחָא עֲלֵיהוֹן מִתבַּדְּרִין וְלָא אִתיְדַע אֲתַרהוֹן לְאָן עָרְקִין :
<h3>פסוק יח</h3>
אִתְּבַרוּ גִיבָּרָך מַלכָּא דְאַתּוּר גְּלוֹ עַם מַשׁרְיָתָך אִתבַּדַּרוּ עַמָך עַל טוּרַיָא וְלֵית דִּמכַנֵישׁ :
<h3>פסוק יט</h3>
לֵית דְּכָאֵיב לָך עַל תְּבָרָך מְמָרְעָא מַחֲתָך כָּל שָׁמְעֵי שִׁמעֲתָך טְפַחוּ יְדֵיהוֹן עֲלָך חֲדִיאוּ אֲרֵי עַל מַן לָא עֲדָת מַחַת בִּשׁתָּך תְּדִירָא :
