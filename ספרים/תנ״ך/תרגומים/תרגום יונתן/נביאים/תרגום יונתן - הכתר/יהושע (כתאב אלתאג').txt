<h1>תרגום יונתן על יהושע</h1>
<h2>פרק א</h2>
<h3>פסוק א</h3>
וַהֲוָה בָּתַר דְּמִית מֹשֶׁה עַבדָּא דַיְיָ וַאֲמַר יְיָ לִיהוֹשֻׁעַ בַּר נוּן מְשֻׁמשָׁנֵיהּ דְּמֹשֶׁה לְמֵימַר :
<h3>פסוק ב</h3>
מֹשֶׁה עַבדִּי מִית וּכעַן קוּם עֲבַר יָת יַרדְּנָא הָדֵין אַתְּ וְכָל עַמָא הָדֵין לְאַרעָא דַּאֲנָא יָהֵיב לְהוֹן לִבנֵי יִשׂרָאֵל :
<h3>פסוק ג</h3>
כָּל אַתרָא דְּתִדרוֹך פַּרסַת רַגלְכוֹן בֵּיהּ לְכוֹן יְהַבתֵּיהּ כְּמָא דְמַלֵילִית עִם מֹשֶׁה :
<h3>פסוק ד</h3>
מִן מַדבְּרָא וְלִבנָן הָדֵין וְעַד נַהרָא רַבָּא נַהרָא פְרָת כֹּל אֲרַע חִתָּאֵי וְעַד יַמָא רַבָּא מַעֲלָנֵי שִׁמשָׁא יְהֵי תְּחוּמְכוֹן :
<h3>פסוק ה</h3>
לָא יִתעַתַּד אֱנָשׁ קֳדָמָך כֹּל יוֹמֵי חַיָיך כְּמָא דַהֲוָה מֵימְרִי בְסַעֲדֵיהּ דְּמֹשֶׁה כֵּין יְהֵי מֵימְרִי בְסַעֲדָך לָא אֶשׁבְּקִנָך וְלָא אֲרַחֲקִנָך :
<h3>פסוק ו</h3>
תְּקַף וְעֵילַם אֲרֵי אַתְּ תַּחסֵין יָת עַמָא הָדֵין יָת אַרעָא דְּקַיֵימִית לַאֲבָהָתְהוֹן לְמִתַּן לְהוֹן :
<h3>פסוק ז</h3>
לְחוֹד תְּקַף וְעֵילַם לַחדָּא לְמִטַר לְמֶעֱבַד כְּכָל אוֹרָיתָא דְּפַקְדָך מֹשֶׁה עַבדִּי לָא תִסטֵי מִנֵיהּ לְיַמִינָא וְלִסמָאלָא בְּדִיל דְּתַצלַח בְּכָל אֲתַר דִּתהָך :
<h3>פסוק ח</h3>
לָא יִעדֵּי סִפרָא דְאוֹרָיתָא הָדֵין מִפּוּמָך וּתהֵי הָגֵי בֵיהּ יֵימָם וְלֵילֵי בְּדִיל דְּתִטַר לְמֶעֱבַד כְּכָל דִּכתִיב בֵּיהּ אֲרֵי בְכֵין תַּצלַח יָת אוֹרחָתָך וּבכֵין תַּכשֵׁיט :
<h3>פסוק ט</h3>
הֲלָא פַקֵידְתָך תְּקַף וְעֵילַם לָא תִדחַל וְלָא תִתְּבַר אֲרֵי בְסַעֲדָך מֵימְרָא דַיְיָ אֱלָהָך בְּכָל אֲתַר דִּתהָך :
<h3>פסוק י</h3>
וּפַקֵיד יְהוֹשֻׁעַ יָת סָרְכֵי עַמָא לְמֵימַר :
<h3>פסוק יא</h3>
עֲבֻרוּ בְּגוֹ מַשׁרִיתָא וּפַקִידוּ יָת עַמָא לְמֵימַר אַתקִינוּ לְכוֹן זְוָדִין אֲרֵי בְּסוֹף תְּלָתָא יוֹמִין אַתּוּן עָבְרִין יָת יַרדְּנָא הָדֵין לְמֵיעַל לְמֵירַת יָת אַרעָא דַּיְיָ אֱלָהֲכוֹן יָהֵיב לְכוֹן לְמֵירְתַהּ :
<h3>פסוק יב</h3>
וּלשֵׁבַט רְאוּבֵן וּלשֵׁיבַט גָּד וּלפַלגוּת שִׁבטָא דִמנַשֶׁה אֲמַר יְהוֹשֻׁעַ לְמֵימַר :
<h3>פסוק יג</h3>
הֲווֹ דְכִירִין יָת פִּתגָמָא דְּפַקֵיד יָתְכוֹן מֹשֶׁה עַבדָּא דַיְיָ לְמֵימָר יְיָ אֱלָהֲכוֹן מְנִיחַ לְכוֹן וִיהַב לְכוֹן יָת אַרעָא הָדָא :
<h3>פסוק יד</h3>
נְשֵׁיכוֹן טַפלְכוֹן וּבעִירְכוֹן יִתְּבוּן בְּאַרעָא דִּיהַב לְכוֹן מֹשֶׁה בְּעִברָא דְיַרדְּנָא וְאַתּוּן תִּעבְּרוּן מְזָרְזִין קֳדָם אֲחֵיכוֹן כֹּל גִּיבָּרֵי חֵילָא וּתסַעֲדוּן יָתְהוֹן :
<h3>פסוק טו</h3>
עַד דִּינִיחַ יְיָ לַאֲחֵיכוֹן כְּוָתְכוֹן וְיֵירְתוּן אַף אִנוּן יָת אַרעָא דַּיְיָ אֱלָהֲכוֹן יָהֵיב לְהוֹן וּתתוּבוּן לַאֲרַע יְרוּתַּתכּוֹן וְתֵירְתוּן יָתַהּ דִּיהַב לְכוֹן מֹשֶׁה עַבדָּא דַיְיָ בְּעִברָא דְיַרדְּנָא מַדנַח שִׁמשָׁא :
<h3>פסוק טז</h3>
וַאֲתִיבוּ יָת יְהוֹשֻׁעַ לְמֵימַר כָּל דְּפַקֵידתַּנָא נַעֲבֵיד וּלכָל אֲתַר דְּתִשׁלְחִינַנָא נְהָך :
<h3>פסוק יז</h3>
כְּכָל דְּקַבֵּילנָא מִן מֹשֶׁה כֵּן נְקַבֵּיל מִינָך לְחוֹד יְהֵי מֵימְרָא דַיְיָ אֱלָהָך בְּסַעֲדָך כְּמָא דַהֲוָה בְּסַעֲדֵיהּ דְּמֹשֶׁה :
<h3>פסוק יח</h3>
כָּל גְּבַר דִּיסָרֵיב עַל מֵימְרָך וְלָא יְקַבֵּיל יָת פִּתגָמָך לְכֹל דִּתפַקְדִנֵיהּ יִתקְטִיל לְחוֹד תְּקַף וְעֵילַם :
<h2>פרק ב</h2>
<h3>פסוק א</h3>
וּשׁלַח יְהוֹשֻׁעַ בַּר נוּן מִן שִׁטִין תְּרֵין גֻּברִין מְאַלְלִין בְּרָז לְמֵימַר אִיזִילוּ חֲזוֹ יָת אַרעָא וְיָת יְרִיחוֹ וַאֲזַלוּ וְעָלוּ לְבֵית אִיתְּתָא פֻנדְּקֵיתָא וּשׁמַהּ רָחָב וּשׁכִיבוּ תַמָן :
<h3>פסוק ב</h3>
וְאִתאֲמַר לְמַלכָּא דִירִיחוֹ לְמֵימַר הָא גֻברַיָא אֲתוֹ הָלְכָא בְלֵיליָא מִבְּנֵי יִשׂרָאֵל לְאַלָלָא יָת אַרעָא :
<h3>פסוק ג</h3>
וּשׁלַח מַלכָּא דִירִיחוֹ לְוָת רָחָב לְמֵימַר אַפִּיקִי גֻּברַיָא דַאֲתוֹ לְוָתִיך דְּעָלוּ לְבֵיתִיך אֲרֵי לְאַלָלָא יָת כָּל אַרעָא אֲתוֹ :
<h3>פסוק ד</h3>
וּדבַרַת אִיתְּתָא יָת תְּרֵין גֻּברַיָא וְאַטמַרַתנוּן וַאֲמַרַת בְּקֻשׁטָא אֲתוֹ לְוָתִי גֻּברַיָא וְלָא יְדַעִית אֵי מְנָן אִנוּן :
<h3>פסוק ה</h3>
וַהֲוָה עִדָּן לְמֵיחַד תַּרעָא בְּקַבלָא וְגֻברַיָא נְפַקוּ לָא יְדַעִית לְאָן אֲזַלוּ גֻּברַיָא רְדוּפוּ בִפרִיעַ בָּתְרֵיהוֹן אֲרֵי תַדבְּקוּנוּנוּן :
<h3>פסוק ו</h3>
וְהִיא אַסֵיקַתנוּן לְאִיגָּרָא וְאַטמַרַתנוּן בִּטעוּנֵי כִתָּנָא דִּסדִירִין לַהּ עַל אִגָּרָא :
<h3>פסוק ז</h3>
וְגֻברַיָא רְדַפוּ בָתְרֵיהוֹן אוֹרַח יַרדְּנָא עַל מְגָזָתָא וְתַרעָא אֲחַדוּ בָּתַר דִּנפַקוּ רָדְפַיָא בָּתְרֵיהוֹן :
<h3>פסוק ח</h3>
וְאִנוּן עַד לָא שְׁכִיבוּ וְהִיא סְלֵיקַת לְוָתְהוֹן לְאִיגָּרָא :
<h3>פסוק ט</h3>
וַאֲמַרַת לְגֻברַיָא יָדַענָא אֲרֵי יְהַב יְיָ לְכוֹן יָת אַרעָא וַאֲרֵי נְפַלַת אֵימַתכוֹן עֲלַנָא וַאֲרֵי אִתְּבַרוּ כָּל יָתְבֵי אַרעָא מִן קֳדָמֵיכוֹן :
<h3>פסוק י</h3>
אֲרֵי שְׁמַענָא יָת דְּיַבֵּישׁ יְיָ יָת מֵי יַמָא דְסוּף מִן קֳדָמֵיכוֹן בְּמִפַּקכוֹן מִמִצרַיִם וְדַעֲבַדתּוּן לִתרֵין מַלכֵי אֱמוֹרָאָה דִּבעִברָא דְיַרדְּנָא לְסִיחוֹן וּלעוֹג דְּגַמַרתּוּן יָתְהוֹן :
<h3>פסוק יא</h3>
וּשׁמַענָא וְאִתמְסִי לִבַּנָא וְלָא אִשׁתְּאַרַת עוֹד רוּחַ בֶּאֱנָשׁ מִן קֳדָמֵיכוֹן אֲרֵי יְיָ אֱלָהֲכוֹן הוּא אֱלֹהִים דִּשׁכִינְתֵיהּ בִּשׁמַיָא מִלְעֵילָא וְשַׁלִיט עַל אַרעָא מִלְרַע :
<h3>פסוק יב</h3>
וּכעַן קַיִימוּ כְעַן לִי בְּמֵימְרָא דַיְיָ אֲרֵי עֲבַדִית עִמְכוֹן טֵיבוּ וְתַעבְּדוּן אַף אַתּוּן עִם בֵּית אַבָּא טֵיבוּ וְתִתְּנוּן לִי אָת דִּקשׁוֹט :
<h3>פסוק יג</h3>
וְתַחוֹן יָת אַבָּא וְיָת אִמָא וְיָת אַחַי וְיָת אַחֲוָתַי וְיָת כָּל דִּילְהוֹן וְתשֵׁזְבוּן יָת נַפשָׁתַנָא מִמוֹתָא :
<h3>פסוק יד</h3>
וַאֲמַרוּ לַהּ גֻּברַיָא נַפשָׁתַנָא מְסִירָן חֲלָף נַפשָׁתְכוֹן לִממָת אִם לָא תְחַווֹן יָת פִּתגָמַנָא דֵּין וִיהֵי כַּד יִתֵּין יְיָ לַנָא יָת אַרעָא וְנַעֲבֵיד עִמִיך טֵיבוּ וּקשׁוֹט :
<h3>פסוק טו</h3>
וְשַׁלשֵׁילַתנוּן בַּאֲטוּנָא מִן חֲרַכָּא אֲרֵי בֵיתַהּ בִּכתַל שׁוּרָא וּבשׁוּרָא הִיא יָתְבָא :
<h3>פסוק טז</h3>
וַאֲמַרַת לְהוֹן לְטוּרָא אִיזִילוּ דִּלמָא יְעָרְעוּן בְּכוֹן רָדְפַיָא וְתִטַמרוּן תַּמָן תְּלָתָה יוֹמִין עַד דִּיתוּבוּן רָדְפַיָא וּבָתַר כֵּין תְּהָכוּן לְאוֹרַחכוֹן :
<h3>פסוק יז</h3>
וַאֲמַרוּ לַהּ גֻּברַיָא זַכָּאִין אֲנַחנָא מִמוֹמָתִיך הָדָא דְּקַיֵימתְּ עֲלַנָא :
<h3>פסוק יח</h3>
הָא אֲנַחנָא עָלִין בְּאַרעָא יָת תּוּרָא דְּחוּט זְהוֹרִיתָא הָדֵין תִּקטְרִין בַּחֲרַכָּא דְּשַׁלשֵׁילתִּנָא בֵיהּ וְיָת אֲבוּך וְיָת אִמִיך וְיָת אֲחַך וְיָת כָּל בֵּית אֲבוּך תִּכנְשִׁין לְוָתִיך לְבֵיתָא :
<h3>פסוק יט</h3>
וִיהֵי כָּל דְּיִפּוֹק בָּר מִדַּשֵׁי בֵיתִיך לְבָרָא חוֹבַת קְטוּלֵיהּ בְּרֵישֵׁיהּ וַאֲנַחנָא זַכָּאִין וְכָל דִּיהֵי עִמִיך בְּבֵיתָא חוֹבַת קְטוּלֵיהּ בְּרֵישַׁנָא אִם יַד אֱנָשׁ תְּהֵי בֵיהּ :
<h3>פסוק כ</h3>
וְאִם תְּחַווֹן יָת פִּתגָמַנָא דֵין וּנהֵי זַכָּאִין מִמוֹמָתִיך דְּקַיֵימתְּ עֲלַנָא :
<h3>פסוק כא</h3>
וַאֲמַרַת כְּפִתגָמֵיכוֹן כֵּן הוּא וְשַׁלַחַתנוּן וַאֲזַלוּ וּקטַרַת יָת תּוּרָא דִזהוֹרִיתָא בַּחֲרַכָּא :
<h3>פסוק כב</h3>
וַאֲזַלוּ וְעָלוּ לְטוּרָא וִיתִיבוּ תַמָן תְּלָתָה יוֹמִין עַד דְּתָבוּ רָדְפַיָא וּבעוֹ רָדְפַיָא בְּכָל אוֹרחָא וְלָא אַשׁכַּחוּ :
<h3>פסוק כג</h3>
וְתָבוּ תְּרֵין גֻּברַיָא וּנחַתוּ מִטוּרָא וַעֲבַרוּ וַאֲתוֹ לְוָת יְהוֹשֻׁעַ בַּר נוּן וְאִשׁתַּעִיאוּ לֵיהּ יָת כָּל דְּעָרַעָא יָתְהוֹן :
<h3>פסוק כד</h3>
וַאֲמַרוּ לִיהוֹשֻׁעַ אֲרֵי מְסַר יְיָ בִּידַנָא יָת כָּל אַרעָא וְאַף אִתְּבַרוּ כָּל יָתְבֵי אַרעָא מִן קֳדָמַנָא :
<h2>פרק ג</h2>
<h3>פסוק א</h3>
וְאַקדֵּים יְהוֹשֻׁעַ בְּצַפרָא וּנטַלוּ מִשִׁטִין וַאֲתוֹ עַד יַרדְּנָא הוּא וְכָל בְּנֵי יִשׂרָאֵל וּבָתוּ תַמָן קֳדָם דְּיִעבְּרוּן :
<h3>פסוק ב</h3>
וַהֲוָה מִסוֹף תְּלָתָה יוֹמִין וַעֲבַרוּ סָרְכַיָא בְּגוֹ מַשׁרִיתָא :
<h3>פסוק ג</h3>
וּפַקִידוּ יָת עַמָא לְמֵימַר כְּמִחזֵיכוֹן יָת אֲרוֹן קְיָמָא דַיְיָ אֱלָהֲכוֹן וְכָהֲנַיָא לֵיוָאֵי נָטְלִין יָתֵיהּ וְאַתּוּן תִּיטְלוּן מֵאַתרְכוֹן וּתהָכוּן בָּתְרוֹהִי :
<h3>פסוק ד</h3>
בְּרַם רַחִיק יְהֵי בֵּינֵיכוֹן וּבֵינוֹהִי כִּתרֵין אַלפִין אַמִין בְּמִשׁחֲתָא לָא תִקרְבוּן לְוָתֵיהּ בְּדִיל דְּתִדְּעוּן יָת אוֹרחָא דִּתהָכוּן בַּהּ אֲרֵי לָא עֲבַרתּוּן בְּאוֹרחָא מֵאֶתמָלִי וּמִדְּקַמוֹהִי :
<h3>פסוק ה</h3>
וַאֲמַר יְהוֹשֻׁעַ לְעַמָא אִזדָּמַנוּ אֲרֵי מְחַר יַעֲבֵיד יְיָ בֵּינֵיכוֹן פְּרִישָׁן :
<h3>פסוק ו</h3>
וַאֲמַר יְהוֹשֻׁעַ לְכָהֲנַיָא לְמֵימַר טוּלוּ יָת אֲרוֹן קְיָמָא וַעֲבֻרוּ קֳדָם עַמָא וּנטַלוּ יָת אֲרוֹנָא דִקיָמָא וַאֲזַלוּ קֳדָם עַמָא :
<h3>פסוק ז</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ יוֹמָא דֵין אֲשָׁרֵי לְרַבָּיוּתָך בְּעֵינֵי כָּל יִשׂרָאֵל דְּיִדְּעוּן אֲרֵי כְּמָא דַהֲוָה מֵימְרִי בְסַעֲדֵיהּ דְּמֹשֶׁה כֵּין יְהֵי מֵימְרִי בְסַעֲדָך :
<h3>פסוק ח</h3>
וְאַתְּ תְּפַקֵיד יָת כָּהֲנַיָא נָטְלֵי אֲרוֹנָא דִקיָמָא לְמֵימַר כְּמִמטֵיכוֹן עַד קְצָת מֵי יַרדְּנָא בְּיַרדְּנָא תְּקוּמוּן :
<h3>פסוק ט</h3>
וַאֲמַר יְהוֹשֻׁעַ לִבנֵי יִשׂרָאֵל אִתקְרַבוּ הָלְכָא וּשׁמַעוּ יָת פִּתגָמָא דַּיְיָ אֱלָהֲכוֹן :
<h3>פסוק י</h3>
וַאֲמַר יְהוֹשֻׁעַ בְּדָא תִּדְּעוּן אֲרֵי אֱלָה קַיָים אִתרְעִי לְאַשׁרָאָה שְׁכִינְתֵיהּ בֵּינֵיכוֹן וְתָרָכָא יְתָרֵיך מִן קֳדָמֵיכוֹן יָת כְּנַעֲנָאֵי וְיָת חִתָּאֵי וְיָת חִוָאֵי וְיָת פְּרִזָאֵי וְיָת גַּרגִּישָׁאֵי וֶאֱמוֹרָאֵי וִיבוּסָאֵי :
<h3>פסוק יא</h3>
הָא אֲרוֹן קְיָמָא דְּרִיבּוֹן כָּל אַרעָא עָבַר קֳדָמֵיכוֹן בְּיַרדְּנָא :
<h3>פסוק יב</h3>
וּכעַן סַבוּ לְכוֹן תְּרֵי עֲסַר גֻּברִין מִשִׁבטֵי יִשׂרָאֵל גֻּברָא חַד גֻּברָא לְשִׁבטָא :
<h3>פסוק יג</h3>
וִיהֵי כִּמנָח פַּרסַת רַגלֵי כָהֲנַיָא נָטְלֵי אֲרוֹנָא דַיְיָ רִבּוֹן כָּל אַרעָא בְּמֵי יַרדְּנָא מֵי יַרדְּנָא יִפסְקוּן מַיָא דְנָחֲתִין מִלְעֵילָא וִיקוּמוּן רִכבָּא חַד :
<h3>פסוק יד</h3>
וַהֲוָה כַּד נְטַלוּ עַמָא מִמַשׁכְּנֵיהוֹן לְמִעבַּר יָת יַרדְּנָא וְכָהֲנַיָא נָטְלֵי אֲרוֹנָא דִקיָמָא קֳדָם עַמָא :
<h3>פסוק טו</h3>
וּכמִמטֵי נָטְלֵי אֲרוֹנָא עַד יַרדְּנָא וְרַגלֵי כָהֲנַיָא נָטְלֵי אֲרוֹנָא טְבִילָא בִּקצָת מַיָא וְיַרדְּנָא מְלֵי עַל כָּל כֵּיפוֹהִי כָּל יוֹמֵי חֲצָדָא :
<h3>פסוק טז</h3>
וְקָמוּ מַיָא דְנָחֲתִין מִלְעֵילָא קָמוּ רִכבָּא חַד רַחִיקִין לַחדָּא מֵאָדָם קַרתָּא דְּבִסְטַר צָרְתָן וּדנָחֲתִין לְיַמָא דְמֵישְׁרָא לְיַמָא דְמִלחָא שְׁלִימוּ פְסַקוּ וְעַמָא עֲבַרוּ לָקֳבֵיל יְרִיחוֹ :
<h3>פסוק יז</h3>
וְקָמוּ כָהֲנַיָא נָטְלֵי אֲרוֹן קְיָמָא דַיְיָ בְּיַבַּשׁתָּא בְּגוֹ יַרדְּנָא מְתֻקְנַיָא וְכָל יִשׂרָאֵל עָבְרִין בְּיַבַּשׁתָּא עַד דִּשׁלִימוּ כָּל עַמָא לְמִעבַּר יָת יַרדְּנָא :
<h2>פרק ד</h2>
<h3>פסוק א</h3>
וַהֲוָה כַּד שְׁלִימוּ כָל עַמָא לְמִעבַּר יָת יַרדְּנָא וַאֲמַר יְיָ לִיהוֹשֻׁעַ לְמֵימַר :
<h3>פסוק ב</h3>
דְּבַרוּ לְכוֹן מִן עַמָא תְּרֵי עֲסַר גֻּברִין גֻּברָא חַד גֻּברָא חַד מִשִׁבטָא :
<h3>פסוק ג</h3>
וּפַקִידוּ יָתְהוֹן לְמֵימַר טוּלוּ לְכוֹן מִכָּא מִגּוֹ יַרדְּנָא מֵאֲתַר מְקָם רַגלֵי כָהֲנַיָא מְתֻקְנַיָא תַּרתַּא עַסרֵי אַבנַיָא וְתַעבְּרוּן יָתְהוֹן עִמְכוֹן וְתַחֲתוּן יָתְהוֹן בְּבֵית מְבָתָא דִּתבִיתוּן בֵּיהּ בְּלֵיליָא :
<h3>פסוק ד</h3>
וּקרָא יְהוֹשֻׁעַ לִתרֵי עֲסַר גֻּברִין דְּאַתקֵין מִבְּנֵי יִשׂרָאֵל גֻּברָא חַד גֻּברָא חַד מִשִׁבטָא :
<h3>פסוק ה</h3>
וַאֲמַר לְהוֹן יְהוֹשֻׁעַ עֲבַרוּ קֳדָם אֲרוֹנָא דַיְיָ אֱלָהֲכוֹן לְגוֹ יַרדְּנָא וַאֲרִימוּ לְכוֹן גְּבַר אַבנָא חֲדָא עַל כִּתפֵּיהּ לְמִניַן שִׁבטַיָא דִבנֵי יִשׂרָאֵל :
<h3>פסוק ו</h3>
בְּדִיל דִּתהֵי דָּא אָת בֵּינֵיכוֹן אֲרֵי יִשׁאֲלוּן בְּנֵיכוֹן מְחַר לְמֵימַר מָא אַבנַיָא הָאִלֵין לְכוֹן :
<h3>פסוק ז</h3>
וְתֵימְרוּן לְהוֹן דִּפסַקוּ מֵי יַרדְּנָא מִן קֳדָם אֲרוֹן קְיָמָא דַיְיָ בְּמִעבְּרֵיהּ בְּיַרדְּנָא פְּסַקוּ מֵי יַרדְּנָא וְיִהוְיָן אַבנַיָא הָאִלֵין לְדֻכרָנָא לִבנֵי יִשׂרָאֵל עַד עָלְמָא :
<h3>פסוק ח</h3>
וַעֲבַדוּ כֵן בְּנֵי יִשׂרָאֵל כְּמָא דְפַקֵיד יְהוֹשֻׁעַ וּנטַלוּ תַּרתַּא עַסרֵי אַבנַיָא מִגּוֹ יַרדְּנָא כְּמָא דְמַלֵיל יְיָ עִם יְהוֹשֻׁעַ לְמִניַן שִׁבטַיָא דִבנֵי יִשׂרָאֵל וְאַעבַּרוּנוּן עִמְהוֹן לְבֵית מְבָתָא וְאַצנַעוּנוּן תַּמָן :
<h3>פסוק ט</h3>
וְתַרתַּא עַסרֵי אַבנַיָא אֲקֵים יְהוֹשֻׁעַ בְּגוֹ יַרדְּנָא בַּאֲתַר מְקָם רַגלֵי כָהֲנַיָא נָטְלֵי אֲרוֹנָא דִקיָמָא וַהֲווֹ תַמָן עַד יוֹמָא הָדֵין :
<h3>פסוק י</h3>
וְכָהֲנַיָא נָטְלֵי אֲרוֹנָא קָיְמִין בְּגוֹ יַרדְּנָא עַד דִּשׁלִים כָּל פִּתגָמָא דְּפַקֵיד יְיָ יָת יְהוֹשֻׁעַ לְמַלָלָא עִם עַמָא כְּכֹל דְּפַקֵיד מֹשֶׁה יָת יְהוֹשֻׁעַ וְאוֹחִיאוּ עַמָא וַעֲבַרוּ :
<h3>פסוק יא</h3>
וַהֲוָה כַּד שְׁלִים כָּל עַמָא לְמִעבַּר וַעֲבַר אֲרוֹנָא דַיְיָ וְכָהֲנַיָא קֳדָם עַמָא :
<h3>פסוק יב</h3>
וַעֲבַרוּ בְּנֵי רְאוּבֵן וּבנֵי גָד וּפַלגוּת שִׁבטָא דִמנַשֶׁה מְזָרְזִין קֳדָם בְּנֵי יִשׂרָאֵל כְּמָא דְּמַלֵיל עִמְהוֹן מֹשֶׁה :
<h3>פסוק יג</h3>
כְּאַרבְּעִין אַלפִין מְזָרְזֵי חֵילָא עֲבַרוּ קֳדָם עַמָא דַיְיָ לִקרָבָא לְמֵישְׁרֵי יְרִיחוֹ :
<h3>פסוק יד</h3>
בְּיוֹמָא הַהוּא רַבִּי יְיָ יָת יְהוֹשֻׁעַ בְּעֵינֵי כָּל יִשׂרָאֵל וּדחִילוּ מִנֵיהּ כְּמָא דַּהֲווֹ דָחֲלִין מִן מֹשֶׁה כָּל יוֹמֵי חַיוֹהִי :
<h3>פסוק טו</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ לְמֵימַר :
<h3>פסוק טז</h3>
פַּקֵיד יָת כָּהֲנַיָא נָטְלֵי אֲרוֹנָא דְסָהֲדוּתָא וְיִסְקוּן מִן יַרדְּנָא :
<h3>פסוק יז</h3>
וּפַקֵיד יְהוֹשֻׁעַ יָת כָּהֲנַיָא לְמֵימַר סַקוּ מִן יַרדְּנָא :
<h3>פסוק יח</h3>
וַהֲוָה כַּד בְּעוֹ לְמִסַק כָּהֲנַיָא נָטְלֵי אֲרוֹן קְיָמָא דַיְיָ מִגּוֹ יַרדְּנָא אִתנְגִידָא פַּרסַת רַגלֵי כָהֲנַיָא וְנַחָא עַל יַבַּשׁתָּא וְתָבוּ מֵי יַרדְּנָא לַאֲתַרהוֹן וַאֲזַלוּ כְמֵאֶתמָלִי וּמִדְּקַמוֹהִי עַל כָּל כֵּיפוֹהִי :
<h3>פסוק יט</h3>
וְעַמָא סְלִיקוּ מִן יַרדְּנָא בְּעַסרָא לְיַרחָא קַדמָאָה וּשׁרוֹ בְּגִלגָּלָא בִּסיָפֵי מַדנַח יְרִיחוֹ :
<h3>פסוק כ</h3>
וְיָת תַּרתַּא עַסרֵי אַבנַיָא הָאִלֵין דִּנסַבוּ מִן יַרדְּנָא אֲקֵים יְהוֹשֻׁעַ בְּגִלגָּלָא :
<h3>פסוק כא</h3>
וַאֲמַר לִבנֵי יִשׂרָאֵל לְמֵימַר דְּיִשׁאֲלוּן בְּנֵיכוֹן מְחַר יָת אֲבָהָתְהוֹן לְמֵימַר מָא אַבנַיָא הָאִלֵין :
<h3>פסוק כב</h3>
וּתהוֹדְעוּן יָת בְּנֵיכוֹן לְמֵימַר בְּיַבַּשׁתָּא עֲבַר יִשׂרָאֵל יָת יַרדְּנָא הָדֵין :
<h3>פסוק כג</h3>
דְּיַבֵּישׁ יְיָ אֱלָהֲכוֹן יָת מֵי יַרדְּנָא מִן קֳדָמֵיכוֹן עַד מִעבַּרכוֹן כְּמָא דַעֲבַד יְיָ אֱלָהֲכוֹן לְיַמָא דְסוּף דְּיַבֵּישׁ מִן קֳדָמַנָא עַד דַּעֲבַרנָא :
<h3>פסוק כד</h3>
בְּדִיל דְּיִדְּעוּן כָּל עַמְמֵי אַרעָא יָת גְּבוּרְתָא דַיְיָ אֲרֵי תַקִיפָא הִיא בְּדִיל דְּתִדחֲלוּן קֳדָם יְיָ אֱלָהֲכוֹן כָּל יוֹמַיָא :
<h2>פרק ה</h2>
<h3>פסוק א</h3>
וַהֲוָה כַד שְׁמַעוּ כָל מַלכֵי אֱמוֹרָאָה דִּבעִברָא דְיַרדְּנָא מַערְבָא וְכָל מַלכֵי כְנַעֲנָאָה דְּעַל יַמָא יָת דְּיַבֵּישׁ יְיָ יָת מֵי יַרדְּנָא מִן קֳדָם בְּנֵי יִשׂרָאֵל עַד דַּעֲבַרוּ וְאִתמְסִי לִבְּהוֹן וְלָא אִשׁתְּאַרַת בְּהוֹן עוֹד רוּחַ מִן קֳדָם בְּנֵי יִשׂרָאֵל :
<h3>פסוק ב</h3>
בְּעִידָּנָא הַהוּא אֲמַר יְיָ לִיהוֹשֻׁעַ עֲבֵיד לָך אֻזמֵילָוָן חָרִיפִין וְתוּב גְּזַר יָת בְּנֵי יִשׂרָאֵל תִּניָנוּת :
<h3>פסוק ג</h3>
וַעֲבַד לֵיהּ יְהוֹשֻׁעַ אֻזמֵילָוָן חָרִיפִין וּגזַר יָת בְּנֵי יִשׂרָאֵל בְּגִבעֲתָא וּקרָא לַהּ גִּבעַת עֻרלַתָא :
<h3>פסוק ד</h3>
וְדֵין פִּתגָמָא דִּגזַר יְהוֹשֻׁעַ כָּל עַמָא דִנפַקוּ מִמִצרַיִם דִּכרַיָא כָּל גֻּברֵי מְגִיחֵי קְרָבָא מִיתוּ בְמַדבְּרָא בְּאוֹרחָא בְּמִפַּקהוֹן מִמִצרָיִם :
<h3>פסוק ה</h3>
אֲרֵי גְזִירִין הֲווֹ כָּל עַמָא דִּנפַקוּ וְכָל עַמָא דְּאִתיַלַדוּ בְמַדבְּרָא בְאוֹרחָא בְּמִפַּקהוֹן מִמִצרַיִם לָא גְזַרוּ :
<h3>פסוק ו</h3>
אֲרֵי אַרבְּעִין שְׁנִין הַלִיכוּ בְנֵי יִשׂרָאֵל בְּמַדבְּרָא עַד דְּסָף כָּל עַמָא גֻּברֵי מְגִיחֵי קְרָבָא דִּנפַקוּ מִמִצרַיִם דְּלָא קַבִּילוּ לְמֵימְרָא דַיְיָ דְּקַיֵים יְיָ לְהוֹן בְּדִיל דְּלָא לְאַחזָיוּתְהוֹן יָת אַרעָא דְּקַיֵים יְיָ לַאֲבָהָתְהוֹן לְמִתַּן לַנָא אֲרַע עָבְדָא חֲלָב וּדבָשׁ :
<h3>פסוק ז</h3>
וְיָת בְּנֵיהוֹן דְּקָמוּ בַאֲתַרהוֹן יָתְהוֹן גְּזַר יְהוֹשֻׁעַ אֲרֵי עַרלִין הֲווֹ אֲרֵי לָא גְזַרוּ יָתְהוֹן בְּאוֹרחָא :
<h3>פסוק ח</h3>
וַהֲוָה כַּד שְׁלִימוּ כָל עַמָא לְמִגזַר וִיתִיבוּ בַאֲתַרהוֹן בְּמַשׁרִיתָא עַד דְּאִתַּסִיאוּ :
<h3>פסוק ט</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ יוֹמָא דֵין אַעדִּיתִי יָת חִסוּדֵי מִצרָאֵי מִנְכוֹן וּקרָא שְׁמֵיהּ דְּאַתרָא הַהוּא גִּלגָּלָא עַד יוֹמָא הָדֵין :
<h3>פסוק י</h3>
וּשׁרוֹ בְנֵי יִשׂרָאֵל בְּגִלגָּלָא וַעֲבַדוּ יָת פִּסחָא בְּאַרבְּעַת עַסרָא יוֹמָא לְיַרחָא בְּרַמשָׁא בְּמֵישְׁרֵי יְרִיחוֹ :
<h3>פסוק יא</h3>
וַאֲכַלוּ מֵעֲבוּרָא דְאַרעָא מִבָּתַר פִּסחָא פַּטִיר וְקָליָא בִּכרַן יוֹמָא הָדֵין :
<h3>פסוק יב</h3>
וּפסַק מַנָא בְּיוֹמָא דְבָתְרוֹהִי בְּמֵיכַלהוֹן מֵעֲבוּרָא דְאַרעָא וְלָא הֲוָה עוֹד לִבנֵי יִשׂרָאֵל מַנָא וַאֲכַלוּ מֵעַלְלַת אַרעָא דִכנַעַן בְּשַׁתָּא הַהִיא :
<h3>פסוק יג</h3>
וַהֲוָה כַּד הֲוָה יְהוֹשֻׁעַ בִּירִיחוֹ וּזקַף עֵינוֹהִי וַחֲזָא וְהָא גֻברָא קָאֵים לְקִבלֵיהּ וְחַרבֵּיהּ שְׁלִיפָא בִּידֵיהּ וַאֲזַל יְהוֹשֻׁעַ לְוָתֵיהּ וַאֲמַר לֵיהּ הַלְמִסעֲדַנָא אֲתֵיתָא אִם לְבַעֲלֵי דְבָבַנָא :
<h3>פסוק יד</h3>
וַאֲמַר לָא אֲרֵי אֲנָא מַלאַך שְׁלִיחַ מִן קֳדָם יְיָ כְּעַן אֲתֵיתִי וּנפַל יְהוֹשֻׁעַ עַל אַפּוֹהִי עַל אַרעָא וּסגֵיד וַאֲמַר לֵיהּ מָא רִבּוֹנִי מְמַלֵיל עִם עַבדֵּיהּ :
<h3>פסוק טו</h3>
וַאֲמַר מַלאֲכָא דִשׁלִיחַ מִן קֳדָם יְיָ לִיהוֹשֻׁעַ שְׁרִי סֵינָך מֵעַל רַגלָך אֲרֵי אַתרָא דְּאַתְּ קָאֵים עֲלוֹהִי קַדִּישָׁא הוּא וַעֲבַד יְהוֹשֻׁעַ כֵּן :
<h2>פרק ו</h2>
<h3>פסוק א</h3>
וִירִיחוֹ אֲחִידָא וּמתֻקְפָא מִן קֳדָם בְּנֵי יִשׂרָאֵל לֵית מִנְהוֹן נָפֵיק וְעָלֵיל :
<h3>פסוק ב</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ חֲזִי דִּמסַרִית בִּידָך יָת יְרִיחוֹ וְיָת מַלכַּהּ גִּבָּרֵי חֵילָא :
<h3>פסוק ג</h3>
וְתַסחֲרוּן יָת קַרתָּא כָּל גֻּברֵי עָבְדֵי קְרָבָא אַקֵיף יָת קַרתָּא זִמנָא חֲדָא כְּדֵין תַּעֲבֵיד שִׁתָּא יוֹמִין :
<h3>פסוק ד</h3>
וְשִׁבעָה כָהֲנַיָא יִסְבוּן שִׁבעָה שׁוֹפָרַיָא דְקֶרֶן דִּכרָא קֳדָם אֲרוֹנָא וּביוֹמָא שְׁבִיעָאָה תַּסחֲרוּן יָת קַרתָּא שְׁבַע זִמנִין וְכָהֲנַיָא יִתקְעוּן בְּשׁוֹפָרַיָא :
<h3>פסוק ה</h3>
וִיהֵי כְּמִגַּד בְּקֶרֶן דִּכרָא כְּמִשׁמַעכוֹן יָת קָל שׁוֹפָרָא יְיַבְּבוּן כָּל עַמָא יַבָּבָא רַבָּא וְיִפּוֹל שׁוּרָא דְקַרתָּא וְיִתבְּלַע תְּחוֹתוֹהִי וְיִסְקוּן עַמָא גְּבַר לְקִבלֵיהּ :
<h3>פסוק ו</h3>
וּקרָא יְהוֹשֻׁעַ בַּר נוּן לְכָהֲנַיָא וַאֲמַר לְהוֹן טוּלוּ יָת אֲרוֹן קְיָמָא וְשִׁבעָה כָהֲנַיָא יִסְבוּן שִׁבעָה שׁוֹפָרַיָא דְּקֶרֶן דִּכרַיָא קֳדָם אֲרוֹנָא דַיְיָ :
<h3>פסוק ז</h3>
וַאֲמַר לְעַמָא עֲבַרוּ וְאַקִיפוּ יָת קַרתָּא וּמזָרְזֵי חֵילָא יִעבְּרוּן קֳדָם אֲרוֹנָא דַיְיָ :
<h3>פסוק ח</h3>
וַהֲוָה כַּד אֲמַר יְהוֹשֻׁעַ לְעַמָא וְשִׁבעָה כָהֲנַיָא נְסִיבוּ שִׁבעָה שׁוֹפָרַיָא דְקֶרֶן דִּכרַיָא קֳדָם יְיָ עָבְרִין וְתָקְעִין בְּשׁוֹפָרַיָא וַאֲרוֹן קְיָמָא דַיְיָ אָזֵיל בָּתְרֵיהוֹן :
<h3>פסוק ט</h3>
וּמזָרְזֵי חֵילָא אָזְלִין קֳדָם כָּהֲנַיָא תָּקְעֵי שׁוֹפָרַיָא וְשִׁבטָא דְבֵית דָּן אָזֵיל בָּתַר אֲרוֹנָא וְכָהֲנַיָא אָזְלִין וְתָקְעִין בְּשׁוֹפָרַיָא :
<h3>פסוק י</h3>
וְיָת עַמָא פַקֵיד יְהוֹשֻׁעַ לְמֵימַר לָא תְיַבְּבוּן וְלָא תַשׁמְעוּן יָת קָלְכוֹן וְלָא יִפּוֹק מִפּוּמְכוֹן פִּתגָמָא עַד יוֹמָא דְאֵימַר לְכוֹן יַבִּיבוּ וְתיַבְּבוּן :
<h3>פסוק יא</h3>
וְאַסחַר אֲרוֹנָא דַיְיָ יָת קַרתָּא אַקֵיף זִמנָא חֲדָא וְעָלוּ לְמַשׁרִיתָא וּבָתוּ בְּמַשׁרִיתָא :
<h3>פסוק יב</h3>
וְאַקדֵּים יְהוֹשֻׁעַ בְּצַפרָא וּנטַלוּ כָהֲנַיָא יָת אֲרוֹנָא דַיְיָ :
<h3>פסוק יג</h3>
וְשִׁבעָה כָהֲנַיָא נְסִיבוּ שִׁבעָה שׁוֹפָרַיָא דְּקֶרֶן דִּכרַיָא קֳדָם אֲרוֹנָא דַיְיָ אָזְלִין מֵיזָל וְתָקְעִין בְּשׁוֹפָרַיָא וּמזָרְזֵי חֵילָא אָזְלִין קֳדָמֵיהוֹן וְשִׁבטָא דְבֵית דָּן אָזֵיל בָּתַר אֲרוֹנָא דַיְיָ וְכָהֲנַיָא אָזְלִין וְתָקְעִין בְּשׁוֹפָרַיָא :
<h3>פסוק יד</h3>
וְאַסחַרוּ יָת קַרתָּא בְּיוֹמָא תִניָנָא זִמנָא חֲדָא וְתָבוּ לְמַשׁרִיתָא כְּדֵין עֲבַדוּ שִׁתָּא יוֹמִין :
<h3>פסוק טו</h3>
וַהֲוָה בְּיוֹמָא שְׁבִיעָאָה וְאַקדִּימוּ כְּמִיסַק צַפרָא וְאַסחַרוּ יָת קַרתָּא כְּהִלכְתָא הָדָא שְׁבַע זִמנִין לְחוֹד בְּיוֹמָא הַהוּא אַקִיפוּ יָת קַרתָּא שְׁבַע זִמנִין :
<h3>פסוק טז</h3>
וַהֲוָה בְּזִמנָא שְׁבִיעֵיתָא תְּקַעוּ כָהֲנַיָא בְּשׁוֹפָרַיָא וַאֲמַר יְהוֹשֻׁעַ לְעַמָא יַבִּיבוּ אֲרֵי יְהַב יְיָ לְכוֹן יָת קַרתָּא :
<h3>פסוק יז</h3>
וּתהֵי קַרתָּא חֶרמָא הִיא וְכָל דְּבַהּ קֳדָם יְיָ לְחוֹד רָחָב פֻּנדְּקֵיתָא תֵּיחֵי הִיא וְכָל דְּעִימַהּ בְּבֵיתָא אֲרֵי אַטמַרַת יָת אִזגַּדַּיָא דִּשׁלַחנָא :
<h3>פסוק יח</h3>
וּלחוֹד אַתּוּן אִסתְּמַרוּ מִן חֶרמָא דִּלמָא תַחרְמוּן וְתִיסְבוּן מִן חֶרמָא וּתשַׁווֹן יָת מַשׁרִיתָא דְיִשׂרָאֵל לְחֶרמָא וְתַעכְּרוּן יָתֵיהּ :
<h3>פסוק יט</h3>
וְכֹל כַּספָּא וְדַהבָּא וּמָנֵי נְחָשָׁא וּבַרזְלָא קֻדשָׁא אִנוּן קֳדָם יְיָ לְאוֹצַר בֵּית מַקדְּשָׁא דַיְיָ יִתָּעֲלוּן :
<h3>פסוק כ</h3>
וְיַבֵּיב עַמָא וּתקַעוּ בְּשׁוֹפָרַיָא וַהֲוָה כַד שְׁמַע עַמָא יָת קָל שׁוֹפָרָא וְיַבִּיבוּ עַמָא יַבָּבָא רַבָּא וּנפַל שׁוּרָא דְקַרתָּא וְאִתבְּלַע תְּחוֹתוֹהִי וּסלֵיק עַמָא לְקַרתָּא גְּבַר לְקִבלֵיהּ וּכבַשׁוּ יָת קַרתָּא :
<h3>פסוק כא</h3>
וְגַמַרוּ יָת כָּל דִּבקַרתָּא מִגְּבַר וְעַד אִיתָּא מֵעוּלֵימָא וְעַד סָבָא וְעַד תּוֹר וְאִמַר וַחֲמָר לְפִתגָּם דְּחָרֶב :
<h3>פסוק כב</h3>
וְלִתרֵין גֻּברַיָא דְּאַלִילוּ יָת אַרעָא אֲמַר יְהוֹשֻׁעַ עוּלוּ לְבֵית אִתְּתָא פֻנדְּקֵיתָא וְאַפִּיקוּ מִתַּמָן יָת אִיתְּתָא וְיָת כָּל דְּלַהּ כְּמָא דְקַיֵמתּוּן לַהּ :
<h3>פסוק כג</h3>
וְעָלוּ עוּלֵימַיָא מְאַלְלַיָא וְאַפִּיקוּ יָת רָחָב וְיָת אֲבוּהָא וְיָת אִמַהּ וְיָת אֲחַהָא וְיָת כָּל דְּלַהּ וְיָת כָּל זַרעֲיָתַהָא אַפִּיקוּ וְאַשׁרִיאוּנוּן מִבַּרָא לְמַשׁרִיתָא דְיִשׂרָאֵל :
<h3>פסוק כד</h3>
וְקַרתָּא אוֹקִידוּ בְנוּרָא וְכָל דְּבַהּ לְחוֹד כַּספָּא וְדַהֲבָא וּמָנֵי נְחָשָׁא וּבַרזְלָא יְהַבוּ בְּאוֹצַר בֵּית מַקדְּשָׁא דַיְיָ :
<h3>פסוק כה</h3>
וְיָת רָחָב פֻּנדְּקֵיתָא וְיָת בֵּית אֲבוּהָא וְיָת כָּל דְּלַהּ אַחִי יְהוֹשֻׁעַ וִיתֵיבַת בְּגוֹ בְנֵי יִשׂרָאֵל עַד יוֹמָא הָדֵין אֲרֵי אַטמַרַת יָת אִזגַּדַּיָא דִּשׁלַח יְהוֹשֻׁעַ לְאַלָלָא יָת יְרִיחוֹ :
<h3>פסוק כו</h3>
וְאוֹמִי יְהוֹשֻׁעַ בְּעִידָּנָא הַהוּא לְמֵימַר לִיט גֻּברָא קֳדָם יְיָ דִּיקוּם וְיִבנֵי יָת קַרתָּא הָדָא יָת יְרִיחוֹ בְּבֻכרֵיהּ יְשַׁכלְלִנַהּ וּבִזעֵיר בְּנוֹהִי יְקִים דַּשַׁהָא :
<h3>פסוק כז</h3>
וַהֲוָה מֵימְרָא דַיְיָ בְּסַעֲדֵיהּ דִּיהוֹשֻׁעַ וַהֲוָה שָׁמעֵיָהּ סָגֵי בְּכָל אַרעָא :
<h2>פרק ז</h2>
<h3>פסוק א</h3>
וְשַׁקַרוּ בְנֵי יִשׂרָאֵל שְׁקַר בְּחֶרמָא וּנסֵיב עָכָן בַּר כַּרמִי בַר זַבדִּי בַר זֶרַח לְשִׁבטָא דִיהוּדָה מִן חֶרמָא וּתקֵיף רֻגזָא דַיְיָ בִּבנֵי יִשׂרָאֵל :
<h3>פסוק ב</h3>
וּשׁלַח יְהוֹשֻׁעַ גֻּברִין מִירִיחוֹ לְעָי דְּעִם בֵּית אָוֶן מִמַדנַח לְבֵית אֵל וַאֲמַר לְהוֹן לְמֵימַר סַקוּ וְאַלִילוּ יָת אַרעָא וּסלִיקוּ גֻּברַיָא וְאַלִילוּ יָת עָי :
<h3>פסוק ג</h3>
וְתָבוּ לְוָת יְהוֹשֻׁעַ וַאֲמַרוּ לֵיהּ לָא יִסַק כָּל עַמָא כִּתרֵין אַלפִין אוֹ כִּתלָתָה אַלפִין גֻּברָא יִסְקוּן וְיִמחוֹן יָת עָי לָא תַרגֵּישׁ לְתַמָן יָת כָּל עַמָא אֲרֵי זְעֵירִין אִנוּן :
<h3>פסוק ד</h3>
וּסלִיקוּ מִן עַמָא לְתַמָן כִּתלָתָה אַלפִין גֻּברָא וַאֲפַכוּ קֳדָם אֱנָשֵׁי עָי :
<h3>פסוק ה</h3>
וּקטַלוּ מִנְהוֹן אֱנָשֵׁי עָי כִּתלָתִין וְשִׁתָּה גֻּברָא וּרדַפוּנוּן קֳדָם תַּרעָא עַד דִּתבַרוּנוּן וּמחוֹנוּן בְּמַחֲתַנָא וְאִתמְסִי לִבָּא דְעַמָא וַהֲוָה כְמַיָא :
<h3>פסוק ו</h3>
וּבַזַע יְהוֹשֻׁעַ לְבוּשׂוֹהִי וּנפַל עַל אַפּוֹהִי עַל אַרעָא קֳדָם אֲרוֹנָא דַיְיָ עַד רַמשָׁא הוּא וְסָבֵי יִשׂרָאֵל וְאַסִיקוּ עַפרָא עַל רֵישֵׁיהוֹן :
<h3>פסוק ז</h3>
וַאֲמַר יְהוֹשֻׁעַ קַבֵּיל בָּעוּתִי יְיָ אֱלֹהִים לְמָא אַעבַּרתָּא אַעבָּרָא יָת עַמָא הָדֵין יָת יַרדְּנָא לְמִמסַר יָתַנָא בִּידָא דֶאֱמוֹרָאָה לְאַבָּדוּתַנָא וְאִלוּ פוֹן דְּשָׁרִינָא וִיתֵיבנָא בְּעִברָא דְּיַרדְּנָא :
<h3>פסוק ח</h3>
בְּבָעוּ יְיָ מָא אֵימַר בָּתַר דְּאַחזַרוּ יִשׂרָאֵל קְדָלְהוֹן לְמֵיפַך קֳדָם בַּעֲלֵי דְבָבֵיהוֹן :
<h3>פסוק ט</h3>
וְיִשׁמְעוּן כְּנַעֲנָאֵי וְכֹל יָתְבֵי אַרעָא וְיִסתַּחרוּן עֲלַנָא וִישֵׁיצוֹן יָת שְׁמַנָא מִן אַרעָא וְאַתְּ עֲבֵיד בְּדִיל שְׁמָך רַבָּא :
<h3>פסוק י</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ קוּם לָך לְמָא דְנָן אַתְּ רְמִי עַל אַפָּך :
<h3>פסוק יא</h3>
חֲטָא יִשׂרָאֵל וְאַף עֲבַרוּ עַל קְיָמִי דְּפַקֵידִית יָתְהוֹן וְאַף נְסִיבוּ מִן חֶרמָא וְאַף גְּנַבוּ וְאַף כַּדִּיבוּ וְאַף שַׁוִיאוּ בְמָנֵיהוֹן :
<h3>פסוק יב</h3>
וְלָא יָכְלִין בְּנֵי יִשׂרָאֵל לִמקָם קֳדָם בַּעֲלֵי דְבָבֵיהוֹן קְדָלְהוֹן יַחזְרוּן לְמֵיפַך קֳדָם בַּעֲלֵי דְבָבֵיהוֹן אֲרֵי הֲווֹ לְחֶרמָא לָא אוֹסֵיף לְמִהוֵי מֵימְרִי בְסַעדְּכוֹן אִם לָא תְשֵׁיצוֹן חֶרמָא מִבֵּינֵיכוֹן :
<h3>פסוק יג</h3>
קוּם זָמֵין יָת עַמָא וְתֵימַר אִזדָּמַנוּ לִמחַר אֲרֵי כִדנָן אֲמַר יְיָ אֱלָהָא דְיִשׂרָאֵל חֶרמָא בֵינָך יִשׂרָאֵל לָא תִיכְּלוּן לִמקָם קֳדָם בַּעֲלֵי דְבָבֵיכוֹן עַד דְּתַעדּוֹן חֶרמָא מִבֵּינֵיכוֹן :
<h3>פסוק יד</h3>
וְתִקרְבוּן בְּצַפרָא לְשִׁבטֵיכוֹן וִיהֵי שִׁבטָא דְיִתאֲחַד מִן קֳדָם יְיָ יִתקָרַב לְזַרעֲיָן וְזַרעִיתָא דְּיִתאֲחַד מִן קֳדָם יְיָ תִּקרַב לְבָתִּין וּבֵיתָא דְּיִתאֲחַד מִן קֳדָם יְיָ יִקרַב לְגֻברַיָא :
<h3>פסוק טו</h3>
וִיהֵי דְּיִתאֲחַד בְּחֶרמָא יִתּוֹקַד בְּנוּרָא הוּא וְכָל דְּלֵיהּ אֲרֵי עֲבַר עַל קְיָמָא דַיְיָ וַאֲרֵי עֲבַד דְּלָא כָשַׁר בְּיִשׂרָאֵל :
<h3>פסוק טז</h3>
וְאַקדֵּים יְהוֹשֻׁעַ בְּצַפרָא וְקָרֵיב יָת יִשׂרָאֵל לְשִׁבטוֹהִי וְאִתאֲחַד שִׁבטָא דְבֵית יְהוּדָה :
<h3>פסוק יז</h3>
וְקָרֵיב יָת זַרעִית יְהוּדָה וְאִתאֲחַדַת זַרעִית זֶרַח וְקָרֵיב יָת זַרעִית זֶרַח לְגֻברַיָא וְאִתאֲחַד זַבדִּי :
<h3>פסוק יח</h3>
וְקָרֵיב יָת בֵּיתֵיהּ לְגֻברַיָא וְאִתאֲחַד עָכָן בַּר כַּרמִי בַר זַבדִּי בַּר זֶרַח לְשִׁבטָא דִיהוּדָה :
<h3>פסוק יט</h3>
וַאֲמַר יְהוֹשֻׁעַ לְעָכָן בְּרִי שַׁוִי כְעַן יְקָרָא קֳדָם יְיָ אֱלָהָא דְיִשׂרָאֵל וְהַב קֳדָמוֹהִי אוֹדָאָה וְחַוִי כְעַן לִי מָא עֲבַדתָּא לָא תְכַסֵי מִנִי :
<h3>פסוק כ</h3>
וַאֲתֵיב עָכָן יָת יְהוֹשֻׁעַ וַאֲמַר בְּקֻשׁטָא אֲנָא חַבִית קֳדָם יְיָ אֱלָהָא דְיִשׂרָאֵל וּכדֵין וּכדֵין עֲבַדִית :
<h3>פסוק כא</h3>
וַחֲזֵית בְּבִיזְתָא אִצטְלַאי בָבְלַאי חַד שַׁפִּיר וּמָאתַן סִלעִין דִּכסַף וְלִישָׁנָא דְדַהבָּא חַד חַמשִׁין סִלעִין מַתקָלֵיהּ וְרַגֵּגתִּנוּן וּנסֵבתִּנוּן וְהָא אִנוּן טְמִירִין בְּאַרעָא בְּגוֹ מַשׁכְּנִי וְכַספָּא תְחוֹתֵיהוֹן :
<h3>פסוק כב</h3>
וּשׁלַח יְהוֹשֻׁעַ אִזגַּדִּין וּרהַטוּ לְמַשׁכְּנָא וְהָא טְמִירִין בְּמַשׁכְּנֵיהּ וְכַספָּא תְחוֹתֵיהוֹן :
<h3>פסוק כג</h3>
וּנסִיבוּנוּן מִגּוֹ מַשׁכְּנָא וְאֵיתִיאוּנוּן לְוָת יְהוֹשֻׁעַ וּלוָת כָּל בְּנֵי יִשׂרָאֵל וְאַתִּיכוּנוּן קֳדָם יְיָ :
<h3>פסוק כד</h3>
וּדבַר יְהוֹשֻׁעַ יָת עָכָן בַּר זֶרַח וּנסֵיב יָת כַּספָּא וְיָת אִצטְלָא וְיָת לִישָׁנָא דְדַהבָּא וּדבַר יָת בְּנוֹהִי וְיָת בְּנָתֵיהּ וְיָת תּוֹרֵיהּ וְיָת חֲמָרֵיהּ וְיָת עָנֵיהּ וְיָת מַשׁכְּנֵיהּ וְיָת כָּל דְּלֵיהּ וְכָל יִשׂרָאֵל עִמֵיהּ וְאַסִיקוּ יָתְהוֹן לְמֵישַׁר עָכוֹר :
<h3>פסוק כה</h3>
וַאֲמַר יְהוֹשֻׁעַ מָא עֲכַרתַּנָא יַעכְּרִנָך יְיָ בְּיוֹמָא הָדֵין וּרגַמוּ יָתֵיהּ כָּל יִשׂרָאֵל בְּאַבנָא וְאוֹקִידוּ יָתְהוֹן בְּנוּרָא בָּתַר דִּרגַמוּ יָתְהוֹן בְּאַבנַיָא :
<h3>פסוק כו</h3>
וַאֲקִימוּ עֲלוֹהִי דְּגוֹר אַבנִין רַב עַד יוֹמָא הָדֵין וְתָב יְיָ מִתְּקוֹף רֻגזֵיהּ עַל כֵּן קְרָא שְׁמֵיהּ דְּאַתרָא הַהוּא מֵישַׁר עָכוֹר עַד יוֹמָא הָדֵין :
<h2>פרק ח</h2>
<h3>פסוק א</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ לָא תִדחַל וְלָא תִתְּבַר דְּבַר עִמָך יָת כָּל עַמָא עָבְדֵי קְרָבָא וְקוּם סַק לְעָי חֲזִי דִּמסַרִית בִּידָך יָת מַלכָּא דְעַי וְיָת עַמֵיהּ וְיָת קַרתֵּיהּ וְיָת אַרעֵיהּ :
<h3>פסוק ב</h3>
וְתַעֲבֵיד לְעַי וּלמַלכַּהּ כְּמָא דַעֲבַדתָּא לִירִיחוֹ וּלמַלכַּהּ לְחוֹד עֲדָאַהּ וּבעִירַהּ תִּבְּזוּן לְכוֹן אַתקֵין לָך כָּמְנָא לְקַרתָּא מֵאֲחוֹרַהָא :
<h3>פסוק ג</h3>
וְקָם יְהוֹשֻׁעַ וְכָל עַמָא עָבְדֵי קְרָבָא לְמִסַק לְעָי וּבחַר יְהוֹשֻׁעַ תְּלָתִין אַלפִין גֻּברָא גִּבָּרֵי חֵילָא וּשׁלַחִנוּן בְּלֵיליָא :
<h3>פסוק ד</h3>
וּפַקֵיד יָתְהוֹן לְמֵימַר חֲזוֹ דְּאַתּוּן כָּמְנִין לְקַרתָּא מֵאֲחוֹרֵי קַרתָּא לָא תַרחֲקוּן מִן קַרתָּא לַחדָּא וּתהוֹן כֻּלְכוֹן מְתֻקְנַיָא :
<h3>פסוק ה</h3>
וַאֲנָא וְכָל עַמָא דְּעִמִי נִתקָרַב לְקַרתָּא וִיהֵי אֲרֵי יִפְּקוּן לְקַדָּמוּתַנָא כִּיד בְּקַדמֵיתָא וְנֵיפוֹך קֳדָמֵיהוֹן :
<h3>פסוק ו</h3>
וְיִפְּקוּן בָּתרַנָא עַד דְּנֵיגוֹד יָתְהוֹן מִן קַרתָּא אֲרֵי יֵימְרוּן תְּבִירִין קֳדָמַנָא כִּד בְּקַדמֵיתָא וְנֵיפוֹך קֳדָמֵיהוֹן :
<h3>פסוק ז</h3>
וְאַתּוּן תְּקוּמוּן מִן כָּמְנָא וּתתָרְכוּן יָת קַרתָּא וְיִמסְרִינַהּ יְיָ אֱלָהֲכוֹן בְּיַדכוֹן :
<h3>פסוק ח</h3>
וִיהֵי כְּמֵיחַדכוֹן יָת קַרתָּא תַּדלְקוּן יָת קַרתָּא בְּנוּרָא כְּפִתגָמָא דַיְיָ תַּעבְּדוּן חֲזוֹ דְּפַקֵידִית יָתְכוֹן :
<h3>פסוק ט</h3>
וְשַׁלַחִנוּן יְהוֹשֻׁעַ וַאֲזַלוּ לְכָמְנָא וִיתִיבוּ בֵּין בֵּית אֵל וּבֵין עַי מַערַב לְעָי וּבָת יְהוֹשֻׁעַ בְּלֵיליָא הַהוּא בְּגוֹ עַמָא :
<h3>פסוק י</h3>
וְאַקדֵּים יְהוֹשֻׁעַ בְּצַפרָא וּמנָא יָת עַמָא וּסלֵיק הוּא וְסָבֵי יִשׂרָאֵל קֳדָם עַמָא לְעָי :
<h3>פסוק יא</h3>
וְכָל עַמָא עָבְדֵי קְרָבָא דְּעִמֵיהּ סְלִיקוּ וְאִתקָרַבוּ וַאֲתוֹ לָקֳבֵיל קַרתָּא וּשׁרוֹ מִצִפּוּנָא לְעַי וְחִילְתָא בֵּינוֹהִי וּבֵין עָי :
<h3>פסוק יב</h3>
וּדבַר כְּחַמשָׁא אַלפִין גֻּברָא וְשַׁוִי יָתְהוֹן כָּמְנָא בֵּין בֵּית אֵל וּבֵין עַי מַערַב לְקַרתָּא :
<h3>פסוק יג</h3>
וְשַׁוִיאוּ עַמָא יָת כָּל מַשׁרִיתָא דְּמִצִפּוּנָא לְקַרתָּא וְיָת כָּמְנֵיהּ מַערַב לְקַרתָּא וַאֲזַל יְהוֹשֻׁעַ בְּלֵיליָא הַהוּא בְּגוֹ מֵישְׁרָא :
<h3>פסוק יד</h3>
וַהֲוָה כַּד חֲזָא מַלכָּא דְעַי וְאוֹחִיאוּ וְאַקדִּימוּ וּנפַקוּ אֱנָשֵׁי קַרתָּא לְקַדָּמוּת יִשׂרָאֵל לְאָגָחָא קְרָבָא הוּא וְכָל עַמֵיהּ לְזִמנָא דִּמתֻקַן לֵיהּ קֳדָם מֵישְׁרָא וְאִנוּן לָא יָדְעִין אֲרֵי כָמְנָא לְהוֹן מֵאֲחוֹרֵי קַרתָּא :
<h3>פסוק טו</h3>
וְאִתְּבַרוּ יְהוֹשֻׁעַ וְכָל יִשׂרָאֵל קֳדָמֵיהוֹן וַאֲפַכוּ בְּאוֹרַח מַדבְּרָא :
<h3>פסוק טז</h3>
וְאִתכְּנַשׁוּ כָּל עַמָא דִּבעַי לְמִרדַּף בָּתְרֵיהוֹן וּרדַפוּ בָּתַר יְהוֹשֻׁעַ וְאִתנְגִידוּ מִן קַרתָּא :
<h3>פסוק יז</h3>
וְלָא אִשׁתְּאַר אֱנָשׁ בְּעַי וּבֵית אֵל דְּלָא נְפַקוּ בָּתַר יִשׂרָאֵל וּשׁבַקוּ יָת קַרתָּא כַּד פְּתִיחָא וּרדַפוּ בָּתַר יִשׂרָאֵל :
<h3>פסוק יח</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ אֲרֵים בְּרֻמחָא דִביְדָך עַל עַי אֲרֵי בִידָך אַמסְרִנַהּ וַאֲרֵים יְהוֹשֻׁעַ בְּרֻמחָא דִביְדֵיהּ עַל קַרתָּא :
<h3>פסוק יט</h3>
וְכָמְנָא קָם בִּפרִיעַ מֵאַתרֵיהּ וּרהַטוּ כַּד אֲרֵים יְדֵיהּ וְעָלוּ לְקַרתָּא וְכַבשׁוּהָא וְאוֹחִיאוּ וְאַדלִיקוּ יָת קַרתָּא בְּנוּרָא :
<h3>פסוק כ</h3>
וְאִתפְּנִיאוּ אֱנָשֵׁי עַי לַאֲחוֹרֵיהוֹן וַחֲזוֹ וְהָא סְלֵיק תַּנְנָא דְקַרתָּא לְצֵית שְׁמַיָא וְלָא הֲוָה בְהוֹן חֵילָא לְמִערַק לְכָא וּלכָא וְעַמָא דַּאֲפַך לְמַדבְּרָא אִתחֲזַר עַל רָדְפָא :
<h3>פסוק כא</h3>
וִיהוֹשֻׁעַ וְכָל יִשׂרָאֵל חֲזוֹ אֲרֵי כְבַשׁ כָּמְנָא יָת קַרתָּא וַאֲרֵי סְלֵיק תַּנְנָא דְקַרתָּא וְתָבוּ וּמחוֹ יָת אֱנָשֵׁי עָי :
<h3>פסוק כב</h3>
וְאִלֵין נְפַקוּ מִן קַרתָּא לְקַדָּמוּתְהוֹן וַהֲווֹ לְיִשׂרָאֵל בִּמצִיעִין אִלֵין מִכָּא וְאִלֵין מִכָּא וּמחוֹ יָתְהוֹן עַד דְּלָא אִשׁתְּאַר לְהוֹן שְׁאָר וּמשֵׁיזֵיב :
<h3>פסוק כג</h3>
וְיָת מַלכָּא דְעַי אֲחַדוּ כַד חַי וְקָרִיבוּ יָתֵיהּ לְוָת יְהוֹשֻׁעַ :
<h3>פסוק כד</h3>
וַהֲוָה כַד שֵׁיצִי יִשׂרָאֵל לְקַטָלָא יָת כָּל יָתְבֵי עַי בְּחַקלָא בְּמַדבְּרָא דִּרדַפוּנוּן בֵּיהּ וְאִתקְטַלוּ כֻלְהוֹן לְפִתגָם דְּחֶרֶב עַד דִּשׁלִימוּ וְתָבוּ כָל יִשׂרָאֵל לְעָי וּמחוֹ יָתַהּ לְפִתגָם דְּחָרֶב :
<h3>פסוק כה</h3>
וַהֲווֹ כָל דְּאִתקְטַלוּ בְּיוֹמָא הַהוּא מִגְּבַר וְעַד אִתָּא תְּרֵי עֲסַר אַלפִין כֹּל אֱנָשֵׁי עָי :
<h3>פסוק כו</h3>
וִיהוֹשֻׁעַ לָא אֲתֵיב יְדֵיהּ דַּאֲרֵים בְּרֻמחָא עַד דְּגַמַר יָת כָּל יָתְבֵי עָי :
<h3>פסוק כז</h3>
לְחוֹד בְּעִירָא וַעֲדַי קַרתָּא הַהִיא בַּזוּ לְהוֹן יִשׂרָאֵל כְּפִתגָמָא דַיְיָ דְּפַקֵיד יָת יְהוֹשֻׁעַ :
<h3>פסוק כח</h3>
וְאוֹקֵיד יְהוֹשֻׁעַ יָת עָי וְשַׁויַהּ תֵּל חָרוּב לְעָלַם לְצָדוּ עַד יוֹמָא הָדֵין :
<h3>פסוק כט</h3>
וְיָת מַלכָּא דְעָי צְלַב עַל צְלִיבָא עַד עִידָּן רַמשָׁא וּכמֵיעַל שִׁמשָׁא פַקֵיד יְהוֹשֻׁעַ וְאַחִיתוּ יָת נְבֵילְתֵיהּ מִן צְלִיבָא וּרמוֹ יָתַהּ בְּמַעֲלָנָא דִּתרַע קַרתָּא וַאֲקִימוּ עֲלוֹהִי דְּגוֹר אַבנִין רַב עַד יוֹמָא הָדֵין :
<h3>פסוק ל</h3>
בְּכֵין בְּנָא יְהוֹשֻׁעַ מַדבְּחָא קֳדָם יְיָ אֱלָהָא דְיִשׂרָאֵל בְּטוּרָא דְּעֵיבָל :
<h3>פסוק לא</h3>
כְּמָא דְפַקֵיד מֹשֶׁה עַבדָּא דַיְיָ יָת בְּנֵי יִשׂרָאֵל כְּמָא דִכתִיב בִּספַר אוֹרָיְתָא דְמֹשֶׁה מַדבַּח אַבנִין שַׁלמָן דְּלָא אִתָּרַם עֲלֵיהוֹן בַּרזְלָא וְאַסִיקוּ עֲלוֹהִי עֲלָוָן קֳדָם יְיָ וְנַכִּיסוּ נִכסַת קֻדשִׁין :
<h3>פסוק לב</h3>
וּכתַב תַּמָן עַל אַבנַיָא יָת פַּרשְׁגַן אוֹרָיתָא דְמֹשֶׁה דִּכתַב קֳדָם בְּנֵי יִשׂרָאֵל :
<h3>פסוק לג</h3>
וְכָל יִשׂרָאֵל וְסָבוֹהִי וְסָרְכוֹהִי וְדַיָנוֹהִי קָיְמִין מִכָּא וּמִכָּא לַאֲרוֹנָא קֳדָם כָּהֲנַיָא לֵיוָאֵי נָטְלֵי אֲרוֹן קְיָמָא דַיְיָ גִּיוֹרָא כְּיַצִיבָא פַּלגְהוֹן לָקֳבֵיל טוּרָא דִגרִיזִין וּפַלגְהוֹן לָקֳבֵיל טוּרָא דְעֵיבָל כְּמָא דְפַקֵיד מֹשֶׁה עַבדָּא דַיְיָ לְבָרָכָא יָת עַמָא יִשׂרָאֵל בְּקַדמֵיתָא :
<h3>פסוק לד</h3>
וּבָתַר כֵּן קְרָא יָת כָּל פִּתגָמֵי אוֹרָיתָא בִּרכָן וּלוָטִין כְּכָל דִּכתִיב בְּסִפרָא דְאוֹרָיתָא :
<h3>פסוק לה</h3>
לָא הֲוָה פִתגָמָא מִכֹּל דְּפַקֵיד מֹשֶׁה דְּלָא קְרָא יְהוֹשֻׁעַ קֳדָם כָּל קְהָלָא דְיִשׂרָאֵל וּנשַׁיָא וְטַפלָא וְגִיוֹרַיָא דְּאָזְלִין בֵּינֵיהוֹן :
<h2>פרק ט</h2>
<h3>פסוק א</h3>
וַהֲוָה כַד שְׁמַעוּ כָל מַלכַיָא דִּבעִברָא דְיַרדְּנָא בְּטוּרָא וּבשָׁפֵילתָּא וּבכָל סְפַר יַמָא רַבָּא דְּלָקֳבֵיל לִבנָן חִתָּאֵי וֶאֱמוֹרָאֵי כְּנַעֲנָאֵי פְּרִזָאֵי חִוָאֵי וִיבוּסָאֵי :
<h3>פסוק ב</h3>
וְאִתכְּנַשׁוּ כַחדָּא לְאָגָחָא קְרָבָא עִם יְהוֹשׁוּעַ וְעִם יִשׂרָאֵל סִיעָא חֲדָא :
<h3>פסוק ג</h3>
וְיָתְבֵי גִבעוֹן שְׁמַעוּ יָת דַּעֲבַד יְהוֹשֻׁעַ לִירִיחוֹ וּלעָי :
<h3>פסוק ד</h3>
וַעֲבַדוּ אַף אִנוּן בְּחָכמָה וַאֲזַלוּ וְאִזדַּוַדוּ וּנסִיבוּ סַקִין בְּלַן לַחֲמָרֵיהוֹן וְזִקִין דַּחֲמַר בְּלַן וּמבֻזְעִין וּמצָרְרִין :
<h3>פסוק ה</h3>
וּמסָנַן בְּלַן וּמרֻקְעִין בְּרַגלֵיהוֹן וּכסוּתָא בַליָא עֲלֵיהוֹן וְכֹל לְחֵים זְוָדְהוֹן יָבִּישׁ הֲוָה כִיסָנִין :
<h3>פסוק ו</h3>
וַאֲזַלוּ לְוָת יְהוֹשׁוּעַ לְמַשׁרִיתָא לְגִלגָּלָא וַאֲמַרוּ לֵיהּ וּלאֱנָשׁ יִשׂרָאֵל מֵאֲרַע רַחִיקָא אֲתֵינָא וּכעַן גְּזַרוּ לַנָא קְיָם :
<h3>פסוק ז</h3>
וַאֲמַר אֱנָשׁ יִשׂרָאֵל לְחִוָאָה דִּלמָא בֵּינַנָא אַתּוּן יָתְבִין וְאֵיכְדֵין נִגזַר לְכוֹן קְיָם :
<h3>פסוק ח</h3>
וַאֲמַרוּ לִיהוֹשֻׁעַ עַבדָּך אֲנַחנָא וַאֲמַר לְהוֹן יְהוֹשֻׁעַ מַן אַתּוּן וּמנָן אֲתֵיתוֹן :
<h3>פסוק ט</h3>
וַאֲמַרוּ לֵיהּ מֵאֲרַע רַחִיקָא לַחדָּא אֲתוֹ עַבדָּך לִשׁמָא דַּיְיָ אֱלָהָך אֲרֵי שְׁמַענָא יָת שֵׁימַע גְּבוּרְתֵיהּ וְיָת כָּל דַּעֲבַד בְּמִצרָיִם :
<h3>פסוק י</h3>
וְיָת כָּל דַּעֲבַד לִתרֵין מַלכֵי אֱמוֹרָאָה דִּבעִברָא דְיַרדְּנָא לְסִיחוֹן מַלכָּא דְחֶשׁבּוֹן וּלעוֹג מַלכָּא דְמַתנַן דִּבעַשׁתָּרוֹת :
<h3>פסוק יא</h3>
וַאֲמַרוּ לַנָא סָבַנָא וְכָל יָתְבֵי אַרעַנָא לְמֵימַר סַבוּ עִמְכוֹן זְוָדִין לְאוֹרחָא וְאִיזִילוּ לְקַדָּמוּתְהוֹן וְתֵימְרוּן לְהוֹן עַבדֵּיכוֹן אֲנַחנָא וּכעַן גְּזַרוּ לַנָא קְיָם :
<h3>פסוק יב</h3>
דֵּין לַחמַנָא כִּיד חַמִים אִזדַּוַדנָא יָתֵיהּ מִבָּתַּנָא בְּיוֹם מִפְּקַנָא לְמֵיתֵי לְוָתְכוֹן וּכעַן הָא יְבֵישׁ וַהֲוָה כִּיסָנִין :
<h3>פסוק יג</h3>
וְאִלֵין זִקִין דַּחֲמַר דִּמלֵינָא כִד חֲדַתִּין וְהָא אִתבְּזַעוּ וְאִלֵין תּוֹתבַנָא וּמסָנַנָא בְּלִיאוּ מִסְגֵי אוֹרחָא לַחדָּא :
<h3>פסוק יד</h3>
וְקַבִּילוּ גֻברַיָא לְפִתגָמֵיהוֹן וְאֻלפָן מִן קֳדָם יְיָ לָא תְבַעוּ :
<h3>פסוק טו</h3>
וַעֲבַד לְהוֹן יְהוֹשֻׁעַ שְׁלָם וּגזַר לְהוֹן קְיָם לְקַיָימוּתְהוֹן וְקַיִימוּ לְהוֹן רַברְבֵי כְּנִשׁתָּא :
<h3>פסוק טז</h3>
וַהֲוָה מִסוֹף תְּלָתָא יוֹמִין בָּתַר דִּגזַרוּ לְהוֹן קְיָם וּשׁמַעוּ אֲרֵי קָרִיבִין אִנוּן לֵיהּ וּבֵינֵיהוֹן אִנוּן יָתְבִין :
<h3>פסוק יז</h3>
וּנטַלוּ בְנֵי יִשׂרָאֵל וַאֲתוֹ לְקִרוֵיהוֹן בְּיוֹמָא תְלִיתָאָה וְקִרוֵיהוֹן גִּבעוֹן וּכפִירָה וּבאֵרוֹת וְקִריַת יְעָרִים :
<h3>פסוק יח</h3>
וְלָא מְחוֹנוּן בְּנֵי יִשׂרָאֵל אֲרֵי קַיִימוּ לְהוֹן רַברְבֵי כְנִשׁתָּא בְּמֵימְרָא דַיְיָ אֱלָהָא דְיִשׂרָאֵל וְאִתרָעַמוּ כָל כְּנִישׁתָּא עַל רַברְבַיָא :
<h3>פסוק יט</h3>
וַאֲמַרוּ כָל רַברְבַיָא לְכָל כְּנִשׁתָּא אֲנַחנָא קַיֵמנָא לְהוֹן בְּמֵימְרָא דַיְיָ אֱלָהָא דְיִשׂרָאֵל וּכעַן לָא נִכּוֹל לְאַנזָקָא לְהוֹן :
<h3>פסוק כ</h3>
דָּא נַעֲבֵיד לְהוֹן וּנקַיֵים יָתְהוֹן וְלָא יְהֵי עֲלַנָא רֻגזָא עַל קְיָמָא דְּקַיֵימנָא לְהוֹן :
<h3>פסוק כא</h3>
וַאֲמַרוּ לְהוֹן רַברְבַיָא יֵיחוֹן וִיהוֹן לָקְטִין אָעִין וּמָלַן מַיָא לְכָל כְּנִשׁתָּא כְּמָא דְּמַלִילוּ לְהוֹן רַברְבַיָא :
<h3>פסוק כב</h3>
וּקרָא לְהוֹן יְהוֹשׁוּעַ וּמַלֵיל עִמְהוֹן לְמֵימַר לְמָא שַׁקַרתּוּן בַּנָא לְמֵימַר רַחִיקִין אֲנַחנָא מִנְכוֹן לַחדָּא וְאַתּוּן בֵּינַנָא יָתְבִין :
<h3>פסוק כג</h3>
וּכעַן לִיטִין אַתּוּן וְלָא יִפסְקוּן מִנְכוֹן עַבדִּין וְלָקְטֵי אָעִין וְמָלַן מַיָא לְבֵית מַקדְּשָׁא דֶאֱלָהִי :
<h3>פסוק כד</h3>
וַאֲתִיבוּ יָת יְהוֹשֻׁעַ וַאֲמַרוּ אֲרֵי חַוָאָה אִתחַוַה לְעַבדָּך יָת דְּפַקֵיד יְיָ אֱלָהָך יָת מֹשֶׁה עַבדֵּיהּ לְמִתַּן לְכוֹן יָת כָּל אַרעָא וּלשֵׁיצָאָה יָת כָּל יָתְבֵי אַרעָא מִן קֳדָמֵיכוֹן וּדחֵילנָא לַחדָּא לְנַפשָׁתַנָא מִן קֳדָמֵיכוֹן וַעֲבַדנָא יָת פִּתגָמָא הָדֵין :
<h3>פסוק כה</h3>
וּכעַן הָא אֲנַחנָא מְסִירִין בִּידָך כְּמָא דְתָקֵין וּדכָשַׁר בְּעֵינָך לְמֶעֱבַד לַנָא עֲבֵיד :
<h3>פסוק כו</h3>
וַעֲבַד לְהוֹן כֵּין וְשֵׁיזֵיב יָתְהוֹן מִיַד בְּנֵי יִשׂרָאֵל וְלָא קַטִילוּנוּן :
<h3>פסוק כז</h3>
וּמסַרִינוּן יְהוֹשֻׁעַ בְּעִידָּנָא הַהוּא לָקְטֵי אָעִין וּמָלַן מַיָא לִכנִשׁתָּא וּלמַדבְּחָא דַיְיָ עַד יוֹמָא הָדֵין לְאַתרָא דְּיִתרְעֵי :
<h2>פרק י</h2>
<h3>פסוק א</h3>
וַהֲוָה כַד שְׁמַע אֲדֹנִי צֶדֶק מַלכָּא דִירוּשׁלֶם אֲרֵי כְבַשׁ יְהוֹשֻׁעַ יָת עַי וְגַמְרַהּ כְּמָא דַעֲבַד לִירִיחוֹ וּלמַלכַּהּ כֵּן עֲבַד לְעַי וּלמַלכַּהּ וַאֲרֵי אַשׁלִימוּ יָתְבֵי גִבעוֹן עִם יִשׂרָאֵל וַהֲווֹ בֵּינֵיהוֹן :
<h3>פסוק ב</h3>
וּדחִילוּ לַחדָּא אֲרֵי קַרתָּא רַבְּתָא גִּבעוֹן כַּחֲדָא מִקִרוֵי מַלכוּתָא וַאֲרֵי הִיא רַבָּא מִן עַי וְכָל גֻּברַהָא גִּבָּרִין :
<h3>פסוק ג</h3>
וּשׁלַח אֲדֹנִי צֶדֶק מַלכָּא דִירוּשׁלֶם לְוָת הוֹהָם מַלכָּא דְחֶברוֹן וּלוָת פִּראָם מַלכָּא דְיַרמוּת וּלוָת יָפִיעַ מַלכָּא דְלָכִישׁ וּלוָת דְּבִיר מַלכָּא דְעֶגלוֹן לְמֵימַר :
<h3>פסוק ד</h3>
סַקוּ לְוָתִי וְסַעֲדוּנַנִי וְנִמחֵי יָת גִּבעוֹן אֲרֵי אַשׁלֵימַת עִם יְהוֹשֻׁעַ וְעִם בְּנֵי יִשׂרָאֵל :
<h3>פסוק ה</h3>
וְאִתכְּנִישׁוּ וּסלִיקוּ חַמשָׁה מַלכֵי אֱמוֹרָאָה מַלכָּא דִירוּשׁלֶם מַלכָּא דְחֶברוֹן מַלכָּא דְיַרמוּת מַלכָּא דְלָכִישׁ מַלכָּא דְעֶגלוֹן אִנוּן וְכָל מַשׁרְיָתְהוֹן וּשׁרוֹ עַל גִּבעוֹן וַאֲגִיחוּ קְרָבָא עֲלַהּ :
<h3>פסוק ו</h3>
וּשׁלַחוּ אֱנָשֵׁי גִבעוֹן לְוָת יְהוֹשֻׁעַ לְמַשׁרִיתָא לְגִלגָּלָא לְמֵימַר לָא תְרַשֵׁיל יְדָך מֵעַבדָּך סַק לְוָתַנָא בִפרִיעַ וּפרוֹק לַנָא וּסעוֹדנָא אֲרֵי אִתכְּנִישׁוּ עֲלַנָא כָּל מַלכֵי אֱמוֹרָאָה יָתְבֵי טוּרָא :
<h3>פסוק ז</h3>
וּסלֵיק יְהוֹשֻׁעַ מִן גִּלגָּלָא הוּא וְכָל עַמָא עָבְדֵי קְרָבָא עִמֵיהּ וְכָל גִּבָּרֵי חֵילָא :
<h3>פסוק ח</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ לָא תִדחַל מִנְהוֹן אֲרֵי בִידָך מְסַרתִּנוּן לָא יִתעַתַּד אֱנָשׁ מִנְהוֹן קֳדָמָך :
<h3>פסוק ט</h3>
וַאֲתָא לְוָתְהוֹן יְהוֹשֻׁעַ בִּתכֵּיף כָּל לֵיליָא סְלֵיק מִן גִּלגָּלָא :
<h3>פסוק י</h3>
וְשַׁגֵּישִׁנוּן יְיָ קֳדָם יִשׂרָאֵל וּמחָנוּן מַחָא רַבָּא בְּגִבעוֹן וּרדַפִינוּן בְּאוֹרַח מַסְקַנָא דְבֵית חוֹרוֹן וּמחָנוּן עַד עֲזֵקָה וְעַד מַקֵדָה :
<h3>פסוק יא</h3>
וַהֲוָה בְּמֵיפַכהוֹן מִן קֳדָם יִשׂרָאֵל אִנוּן בְּמַחֲתַנָא דְבֵית חוֹרוֹן וּמִן קֳדָם יְיָ אִתרְמַאָה עֲלֵיהוֹן אַבנִין רַברְבָן מִן שְׁמַיָא עַד דַּאֲתוֹ לַעֲזֵיקָה וּמִיתוּ סַגִּיאִין דְּמִיתוּ בְּאַבנֵי בַרדָּא מִדִּקטַלוּ בְּנֵי יִשׂרָאֵל בְּחַרבָּא :
<h3>פסוק יב</h3>
בְּכֵין שַׁבַּח יְהוֹשֻׁעַ קֳדָם יְיָ בְּיוֹמָא דִּמסַר יְיָ יָת אֱמוֹרָאָה קֳדָם בְּנֵי יִשׂרָאֵל וַאֲמַר לְעֵינֵי יִשׂרָאֵל שִׁמשָׁא בְּגִבעוֹן אוֹרֵיך וְסֵיהֲרָא בְּמֵישַׁר אַיָלוֹן :
<h3>פסוק יג</h3>
וְאוֹרֵיך שִׁמשָׁא וְסֵיהֲרָא קָם עַד דְּאִתפְּרַע עַמָא בֵית יִשׂרָאֵל מִבַּעֲלֵי דְבָבֵיהוֹן הֲלָא הִיא כְתִיבָא עַל סִפרָא דְאוֹרָיתָא וְקָם שִׁמשָׁא בְּפַלגוּת שְׁמַיָא וְלָא דְחֵיק לְמֵיעַל כְּיוֹם שְׁלִים :
<h3>פסוק יד</h3>
וְלָא הֲוָה כְּיוֹמָא הַהוּא קֳדָמוֹהִי וּבָתְרוֹהִי דְּאִתקַבַּלַת קֳדָם יְיָ צְלוֹת אֱנָשׁ אֲרֵי יְיָ בְּמֵימְרֵיהּ אֲגִיחַ קְרָבָא לְיִשׂרָאֵל :
<h3>פסוק טו</h3>
וְתָב יְהוֹשֻׁעַ וְכָל יִשׂרָאֵל עִמֵיהּ לְמַשׁרִיתָא לְגִלגָּלָא :
<h3>פסוק טז</h3>
וַאֲפַכוּ חַמשָׁה מַלכַיָא הָאִלֵין וְאִטְמַרוּ בִמעָרְתָא בְּמַקֵדָה :
<h3>פסוק יז</h3>
וְאִתחַוַה לִיהוֹשֻׁעַ לְמֵימַר אִשׁתְּכַחוּ חַמשָׁה מַלכַיָא טְמִירִין בִּמעָרְתָא בְּמַקֵדָה :
<h3>פסוק יח</h3>
וַאֲמַר יְהוֹשֻׁעַ קָרִיבוּ אַבנִין רַברְבָן לְפוּמָה דִמעָרְתָא וּמַנוֹ עֲלַהּ גֻּברִין לְמִטַרהוֹן :
<h3>פסוק יט</h3>
וְאַתּוּן לָא תְקוּמוּן רְדוּפוּ בָּתַר בַּעֲלֵי דְבָבֵיכוֹן וְתַדבְּקוּן יָתְהוֹן לָא תִשׁבְּקוּנוּנוּן לְמֵיעַל לְקִרוֵיהוֹן אֲרֵי מְסַרִנוּן יְיָ אֱלָהֲכוֹן בְּיַדכוֹן :
<h3>פסוק כ</h3>
וַהֲוָה כַד שֵׁיצִי יְהוֹשֻׁעַ וּבנֵי יִשׂרָאֵל לְמִמחֵיהוֹן מַחֲתָא רַבְּתָא לַחדָּא עַד דִּשׁלִימוּ וּמשֵׁיזְבַיָא אִשׁתֵּיזַבוּ מִנְהוֹן וְעָלוּ לְקִרוִין כְּרִיכָן :
<h3>פסוק כא</h3>
וְתָבוּ כָל עַמָא לְמַשׁרִיתָא לְוָת יְהוֹשֻׁעַ לְמַקֵדָה בִּשׁלָם לָא הֲוָה נִזקָא לִבנֵי יִשׂרָאֵל לְמִדחַק גְּבַר יָת נַפשֵׁיהּ :
<h3>פסוק כב</h3>
וַאֲמַר יְהוֹשֻׁעַ פְּתַחוּ יָת פּוּמָא דִמעָרְתָא וְאַפִּיקוּ לְוָתִי יָת חַמשָׁה מַלכַיָא הָאִלֵין מִן מְעָרְתָא :
<h3>פסוק כג</h3>
וַעֲבַדוּ כֵן וְאַפִּיקוּ לְוָתֵיהּ יָת חַמשָׁה מַלכַיָא הָאִלֵין מִן מְעָרְתָא יָת מַלכָּא דִירוּשׁלֶם יָת מַלכָּא דְחֶברוֹן יָת מַלכָּא דְיַרמוּת יָת מַלכָּא דְלָכִישׁ יָת מַלכָּא דְעֶגלוֹן :
<h3>פסוק כד</h3>
וַהֲוָה כַּד אַפִּיקוּ יָת מַלכַיָא הָאִלֵין לְוָת יְהוֹשֻׁעַ וּקרָא יְהוֹשֻׁעַ לְכָל אֱנָשׁ יִשׂרָאֵל וַאֲמַר לְשִׁלטוֹנֵי גֻּברֵי עָבְדֵי קְרָבָא דַּאֲזַלוּ עִמֵיהּ קְרַבוּ שַׁווֹ יָת רַגלֵיכוֹן עַל צַורֵי מַלכַיָא הָאִלֵין וּקרִיבוּ וְשַׁוִיאוּ יָת רַגלֵיהוֹן עַל צַורֵיהוֹן :
<h3>פסוק כה</h3>
וַאֲמַר לְהוֹן יְהוֹשֻׁעַ לָא תִדחֲלוּן וְלָא תִתַּברוּן תְּקַפוּ וְעֵילַמוּ אֲרֵי כְדֵין יַעֲבֵיד יְיָ לְכָל בַּעֲלֵי דְבָבֵיכוֹן דְּאַתּוּן מְגִיחִין קְרָבָא בְהוֹן :
<h3>פסוק כו</h3>
וּמחָנוּן יְהוֹשֻׁעַ בָּתַר כֵּן וּקטַלִנוּן וּצלַבִנוּן עַל חַמשָׁה צְלִיבִין וַהֲווֹ צְלִיבִין עַל צְלִיבַיָא עַד רַמשָׁא :
<h3>פסוק כז</h3>
וַהֲוָה לְעִדָּן מֵיעַל שִׁמשָׁא פַּקֵיד יְהוֹשֻׁעַ וְאַחִיתוּנוּן מֵעַל צְלִיבָא וּרמוֹנוּן לִמעָרְתָא דְּאִטְמַרוּ תַמָן וְשַׁוִיאוּ אַבנִין רַברְבָן עַל פּוּמָא דִמעָרְתָא עַד כְּרַן יוֹמָא הָדֵין :
<h3>פסוק כח</h3>
וְיָת מַקֵדָה כְבַשׁ יְהוֹשֻׁעַ בְּיוֹמָא הַהוּא וּמחַהּ לְפִתגָם דְּחֶרֶב וְיָת מַלכָּהּ גַּמַר יָתַהּ וְיָת כָּל נַפשָׁתָא דְּבַהּ לָא אַשׁאַר מְשֵׁיזֵיב וַעֲבַד לְמַלכָּא דְמַקֵדָה כְּמָא דַעֲבַד לְמַלכָּא דִירִיחוֹ :
<h3>פסוק כט</h3>
וַעֲבַר יְהוֹשֻׁעַ וְכָל יִשׂרָאֵל עִמֵיהּ מִמַקֵדָה לְלִבנָה וַאֲגִיחַ קְרָבָא עִם לִבנָה :
<h3>פסוק ל</h3>
וּמסַר יְיָ אַף יָתַהּ בִּידָא דְיִשׂרָאֵל וְיָת מַלכַּהּ וּמחַהּ לְפִתגָם דְּחֶרֶב וְיָת כָּל נַפשָׁתָא דְּבַהּ לָא אַשׁאַר בַּהּ מְשֵׁיזֵיב וַעֲבַד לְמַלכַּהּ כְּמָא דַעֲבַד לְמַלכָּא דִירִיחוֹ :
<h3>פסוק לא</h3>
וַעֲבַר יְהוֹשֻׁעַ וְכָל יִשׂרָאֵל עִמֵיהּ מִלִבנָה לְלָכִישׁ וּשׁרָא עֲלַהּ וַאֲגִיחַ קְרָבָא בַּהּ :
<h3>פסוק לב</h3>
וּמסַר יְיָ יָת לָכִישׁ בִּידָא דְיִשׂרָאֵל וְכַבשַׁהּ בְּיוֹמָא תִניָנָא וּמחַהּ לְפִתגָם דְּחֶרֶב וְיָת כָּל נַפשָׁתָא דְּבַהּ כְּכֹל דַּעֲבַד לְלִבנָה :
<h3>פסוק לג</h3>
בְּכֵין סְלֵיק הוֹרָם מַלכָּא דְגֶזֶר לְמִסעַד יָת לָכִישׁ וּמחָהִי יְהוֹשֻׁעַ וְיָת עַמֵיהּ עַד דְּלָא אִשׁתְּאַר לֵיהּ מְשֵׁיזֵיב :
<h3>פסוק לד</h3>
וַעֲבַר יְהוֹשֻׁעַ וְכָל יִשׂרָאֵל עִמֵיהּ מִלָכִישׁ לְעֶגלוֹן וּשׁרוֹ עֲלַהּ וַאֲגִיחוּ קְרָבָא עֲלַהּ :
<h3>פסוק לה</h3>
וְכַבשׁוּהָא בְּיוֹמָא הַהוּא וּמחוּהָא לְפִתגָם דְּחֶרֶב וְיָת כָּל נַפשָׁתָא דְבַהּ בְּיוֹמָא הַהוּא גַּמַר כְּכֹל דַּעֲבַד לְלָכִישׁ :
<h3>פסוק לו</h3>
וּסלֵיק יְהוֹשֻׁעַ וְכָל יִשׂרָאֵל עִמֵיהּ מֵעֶגלוֹן לְחֶברוֹן וַאֲגִיחוּ קְרָבָא עֲלַהּ :
<h3>פסוק לז</h3>
וְכַבשׁוּהָא וּמחוּהָא לְפִתגָם דְּחֶרֶב וְיָת מַלכַּהּ וְיָת כָּל קִרוַהָא וְיָת כָּל נַפשָׁתָא דְבַהּ לָא אַשׁאַר מְשֵׁיזֵיב כְּכֹל דַּעֲבַד לְעֶגלוֹן וְגַמַר יָתַהּ וְיָת כָּל נַפשָׁתָא דְּבַהּ :
<h3>פסוק לח</h3>
וְתָב יְהוֹשֻׁעַ וְכָל יִשׂרָאֵל עִמֵיהּ לִדבִיר וַאֲגִיחַ קְרָבָא עֲלַהּ :
<h3>פסוק לט</h3>
וְכַבשַׁהּ וְיָת מַלכַּהּ וְיָת כָּל קִרוַהָא וּמחוֹנוּן לְפִתגָם דְּחֶרֶב וְגַמַרוּ יָת כָּל נַפשָׁתָא דְבַהּ לָא אַשׁאַר מְשֵׁיזֵיב כְּמָא דַעֲבַד לְחֶברוֹן כֵּן עֲבַד לִדבִיר וּלמַלכַּהּ וּכמָא דַעֲבַד לְלִבנָה וּלמַלכַּהּ :
<h3>פסוק מ</h3>
וּמחָא יְהוֹשֻׁעַ יָת כָּל אַרעָא טוּרָא וְדָרוֹמָא וְשָׁפֵילתָּא וּמִשׁפַּך מֵרָמְתָא וְיָת כָּל מַלכֵיהוֹן לָא אַשׁאַר מְשֵׁיזֵיב וְיָת כָּל נִשׁמָא גַּמַר כְּמָא דְפַקֵיד יְיָ אֱלָהָא דְיִשׂרָאֵל :
<h3>פסוק מא</h3>
וּמחָנוּן יְהוֹשֻׁעַ מֵרְקַם גֵּיאָה וְעַד עַזָה וְיָת כָּל אֲרַע גֹּשֶׁן וְעַד גִּבעוֹן :
<h3>פסוק מב</h3>
וְיָת כָּל מַלכַיָא הָאִלֵין וְיָת אֲרַעהוֹן כְּבַשׁ יְהוֹשֻׁעַ זִמנָא חֲדָא אֲרֵי יְיָ אֱלָהָא דְיִשׂרָאֵל בְּמֵימְרֵיהּ אֲגִיחַ קְרָבָא לְיִשׂרָאֵל :
<h3>פסוק מג</h3>
וְתָב יְהוֹשֻׁעַ וְכָל יִשׂרָאֵל עִמֵיהּ לְמַשׁרִיתָא לְגִלגָּלָא :
<h2>פרק יא</h2>
<h3>פסוק א</h3>
וַהֲוָה כַּד שְׁמַע יָבִין מַלכָּא דְחָצוֹר וּשׁלַח לְוָת יוֹבָב מַלכָּא דְמָדוֹן וּלוָת מַלכָּא דְשִׁמרוֹן וּלוָת מַלכָּא דְאַכשָׁף :
<h3>פסוק ב</h3>
וּלמַלכַיָא דְּמִצִפּוּנָא בְּטוּרָא וּבמֵישְׁרָא דָּרוֹם גִּנֵיסַר וּבשָׁפֵילתָּא וּבפִלכֵי דוֹר מַערְבָא :
<h3>פסוק ג</h3>
כְּנַעֲנָאָה מִמַדנְחָא וּמִמַערְבָא וֶאֱמוֹרָאָה וְחִתָּאָה וּפרִזָאָה וִיבוּסָאָה בְּטוּרָא וְחִוָאָה שִׁפּוֹלֵי חֶרמוֹן בַּאֲרַע מִצפְּיָא :
<h3>פסוק ד</h3>
וּנפַקוּ אִנוּן וְכָל מַשׁרְיָתְהוֹן עִמְהוֹן עַם סַגִּי כְּחָלָא דְּעַל כֵּיף יַמָא לִסגֵי וְסוּסָוָן וּרתִיכִּין סַגִּי לַחדָּא :
<h3>פסוק ה</h3>
וְאִזדָּמַנוּ כֹּל מַלכַיָא הָאִלֵין וַאֲתוֹ וּשׁרוֹ כַחדָּא עַל מֵי מֵרוֹם לְאָגָחָא קְרָבָא עִם יִשׂרָאֵל :
<h3>פסוק ו</h3>
וַאֲמַר יְיָ לִיהוֹשֻׁעַ לָא תִדחַל מִן קֳדָמֵיהוֹן אֲרֵי מְחַר כְּעִדָּנָא הָדֵין אֲנָא מָסַר יָת כֻּלְהוֹן קְטִילִין קֳדָם יִשׂרָאֵל יָת סוּסָוָתְהוֹן תְּעַקַר וְיָת רְתִכֵּיהוֹן תּוֹקֵיד בְּנוּרָא :
<h3>פסוק ז</h3>
וַאֲתָא יְהוֹשֻׁעַ וְכָל עַמָא עָבְדֵי קְרָבָא עִמֵיהּ עֲלֵיהוֹן וְאִנוּן שָׁרַן עַל מֵי מֵרוֹם בִּתכֵּיף וּנפַלוּ בְּהוֹן :
<h3>פסוק ח</h3>
וּמסַרִנוּן יְיָ בִּידָא דְיִשׂרָאֵל וּמחוֹנוּן וּרדַפוּנוּן עַד צִידוֹן רַבְּתָא וְעַד חַרצֵי מַיָא וְעַד בִּקעַת מִצפְּיָא מַדנְחָאָה וּמחוֹנוּן עַד דְּלָא אִשׁתְּאַר לְהוֹן מְשֵׁיזֵיב :
<h3>פסוק ט</h3>
וַעֲבַד לְהוֹן יְהוֹשֻׁעַ כְּמָא דַאֲמַר לֵיהּ יְיָ יָת סוּסָוָתְהוֹן עַקַר וְיָת רְתִכֵּיהוֹן אוֹקֵיד בְּנוּרָא :
<h3>פסוק י</h3>
וְתָב יְהוֹשֻׁעַ בְּעִדָּנָא הַהוּא וּכבַשׁ יָת חָצוֹר וְיָת מַלכַּהּ קְטַל בְּחַרבָּא אֲרֵי חָצוֹר מִלְקַדמִין הִיא רֵישׁ לְכָל מַלכְוָתָא הָאִלֵין :
<h3>פסוק יא</h3>
וּמחוֹ יָת כָּל נַפשָׁתָא דְבַהּ לְפִתגָם דְּחֶרֶב גְּמֵירָא לָא אַשׁאַר כָּל נִשׁמָא וְיָת חָצוֹר אוֹקֵיד בְּנוּרָא :
<h3>פסוק יב</h3>
וְיָת כָּל קִרוֵי מַלכַיָא הָאִלֵין וְיָת כָּל מַלכֵיהוֹן כְּבַשׁ יְהוֹשֻׁעַ וּמחָנוּן לְפִתגָם דְּחֶרֶב גַּמַר יָתְהוֹן כְּמָא דְפַקֵיד מֹשֶׁה עַבדָּא דַיְיָ :
<h3>פסוק יג</h3>
לְחוֹד כָּל קִרוַיָא דְּקָיְמִין עַל תֻּקפְּהוֹן לָא אוֹקֵידִנוּן יִשׂרָאֵל אֱלָהֵין יָת חָצוֹר בִּלחוֹדַהּ אוֹקֵיד יְהוֹשֻׁעַ :
<h3>פסוק יד</h3>
וְכֹל עֲדַי קִרוַיָא הָאִלֵין וּבעִירָא בַּזוּ לְהוֹן בְּנֵי יִשׂרָאֵל לְחוֹד יָת כָּל אֱנָשָׁא מְחוֹ לְפִתגָם דְּחֶרֶב עַד דְּשֵׁיצִיאוּ יָתְהוֹן לָא אַשׁאַרוּ כָּל נִשׁמָא :
<h3>פסוק טו</h3>
כְּמָא דְפַקֵיד יְיָ יָת מֹשֶׁה עַבדֵּיהּ כֵּן פַּקֵיד מֹשֶׁה יָת יְהוֹשֻׁעַ וְכֵן עֲבַד יְהוֹשֻׁעַ לָא בַטֵיל פִּתגָמָא מִכֹּל דְּפַקֵיד יְיָ יָת מֹשֶׁה :
<h3>פסוק טז</h3>
וְאַחסֵין יְהוֹשֻׁעַ יָת כָּל אַרעָא הָדָא טוּרָא וְיָת כָּל דָּרוֹמָא וְיָת כָּל אֲרַע גֹּשֶׁן וְיָת שָׁפֵילתָּא וְיָת מֵישְׁרָא וְיָת טוּרָא דְיִשׂרָאֵל וְשָׁפֵילתֵּיהּ :
<h3>פסוק יז</h3>
מִן טוּרָא פְלִיגָא דְּסָלֵיק לְשֵׁעִיר וְעַד מֵישַׁר גָּד בְּבִקעַת לִבנָן שִׁפּוֹלֵי טוּרָא דְחֶרְמוֹן וְיָת כָּל מַלכֵיהוֹן כְּבַשׁ וּמחָנוּן וּקטַלִנוּן :
<h3>פסוק יח</h3>
יוֹמִין סַגִּיאִין עֲבַד יְהוֹשֻׁעַ עִם כָּל מַלכַיָא הָאִלֵין קְרָבָא :
<h3>פסוק יט</h3>
לָא הֲוָת קַרתָּא דְּאַשׁלֵימַת עִם בְּנֵי יִשׂרָאֵל אֱלָהֵין חִוָאֵי יָתְבֵי גִבעוֹן יָת כּוֹלָא נְסִיבוּ בִקרָבָא :
<h3>פסוק כ</h3>
אֲרֵי מִן קֳדָם יְיָ הֲוָת לְתַקָפָא יָת לִבְּהוֹן לְסַדָּרָא קְרָבָא עִם יִשׂרָאֵל בְּדִיל לְגַמָרֻתְהוֹן בְּדִיל דְּלָא יְהוֹן עֲלֵיהוֹן רַחֲמִין אֲרֵי בְּדִיל לְשֵׁיצָיוּתְהוֹן כְּמָא דְּפַקֵיד יְיָ יָת מֹשֶׁה :
<h3>פסוק כא</h3>
וַאֲתָא יְהוֹשֻׁעַ בְּעִדָּנָא הַהוּא וְשֵׁיצִי יָת גִּבָּרַיָא מִן טוּרָא מִן חֶברוֹן מִן דְּבִיר מִן עֲנָב וּמִכָּל טוּר יְהוּדָה וּמִכָּל טוּרָא דְיִשׂרָאֵל עִם קִרוֵיהוֹן גַּמַרִנוּן יְהוֹשֻׁעַ :
<h3>פסוק כב</h3>
לָא אִשׁתְּאַרוּ גִבָּרַיָא בַּאֲרַע בְּנֵי יִשׂרָאֵל לְחוֹד בְּעַזָה בְּגַת וּבאַשׁדּוֹד אִשׁתְּאַרוּ :
<h3>פסוק כג</h3>
וּנסֵיב יְהוֹשֻׁעַ יָת כָּל אַרעָא כְּכֹל דְּמַלֵיל יְיָ עִם מֹשֶׁה וְיַהבַהּ יְהוֹשֻׁעַ לְאַחסָנָא לְיִשׂרָאֵל כְּפֻלגָוָתְהוֹן לְשִׁבטֵיהוֹן וְאַרעָא שְׁדוֹכַת מִלְמֶעֱבַד קְרָבָא :
<h2>פרק יב</h2>
<h3>פסוק א</h3>
וְאִלֵין מַלכֵי אַרעָא דִּמחוֹ בְנֵי יִשׂרָאֵל וִירִיתוּ יָת אֲרַעהוֹן בְּעִברָא דְיַרדְּנָא מַדנַח שִׁמשָׁא מִנַחלָא דְאַרנוֹן עַד טוּרָא דְחֶרְמוֹן וְכָל מֵישְׁרָא מַדנְחָא :
<h3>פסוק ב</h3>
סִיחוֹן מַלכָּא דֶאֱמוֹרָאָה דְּיָתֵיב בְּחֶשׁבּוֹן שַׁלִיט מֵעֲרֹעֵר דְּעַל כֵּיף נַחלָא דְאַרנוֹן וְגוֹ נַחלָא וּפַלגוּת גִּלעָד וְעַד יֻבקָא נַחלָא תְּחוּמָא דִּבנֵי עַמוֹן :
<h3>פסוק ג</h3>
וּמֵישְׁרָא עַד יַם גִּנֵיסַר מַדנְחָא וְעַד יַמָא דְמֵישְׁרָא יַמָא דְמִלחָא מַדנְחָא אוֹרַח בֵּית יְשִׁימוֹת וּמִדָּרוֹמָא תְּחוֹת מִשׁפַּך מֵי רָמְתָא :
<h3>פסוק ד</h3>
וּתחוּם עוֹג מַלכָּא דְמַתנַן מִשְׁאָר גִּבָּרַיָא דְּיָתֵיב בְּעַשׁתָּרוֹת וּבאֶדרֶעִי :
<h3>פסוק ה</h3>
וְשַׁלִיט בְּטוּרָא דְחֶרְמוֹן וּבסַלכָה וּבכָל מַתנַן עַד תְּחוּם גְּשׁוּרָאָה וְאֲפֵיקֵירוֹס וּפַלגוּת אֲרַע גִּלעָד תְּחוּם סִיחוֹן מַלכָּא דְחֶשׁבּוֹן :
<h3>פסוק ו</h3>
מֹשֶׁה עַבדָּא דַיְיָ וּבנֵי יִשׂרָאֵל מְחוֹנוּן וְיַהבַּהּ מֹשֶׁה עַבדָּא דַיְיָ יְרוּתָּא לְשֵׁיבַט רְאוּבֵן וּלשֵׁבַט גָּד וּלפַלגוּת שִׁבטָא דִמנַשֶׁה :
<h3>פסוק ז</h3>
וְאִלֵין מַלכֵי אַרעָא דִּמחָא יְהוֹשֻׁעַ וּבנֵי יִשׂרָאֵל בְּעִברָא דְיַרדְּנָא מַערְבָא מִמֵישַׁר גָּד בְּבִקעַת לִבנָן וְעַד טוּרָא פְלִיגָא דְּסָלֵיק לְשֵׁעִיר וְיַהבַּהּ יְהוֹשֻׁעַ לְשִׁבטַיָא דְיִשׂרָאֵל יְרוּתָּא כְּפֻלגָוָתְהוֹן :
<h3>פסוק ח</h3>
בְּטוּרָא וּבשָׁפֵילתָּא וּבמֵישְׁרָא וּבמִשׁפַּך מֵי רָמְתָא וּבמַדבְּרָא וּבדָרוֹמָא חִתָּאֵי וֶאֱמוֹרָאֵי וּכנַעֲנָאֵי פְּרִזָאֵי חִוָאֵי וִיבוּסָאֵי :
<h3>פסוק ט</h3>
מַלכָּא דִירִיחוֹ חַד מַלכָּא דְעַי דְּבִסטַר בֵּית אֵל חַד :
<h3>פסוק י</h3>
מַלכָּא דִירוּשׁלֶם חַד מַלכָּא דְחֶברוֹן חַד :
<h3>פסוק יא</h3>
מַלכָּא דְיַרמוּת חַד מַלכָּא דְלָכִישׁ חַד :
<h3>פסוק יב</h3>
מַלכָּא דְעֶגלוֹן חַד מַלכָּא דְגֶזֶר חַד :
<h3>פסוק יג</h3>
מַלכָּא דִדבִיר חַד מַלכָּא דְגֶדֶר חַד :
<h3>פסוק יד</h3>
מַלכָּא דְחָרמָה חַד מַלכָּא דַעֲרָד חַד :
<h3>פסוק טו</h3>
מַלכָּא דְלִבנָה חַד מַלכָּא דַעֲדֻלָם חַד :
<h3>פסוק טז</h3>
מַלכָּא דְמַקֵדָה חַד מַלכָּא דְבֵית אֵל חַד :
<h3>פסוק יז</h3>
מַלכָּא דְתַפּוּחַ חַד מַלכָּא דְחֵפֶר חַד :
<h3>פסוק יח</h3>
מַלכָּא דַאֲפֵק חַד מַלכָּא דִלשָׁרוֹן חַד :
<h3>פסוק יט</h3>
מַלכָּא דְמָדוֹן חַד מַלכָּא דְחָצוֹר חַד :
<h3>פסוק כ</h3>
מַלכָּא דְשִׁמרוֹן מְרוֹן חַד מַלכָּא דְאַכשָׁף חַד :
<h3>פסוק כא</h3>
מַלכָּא דְתַעֲנַך חַד מַלכָּא דִמגִדּוֹ חַד :
<h3>פסוק כב</h3>
מַלכָּא דְקֶדֶשׁ חַד מַלכָּא דְיָקנְעָם לְכַרמְלָא חַד :
<h3>פסוק כג</h3>
מַלכָּא דְדוֹר לְפִלכֵי דוֹר חַד מַלכָּא דְעַמְמֵי לְגִלגָּלָא חַד :
<h3>פסוק כד</h3>
מַלכָּא דְתִרצָה חַד כָּל מַלכַיָא תְּלָתִין וְחַד :
<h2>פרק יג</h2>
<h3>פסוק א</h3>
וִיהוֹשֻׁעַ סִיב עָל בְּיוֹמִין וַאֲמַר יְיָ לֵיהּ אַתְּ סַבתָּא עַלתָּא בְיוֹמִין וְאַרעָא אִשׁתְּאַרַת סַגִּיאָה לַחדָּא לְמֵירְתַהּ :
<h3>פסוק ב</h3>
דָּא אַרעָא דְּאִשׁתְּאַרַת כָּל תְּחוּמֵי פְלִשׁתָּאֵי וְכָל גְּשׁוּרָאֵי :
<h3>פסוק ג</h3>
מִן שִׁיחוֹר דְּעַל אַפֵּי מִצרַיִם וְעַד תְּחוּם עֶקרוֹן צִפּוּנָא עַל אֲרַע כְּנַעֲנָאָה מִתחַשׁבָא חַמשָׁה טוּרנֵי פְלִשׁתָּאֵי עַזָתָאֵי וְאַשׁדּוֹדָאֵי אַשׁקְלוֹנָאֵי גִתָּאֵי וְעֶקרוֹנָאֵי וְעַוָאֵי :
<h3>פסוק ד</h3>
מִדָּרוֹמָא כָּל אֲרַע כְּנַעֲנָאֵי וּמעָרְתָא דִּלצִידוֹנָאֵי עַד אֲפֵק עַד תְּחוּם אֱמוֹרָאָה :
<h3>פסוק ה</h3>
וְאַרעָא גִבלִי וְכָל לִבנָן מַדנַח שִׁמשָׁא מִמֵישַׁר גָּד שִׁפּוֹלֵי טוּרָא דְחֶרְמוֹן עַד מַעֲלַנָא דַחֲמָת :
<h3>פסוק ו</h3>
כָּל יָתְבֵי טוּרָא מִן לִבנָן עַד חַרצֵי מַיָא כָּל צִידוֹנָאֵי בְּמֵימְרִי אֲתָרֵיכִנוּן מִן קֳדָם בְּנֵי יִשׂרָאֵל לְחוֹד פַּלֵיגהָא לְיִשׂרָאֵל לְאַחסָנָא כְּמָא דְּפַקֵידתָּך :
<h3>פסוק ז</h3>
וּכעַן פַּלֵיג יָת אַרעָא הָדָא בְּאַחסָנָא לְתִשׁעָה שִׁבטִין וּפַלגוּת שִׁבטָא דִמנַשֶׁה :
<h3>פסוק ח</h3>
עִמֵיהּ שֵׁבַט רְאוּבֵן וְשֵׁבַט גָּד קַבִּילוּ אַחסָנַתהוֹן דִּיהַב לְהוֹן מֹשֶׁה בְּעִברָא דְיַרדְּנָא מַדנְחָא כְּמָא דִיהַב לְהוֹן מֹשֶׁה עַבדָּא דַיְיָ :
<h3>פסוק ט</h3>
מֵעֲרֹעֵר דְּעַל כֵּיף נַחלָא דְאַרנוֹן וְקַרתָּא דִבגוֹ נַחלָא וְכָל מֵישְׁרָא מֵידְבָא עַד דִּיבוֹן :
<h3>פסוק י</h3>
וְכֹל קִרוֵי סִיחוֹן מַלכָּא אֱמוֹרָאָה דִּמלַך בְּחֶשׁבּוֹן עַד תְּחוּם בְּנֵי עַמוֹן :
<h3>פסוק יא</h3>
וַאֲרַע גִּלעָד וּתחוּם גְּשׁוּרָאָה וַאֲפֵיקֵירוֹס וְכָל טוּרָא דְחֶרְמוֹן וְכָל מַתנַן עַד סַלכָה :
<h3>פסוק יב</h3>
כָּל מַלכוּתֵיהּ דְּעוֹג בְּמַתנַן דִּמלַך בְּעַשׁתָּרוֹת וּבאֶדרֶעִי הוּא אִשׁתְּאַר מִשְׁאָר גִּבָּרַיָא וּמחָנוּן מֹשֶׁה וְתָרֵיכִנוּן :
<h3>פסוק יג</h3>
וְלָא תָרִיכוּ בְּנֵי יִשׂרָאֵל יָת גְּשׁוּרָאָה וְיָת אֲפֵיקֵירוֹס וִיתֵיב גְּשׁוּרָאָה וַאֲפֵיקֵירוֹס בְּגוֹ יִשׂרָאֵל עַד יוֹמָא הָדֵין :
<h3>פסוק יד</h3>
לְחוֹד לְשִׁבטָא דְלֵוִי לָא יְהַב אַחסָנָא קֻרבָּנַיָא דַיְיָ אֱלָהָא דְיִשׂרָאֵל אִנוּן אַחסָנְתֵיהּ כְּמָא דְּמַלֵיל לֵיהּ :
<h3>פסוק טו</h3>
וִיהַב מֹשֶׁה לְשִׁבטָא דִבנֵי רְאוּבֵן לְזַרעֲיָתְהוֹן :
<h3>פסוק טז</h3>
וַהֲוָה לְהוֹן תְּחוּמָא מֵעֲרוֹעֵר דְּעַל כֵּיף נַחלָא דְאַרנוֹן וְקַרתָּא דִבגוֹ נַחלָא וְכָל מֵישְׁרָא עַל מֵידְבָא :
<h3>פסוק יז</h3>
חֶשׁבּוֹן וְכָל קִרוַהָא דִּבמֵישְׁרָא דִּיבוֹן וּבָמוֹת בַּעַל וּבֵית בַּעַל מְעוֹן :
<h3>פסוק יח</h3>
וְיַהַץ וּקדֵמוֹת וְמֵפָעַת :
<h3>פסוק יט</h3>
וְקִריָתַיִם וְשִׁבמָה וְצֶרֶת שַׁחַר בְּטוּר מֵישְׁרָא :
<h3>פסוק כ</h3>
וּבֵית פְּעוֹר וּמִשׁפַּך מֵרָמְתָא וּבֵית יְשִׁימוֹת :
<h3>פסוק כא</h3>
וְכֹל קִרוֵי מֵישְׁרָא וְכָל מַלכוּת סִיחוֹן מַלכָּא אֱמוֹרָאָה דִּמלַך בְּחֶשׁבּוֹן דִּמחָא מֹשֶׁה יָתֵיהּ וְיָת רַברְבֵי מִדיָן יָת אֲוִי וְיָת רֶקֶם וְיָת צוּר וְיָת חוּר וְיָת רֶבַע רַברְבֵי סִיחוֹן יָתְבֵי אַרעָא :
<h3>פסוק כב</h3>
וְיָת בִּלעָם בַּר בְּעוֹר קָסוֹמָא קְטַלוּ בְנֵי יִשׂרָאֵל בְּחַרבָּא עַל קְטִילֵיהוֹן :
<h3>פסוק כג</h3>
וַהֲוָה תְּחוּם בְּנֵי רְאוּבֵן יַרדְּנָא וּתחוּמֵיהּ דָּא אַחסָנַת בְּנֵי רְאוּבֵן לְזַרעֲיָתְהוֹן קִרוַיָא וּפַצחֵיהוֹן :
<h3>פסוק כד</h3>
וִיהַב מֹשֶׁה לְשִׁבטָא דְגָד לִבנֵי גָד לְזַרעֲיָתְהוֹן :
<h3>פסוק כה</h3>
וַהֲוָה לְהוֹן תְּחוּמָא יַעזֵר וְכָל קִרוֵי גִלעָד וּפַלגוּת אֲרַע בְּנֵי עַמוֹן עַד עֲרוֹעֵר דְּעַל אַפֵּי רַבָּה :
<h3>פסוק כו</h3>
וּמֵחֶשׁבּוֹן עַד רָמַת מִצפְּיָא וּבטוֹנִים וּמִמַחֲנַיִם עַד תְּחוּם לִדבִיר :
<h3>פסוק כז</h3>
וּבמֵישְׁרָא בֵּית הָרָם וּבֵית נִמרָה וְסֻכּוֹת וְצִפּוּנָא שְׁאָר מַלכוּת סִיחוֹן מַלכָּא דְחֶשׁבּוֹן יַרדְּנָא וּתחוּמֵיהּ עַד סְיָפֵי יַם גִּנֵיסַר עִברָא דְיַרדְּנָא מַדנְחָא :
<h3>פסוק כח</h3>
דָּא אַחסָנַת בְּנֵי גָד לְזַרעֲיָתְהוֹן קִרוַיָא וּפַצחֵיהוֹן :
<h3>פסוק כט</h3>
וִיהַב מֹשֶׁה לְפַלגוּת שִׁבטָא דִמנַשֶׁה וַהֲוָה לְפַלגוּת שִׁבטָא דִבנֵי מְנַשֶׁה לְזַרעֲיָתְהוֹן :
<h3>פסוק ל</h3>
וַהֲוָה תְחוּמְהוֹן מִמַחֲנַיִם כָּל מַתנַן כָּל מַלכוּתֵיהּ דְּעוֹג מַלכָּא דִמַתנַן וְכָל כַּפרָנֵי יָאִיר דִּבמַתנַן שִׁתִּין קִרוִין :
<h3>פסוק לא</h3>
וּפַלגוּת אֲרַע גִּלעָד וְעַשׁתָּרוֹת וְאֶדרֶעִי קִרוֵי מַלכוּתֵיהּ דְּעוֹג בְּמַתנַן לִבנֵי מָכִיר בַּר מְנַשֶׁה לְפַלגוּת בְּנֵי מָכִיר לְזַרעֲיָתְהוֹן :
<h3>פסוק לב</h3>
אִלֵין דְּאַחסֵין מֹשֶׁה בְּמֵישְׁרַיָא דְמוֹאָב מֵעִברָא לְיַרדְּנָא דִירִיחוֹ מַדנְחָא :
<h3>פסוק לג</h3>
וּלשִׁבטָא דְּלֵוִי לָא יְהַב מֹשֶׁה אַחסָנָא מַתְּנָן דִּיהַב לֵיהּ יְיָ אֱלָהָא דְיִשׂרָאֵל אִנִין אַחסָנַתהוֹן כְּמָא דְמַלֵיל לְהוֹן :
<h2>פרק יד</h2>
<h3>פסוק א</h3>
וְאִלֵין דְּאַחסִינוּ בְנֵי יִשׂרָאֵל בְּאַרעָא דִכנָעַן דְּאַחסִינוּ יָתְהוֹן אֶלעָזָר כָּהֲנָא וִיהוֹשֻׁעַ בַּר נוּן וְרֵישֵׁי אֲבָהָת שִׁבטַיָא לִבנֵי יִשׂרָאֵל :
<h3>פסוק ב</h3>
בְּעַדבָּא אִתפְּלַגַת לְהוֹן אַחסָנַתהוֹן כְּמָא דְפַקֵיד יְיָ בִּידָא דְמֹשֶׁה לְתִשׁעָה שִׁבטִין וּפַלגוּת שִׁבטָא :
<h3>פסוק ג</h3>
אֲרֵי יְהַב מֹשֶׁה אַחסָנַת תְּרֵין שִׁבטִין וּפַלגוּת שִׁבטָא מֵעִברָא לְיַרדְּנָא וּללֵוָאֵי לָא יְהַב אַחסָנָא בֵּינֵיהוֹן :
<h3>פסוק ד</h3>
אֲרֵי הֲווֹ בְנֵי יוֹסֵף תְּרֵין שִׁבטִין מְנַשֶׁה וְאֶפרָיִם וְלָא יְהַבוּ חוּלָק לְלֵיוָאֵי בְּאַרעָא אֱלָהֵין קִרוִין לְמִתַּב וְרַוחֵיהוֹן לִבעִירְהוֹן וּלקִניָנְהוֹן :
<h3>פסוק ה</h3>
כְּמָא דְפַקֵיד יְיָ יָת מֹשֶׁה כֵּן עֲבַדוּ בְּנֵי יִשׂרָאֵל וּפַלִיגוּ יָת אַרעָא :
<h3>פסוק ו</h3>
וּקרִיבוּ בְנֵי יְהוּדָה לְוָת יְהוֹשֻׁעַ בְּגִלגָּלָא וַאֲמַר לֵיהּ כָּלֵב בַּר יְפֻנֶה קְנִזָאָה אַתְּ יָדַעתְּ יָת פִּתגָמָא דְמַלֵיל יְיָ עִם מֹשֶׁה נְבִיָא דַיְיָ עַל עֵיסַק דִּילִי וְעַל עֵיסַק דִּילָך בִּרקַם גֵּאָה :
<h3>פסוק ז</h3>
בַּר אַרבְּעִין שְׁנִין אֲנָא כַּד שְׁלַח מֹשֶׁה עַבדָּא דַיְיָ יָתִי מֵרְקַם גֵּיאָה לְאַלָלָא יָת אַרעָא וַאֲתֵיבִית יָתֵיהּ פִּתגָמָא כְּמָא דַּהֲוָה עִם לִבִּי :
<h3>פסוק ח</h3>
וְאַחַי דִּסלִיקוּ עִמִי תְּבַרוּ יָת לִבָּא דְעַמָא וַאֲנָא אַשׁלֵימִית בָּתַר דַּחלְתָא דַיְיָ אֱלָהִי :
<h3>פסוק ט</h3>
וְקַיֵים מֹשֶׁה בְּיוֹמָא הַהוּא לְמֵימַר אִם לָא אַרעָא דִּדרֵיכַת פַּרסַת רַגלָך בַּהּ דִּילָך תְּהֵי לְאַחסָנָא וְדִבנָך עַד עָלמָא אֲרֵי אַשׁלֵימתָּא בָּתַר דַּחלְתָא דַיְיָ אֱלָהִי :
<h3>פסוק י</h3>
וּכעַן הָא קַיֵים יְיָ יָתִי כְּמָא דְמַלֵיל דְּנָן אַרבְּעִין וַחֲמֵישׁ שְׁנִין מֵעִדָּן דְּמַלֵיל יְיָ יָת פִּתגָמָא הָדֵין עִם מֹשֶׁה דַּאֲזַל יִשׂרָאֵל בְּמַדבְּרָא וּכעַן הָא אֲנָא יוֹמָא דֵין בַּר תְּמָנַן וַחֲמֵישׁ שְׁנִין :
<h3>פסוק יא</h3>
עַד כְּעַן אֲנָא יוֹמָא דֵין תַּקִיף כִּד בְּיוֹמָא דִשׁלַח יָתִי מֹשֶׁה כְּחֵילִי דִבכֵין וּכחֵילִי דִכעַן לְאָגָחָא קְרָבָא וּלמִפַּק וּלמֵיעַל :
<h3>פסוק יב</h3>
וּכעַן הַב לִי יָת טוּרָא הָדֵין דְּמַלֵיל יְיָ בְּיוֹמָא הַהוּא אֲרֵי אַתְּ שְׁמַעתָּא בְיוֹמָא הַהוּא אֲרֵי גִבָּרִין תַּמָן וְקִרוִין רַברְבָן וּכרִיכָן מָא אִם יְהֵי מֵימְרָא דַיְיָ בְּסַעֲדִי וְאוֹרְתִנוּן כְּמָא דְמַלֵיל יְיָ :
<h3>פסוק יג</h3>
וּבָרְכֵיהּ יְהוֹשֻׁעַ וִיהַב יָת חֶברוֹן לְכָלֵב בַּר יְפֻנֶה לְאַחסָנָא :
<h3>פסוק יד</h3>
עַל כֵּן הֲוָת חֶברוֹן לְכָלֵב בַּר יְפֻנֶה קְנִזָאָה לְאַחסָנָא עַד יוֹמָא הָדֵין חֲלָף דְּאַשׁלֵים בָּתַר דַּחלְתָא דַיְיָ אֱלָהָא דְיִשׂרָאֵל :
<h3>פסוק טו</h3>
וְשׁוּם חֶברוֹן מִלְקַדמִין קִריַת אַרבַּע אֱנָשׁ רַב בְּגִבָּרַיָא הוּא וְאַרעָא שְׁדוֹכַת מִלְמֶעֱבַד קְרָבָא :
<h2>פרק טו</h2>
<h3>פסוק א</h3>
וַהֲוָה עַדבָּא לְשִׁבטָא דִּבנֵי יְהוּדָה לְזַרעֲיָתְהוֹן לִתחוּם אֱדוֹם מַדבְּרָא דְצִין דָּרוֹמָא מִסְיָפֵי דָרוֹמָא :
<h3>פסוק ב</h3>
וַהֲוָה לְהוֹן תְּחוּם דָּרוֹמָא מִסְיָפֵי יַמָא דְמִלחָא מִן כֵּיפָא דְּמִתפְּנֵי לְדָרוֹמָא :
<h3>פסוק ג</h3>
וְנָפֵיק לְמִדָּרוֹמָא לְמַסְקַנָא דְעַקרַבִּין וְעָבַר לְצִין וְסָלֵיק מִדָּרוֹמָא לִרקַם גֵּיאָה וְעָבַר לְחֶצרוֹן וְסָלֵיק לְאַדָּר וּמִסתְּחַר לְקַרקָעָה :
<h3>פסוק ד</h3>
וְעָבַר לְעַצמוֹן וְנָפֵיק לְנַחלָא דְמִצרַיִם וְהָוַן מַפְּקָנוֹהִי דִתחוּמָא לְיַמָא דֵּין יְהֵי לְכוֹן תְּחוּם דָּרוֹמָא :
<h3>פסוק ה</h3>
וּתחוּם קִדּוּמָא יַמָא דְמִלחָא עַד סְיָפֵי יַרדְּנָא וּתחוּמָא לְרוּחַ צִפּוּנָא מִכֵּיף יַמָא מִסְיָפֵי יַרדְּנָא :
<h3>פסוק ו</h3>
וְסָלֵיק תְּחוּמָא לְבֵית חָגלָה וְעָבַר מִצִפּוּנָא לְבֵית מֵישְׁרָא וְסָלֵיק תְּחוּמָא לְאֶבֶן בֹּהַן בַּר רְאוּבֵן :
<h3>פסוק ז</h3>
וְסָלֵיק תְּחוּמָא לִדבִיר מִמֵישַׁר עָכוֹר וְצִפּוּנָא מִתפְּנֵי לְגִלגָּלָא דְּלָקֳבֵיל מַסְקַנָא דַאֲדֻמִים דְּמִדָּרוֹם לְנַחלָא וְעָבַר תְּחוּמָא לְמֵי עֵין שֶׁמֶשׁ וְהָוַן מַפְּקָנוֹהִי לְעֵין קָצְרָא :
<h3>פסוק ח</h3>
וְסָלֵיק תְּחוּמָא לְחִלַת בַּר הִנוֹם דִּלעֵיבַר יְבוּס מִדָּרוֹמָא הִיא יְרוּשׁלֶם וְסָלֵיק תְּחוּמָא לְרֵישׁ טוּרָא דְּעַל אַפֵּי חִלַת הִנוֹם מַערְבָא דְּבִסיָפֵי מֵישַׁר גִּבָּרַיָא צִפּוּנָא :
<h3>פסוק ט</h3>
וְתָאַר תְּחוּמָא מֵרֵישׁ טוּרָא לְמַבּוּעַ מֵי נֶפתּוֹחַ וְנָפֵיק לְקִרוֵי טוּרָא דְעֶפרוֹן וְתָאַר תְּחוּמָא לְבַעֲלָה הִיא קִריַת יְעָרִים :
<h3>פסוק י</h3>
וּמִסתְּחַר תְּחוּמָא מִבַּעֲלָה לְיַמָא לְטוּרָא דְשֵׁעִיר וְעָבַר לְעֵבַיר טוּר יְעָרִים מִצִפּוּנָא הִיא כְסָלוֹן וְנָחֵית לְבֵית שֶׁמֶשׁ וְעָבַר לְתִמנָת :
<h3>פסוק יא</h3>
וְנָפֵיק תְּחוּמָא לְעֵיבַר עֶקרוֹן לְצִפּוּנָא וְתָאַר תְּחוּמָא לְשִׁכְּרוֹן וְעָבַר לְטוּר בַּעֲלָה וְנָפֵיק לְיַבנְאֵל וְהָוַן מַפְּקָנוֹהִי דִתחוּמָא לְיַמָא :
<h3>פסוק יב</h3>
וּתחוּם מַערְבָא יַמָא רַבָּא וּתחוּמֵיהּ דֵּין תְּחוּם בְּנֵי יְהוּדָה סְחוֹר סְחוֹר לְזַרעֲיָתְהוֹן :
<h3>פסוק יג</h3>
וּלכָלֵב בַּר יְפֻנֶה יְהַב חוּלָק בְּגוֹ בְנֵי יְהוּדָה עַל מֵימְרָא דַיְיָ לִיהוֹשֻׁעַ יָת קִריַת אַרבַּע אֲבוּהוֹן דְּגִבָּרַיָא הִיא חֶברוֹן :
<h3>פסוק יד</h3>
וְתָרֵיך מִתַּמָן כָּלֵב יָת תְּלָתָה בְּנֵי גִבָּרַיָא יָת שֵׁשַׁי וְיָת אֲחִימַן וְיָת תַּלמַי בְּנֵי גִּבָּרַיָא :
<h3>פסוק טו</h3>
וּסלֵיק מִתַּמָן לְוָת יָתְבֵי דְּבִיר וְשׁוּם דְּבִיר דְּמִלְקַדמִין קִריַת אַרכֵי :
<h3>פסוק טז</h3>
וַאֲמַר כָּלֵב דְּיִמחֵי יָת קִריַת אַרכֵי וְיִכבְּשִׁנַהּ וְאֶתֵּין לֵיהּ יָת עַכסָה בְרַתִּי לְאִתּוּ :
<h3>פסוק יז</h3>
וְכַבשַׁהּ עָתנִיאֵל בַּר קְנַז אֲחוּהִי דְכָלֵב וִיהַב לֵיהּ יָת עַכסָה בְרַתֵּיהּ לְאִתּוּ :
<h3>פסוק יח</h3>
וַהֲוָה בְּמֵיעֲלַהּ וּמלַכתֵּיהּ לְמִשׁאַל מִן אֲבוּהָא אַחסָנְתָא וְאִתרְכֵינַת מֵעַל חֲמָרָא וַאֲמַר לַהּ כָּלֵב מָא לִיך :
<h3>פסוק יט</h3>
וַאֲמַרַת הַב לִי אַחסָנְתָא אֲרֵי לַאֲרַע דָּרוֹמָא יְהַבתַּנִי וְתִתֵּין לִי אֲתַר בֵּית שִׁקיָא דְמַיָא וִיהַב לַהּ יָת בֵּית שִׁקיָא עִלָאָה וְיָת בֵּית שִׁקיָא תַחתָּאָה :
<h3>פסוק כ</h3>
דָּא אַחסָנַת שִׁבטָא דִבנֵי יְהוּדָה לְזַרעֲיָתְהוֹן :
<h3>פסוק כא</h3>
וַהֲווֹ קִרוַיָא מִסְיָפֵי לְשִׁבטָא דִבנֵי יְהוּדָה לִתחוּם אֱדוֹמָאָה בְּדָרוֹמָא קַבצְאֵל וְעֵדֶר וְיָגוּר :
<h3>פסוק כב</h3>
וְקִינָה וְדִימֹנָה וְעַדעָדָה :
<h3>פסוק כג</h3>
וְקֶדֶשׁ וְחָצוֹר וְיִתנָן :
<h3>פסוק כד</h3>
זִיף וְטֶלֶם וּבעָלוֹת :
<h3>פסוק כה</h3>
וְחָצוֹר חֲדַתָּה וּקרִיוֹת חֶצְרוֹן הִיא חָצוֹר :
<h3>פסוק כו</h3>
אֲמָם וּשׁמַע וּמוֹלָדָה :
<h3>פסוק כז</h3>
וַחֲצַר גַּדָּה וְחֶשׁמוֹן וּבֵית פָּלֶט :
<h3>פסוק כח</h3>
וַחֲצַר שׁוּעָל וּבאֵר שֶׁבַע וּבִזיוֹתְיָה :
<h3>פסוק כט</h3>
בַּעֲלָה וְעִיִים וָעָצֶם :
<h3>פסוק ל</h3>
וְאֶלתּוֹלַד וּכסִיל וְחָרמָה :
<h3>פסוק לא</h3>
וְצִקלַג וּמַדמַנָה וְסַנסַנָה :
<h3>פסוק לב</h3>
וּלבָאוֹת וְשִׁלחִים וְעַיִן וְרִמוֹן כָּל קִרוַיָא תְּשַׁע וְעַסרִין וּפַצחֵיהוֹן :
<h3>פסוק לג</h3>
בְּשָׁפֵלתָּא אֶשׁתָּאוֹל וְצָרעָה וְאַשׁנָה :
<h3>פסוק לד</h3>
וְזָנוֹחַ וְעֵין גַּנִים תַּפּוּחַ וְעֵינָם :
<h3>פסוק לה</h3>
יַרמוּת וַעֲדֻלָם שׂכֹה וַעֲזֵקָה :
<h3>פסוק לו</h3>
וְשַׁעֲרַיִם וַעֲדִתַיִם וּגדֵרָה וּגדֵרוֹתָיִם קִרוִין אַרבַּע עַסרֵי וּפַצחֵיהוֹן :
<h3>פסוק לז</h3>
צְנָן וַחֲדָשָׁה וּמִגדַּל גָּד :
<h3>פסוק לח</h3>
וְדִלעָן וְהַמִצפֶּה וְיָקתְאֵל :
<h3>פסוק לט</h3>
לָכִישׁ וּבָצקַת וְעֶגלוֹן :
<h3>פסוק מ</h3>
וְכַבּוֹן וְלַחמָס וְכִתלִישׁ :
<h3>פסוק מא</h3>
וּגדֵרוֹת בֵּית דָּגוֹן וְנַעֲמָה וְמַקֵדָה קִרוִין שֵׁית עֲסַר וּפַצחֵיהוֹן :
<h3>פסוק מב</h3>
לִבנָה וָעֶתֶר וְעָשָׁן :
<h3>פסוק מג</h3>
וְיִפתָּח וְאַשׁנָה וּנצִיב :
<h3>פסוק מד</h3>
וּקעִילָה וְאַכזִיב וּמָרֵשָׁה קִרוִין תְּשַׁע וּפַצחֵיהוֹן :
<h3>פסוק מה</h3>
עֶקרוֹן וְכַפרָנַהָא וּפַצחַהָא :
<h3>פסוק מו</h3>
מֵעֶקרוֹן וּמַערְבָא כֹּל קִרוַיָא דְעַל תְּחוּם אַשׁדּוֹד וּפַצחֵיהוֹן :
<h3>פסוק מז</h3>
אַשׁדּוֹד כַּפרָנַהָא וּפַצחַהָא עַזָה כַּפרָנַהָא וּפַצחַהָא עַד נַחלָא דְמִצרָיִם וְיַמָא רַבָּא וּתחוּמֵיהּ :
<h3>פסוק מח</h3>
וּבטוּרָא שָׁמִיר וְיַתִּיר וְשׂוֹכֹה :
<h3>פסוק מט</h3>
וְדַנָה וְקִריַת סַנָה הִיא דְבִיר :
<h3>פסוק נ</h3>
וַעֲנָב וְאֶשׁתְּמֹה וְעָנִים :
<h3>פסוק נא</h3>
וּגֹשֶׁן וְחוֹלוֹן וְגִילוֹ קִרוִין חֲדַא עַסרֵי וּפַצחֵיהוֹן :
<h3>פסוק נב</h3>
אֲרַב וְדוּמָה וְאֶשׁעָן :
<h3>פסוק נג</h3>
וְיָנוּם וּבֵית תַּפּוּחַ וַאֲפֵק :
<h3>פסוק נד</h3>
וְחֻמטָה וְקִריַת אַרבַּע הִיא חֶברוֹן וְצִיעוֹר קִרוִין תְּשַׁע וּפַצחֵיהוֹן :
<h3>פסוק נה</h3>
מָעוֹן כַּרמֶל זִיף וְיוּטָה :
<h3>פסוק נו</h3>
וְיִזרְעֶאל וְיָקדְעָם וְזָנוֹחַ :
<h3>פסוק נז</h3>
הַקַיִן גִּבעָה וְתִמנָה קִרוִין עֲסַר וּפַצחֵיהוֹן :
<h3>פסוק נח</h3>
חַלחוּל בֵּית צוּר וּגדוֹר :
<h3>פסוק נט</h3>
וּמַעֲרָת וּבֵית עֲנוֹת וְאֶלתְּקוֹן קִרוִין שֵׁית וּפַצחֵיהוֹן :
<h3>פסוק ס</h3>
קִריַת בַּעַל הִיא קִריַת יְעָרִים וְרַבָּה קִרוִין תַּרתֵּין וּפַצחֵיהוֹן :
<h3>פסוק סא</h3>
בְּמַדבְּרָא בֵּית מֵישְׁרָא מִדִּין וּסכָכָה :
<h3>פסוק סב</h3>
וְנִבשָׁן וְקִריַת מֶלַח וְעֵין גֶּדִי קִרוִין שֵׁית וּפַצחֵיהוֹן :
<h3>פסוק סג</h3>
וְיָת יְבוּסָאֵי יָתְבֵי יְרוּשׁלֶם לָא יְכִילוּ בְנֵי יְהוּדָה לְתָרָכוּתְהוֹן וִיתִיבוּ יְבוּסָאֵי עִם בְּנֵי יְהוּדָה בִּירוּשׁלֶם עַד יוֹמָא הָדֵין :
<h2>פרק טז</h2>
<h3>פסוק א</h3>
וּנפַק עַדבָּא לִבנֵי יוֹסֵף מִיַרדְּנָא דִירִיחוֹ לְמֵי יְרִיחוֹ מַדנְחָא לְמַדבְּרָא דְּסָלֵיק מִירִיחוֹ בְּטוּרָא לְבֵית אֵל :
<h3>פסוק ב</h3>
וְנָפֵיק מִבֵּית אֵל לְלוּז וְעָבַר לִתחוּם אַרכֵּי לַעֲטָרוֹת :
<h3>פסוק ג</h3>
וְנָחֵית לְיַמָא לִתחוּם יַפלֵט עַד תְּחוּם בֵּית חוֹרוֹן אַרעָאָה וְעַד גָּזֶר וְהָוַן מַפְּקָנוֹהִי לְיַמָא :
<h3>פסוק ד</h3>
וְאַחסִינוּ בְנֵי יוֹסֵף מְנַשֶׁה וְאֶפרָיִם :
<h3>פסוק ה</h3>
וַהֲוָה תְּחוּם בְּנֵי אֶפרַיִם לְזַרעֲיָתְהוֹן וַהֲוָה תְּחוּם אַחסָנַתהוֹן מַדנְחָא עַטרוֹת אַדָּר עַד בֵּית חוֹרוֹן עִלָאָה :
<h3>פסוק ו</h3>
וְנָפֵיק תְּחוּמָא לְיַמָא לְמִכמְתָת מִצִפּוּנָא וּמִסתְּחַר תְּחוּמָא מִמַדנְחָא לְתַאֲנַת שִׁילוֹ וְעָבַר לֵיהּ מִמַדנַח לְיָנוֹחַ :
<h3>פסוק ז</h3>
וְנָחֵית מִיָנוֹחַ לַעֲטָרוֹת וּלנַעֲרָת וּמעָרַע בִּירִיחוֹ וְנָפֵיק לְיַרדְּנָא :
<h3>פסוק ח</h3>
מִתַּפּוּחַ אָזֵיל תְּחוּמָא לְיַמָא לְנַחלָא דְקָנָה וְהָוַן מַפְּקָנוֹהִי לְיַמָא דָּא אַחסָנַת שִׁבטָא דְבֵית אֶפרַיִם לְזַרעֲיָתְהוֹן :
<h3>פסוק ט</h3>
וְקִרוַיָא דִּמפָרְשָׁן לִבנֵי אֶפרַיִם בְּגוֹ אַחסָנַת בְּנֵי מְנַשֶׁה כָּל קִרוַיָא וּפַצחֵיהוֹן :
<h3>פסוק י</h3>
וְלָא תָרִיכוּ יָת כְּנַעֲנָאֵי דְּיָתְבִין בְּגָזֶר וִיתִיבוּ כְנַעֲנָאֵי בְּגוֹ אֶפרַיִם עַד יוֹמָא הָדֵין וַהֲווֹ לְמַסְקֵי מִסִין פָּלְחִין :
<h2>פרק יז</h2>
<h3>פסוק א</h3>
וַהֲוָה עַדבָּא לְשִׁבטָא דִמנַשֶׁה אֲרֵי הוּא בּוּכרָא דְיוֹסֵף לְמָכִיר בּוּכרָא דִמנַשֶׁה אֲבוּהִי דְגִלעָד אֲרֵי הוּא הֲוָה גְּבַר עָבֵיד קְרָבִין וַהֲוָה לֵיהּ אֲרַע גִּלעָד וּמַתנַן :
<h3>פסוק ב</h3>
וַהֲוָה לִבנֵי מְנַשֶׁה דְאִשׁתְּאַרוּ לְזַרעֲיָתְהוֹן לִבנֵי אֲבִיעֶזֶר וְלִבנֵי חֵלֶק וְלִבנֵי אַשׁרִיאֵל וְלִבנֵי שֶׁכֶם וְלִבנֵי חֵפֶר וְלִבנֵי שְׁמִידָע אִלֵין בְּנֵי מְנַשֶׁה בַר יוֹסֵף דִּכרַיָא לְזַרעֲיָתְהוֹן :
<h3>פסוק ג</h3>
וְלִצלָפחָד בַּר חֵפֶר בַּר גִּלעָד בַּר מָכִיר בַּר מְנַשֶׁה לָא הֲווֹ לֵיהּ בְּנִין אֱלָהֵין בְּנָן וְאִלֵין שְׁמָהָת בְּנָתֵיהּ מַחלָה וְנֹעָה חָגלָה מִלכָּה וְתִרצָה :
<h3>פסוק ד</h3>
וּקרִיבָא לִקדָם אֶלעָזָר כָּהֲנָא וְלִקדָם יְהוֹשֻׁעַ בַּר נוּן וְלִקדָם רַברְבַיָא לְמֵימַר יְיָ פַּקֵיד יָת מֹשֶׁה לְמִתַּן לַנָא אַחסָנָא בְּגוֹ אֲחַנָא וִיהַב לְהוֹן עַל מֵימְרָא דַיְיָ אַחסָנָא בְּגוֹ אֲחֵי אֲבוּהוֹן :
<h3>פסוק ה</h3>
וּנפַלוּ עַדבֵּי מְנַשֶׁה עַסרָא בָּר מֵאֲרַע גִּלעָד וּמַתנַן דְּמֵעִברָא לְיַרדְּנָא :
<h3>פסוק ו</h3>
אֲרֵי בְּנָת מְנַשֶׁה אַחסִינוּ אַחסָנָא בְּגוֹ בְנוֹהִי וַאֲרַע גִּלעָד הֲוָת לִבנֵי מְנַשֶׁה דְאִשׁתְּאַרוּ :
<h3>פסוק ז</h3>
וַהֲוָה תְחוּם מְנַשֶׁה מֵאָשֵׁר לְמִכמְתָת דְּעַל אַפֵּי שְׁכֶם וְאָזֵיל תְּחוּמָא לְמִיַמִינָא לְוָת יָתְבֵי עֵין תַּפּוּחַ :
<h3>פסוק ח</h3>
לִמנַשֶׁה הֲוָת אֲרַע תַּפּוּחַ וְתַפּוּחַ עַל תְּחוּם מְנַשֶׁה לִבנֵי אֶפרָיִם :
<h3>פסוק ט</h3>
וְנָחֵית תְּחוּמָא לְנַחלָא דְקָנָה לְדָרוֹמָא לְנַחלָא קִרוַיָא הָאִלֵין לְאֶפרַיִם בְּגוֹ קִרוֵי מְנַשֶׁה וּתחוּם מְנַשֶׁה מִצִפּוּנָא לְנַחלָא וְהָוַן מַפְּקָנוֹהִי לְיַמָא :
<h3>פסוק י</h3>
דָּרוֹמָא לְאֶפרַיִם וְצִפּוּנָא לִמנַשֶׁה וְהָוֵי יַמָא תְּחוּמֵיהּ וּבאָשֵׁר מְעָרְעִין מִצִפּוּנָא וּביִשָּׁשׁכָר מִמַדנְחָא :
<h3>פסוק יא</h3>
וַהֲוָה לִמנַשֶׁה בְּיִשָּׁשׁכָר וּבאָשֵׁר בֵּית שְׁאָן וְכַפרָנַהָא וְיִבלְעָם וְכַפרָנַהָא וְיָת יָתְבֵי דֹאר וְכַפרָנַהָא וְיָתְבֵי עֵין דֹּאר וְכַפרָנַהָא וְיָתְבֵי תַענַך וְכַפרָנַהָא וְיָתְבֵי מְגִדּוֹ וְכַפרָנַהָא תְּלָתָה פִּלכִין :
<h3>פסוק יב</h3>
וְלָא יְכִילוּ בְּנֵי מְנַשֶׁה לְתָרָכָא יָת קִרוַיָא הָאִלֵין וְשָׁרִי כְּנַעֲנָאָה לְמִתַּב בְּאַרעָא הָדָא :
<h3>פסוק יג</h3>
וַהֲוָה כַּד תְּקִיפוּ בְּנֵי יִשׂרָאֵל וּמַנִיאוּ יָת כְּנַעֲנָאֵי לְמַסְקֵי מִסִין וְתָרָכָא לָא תָרִיכוּנוּן :
<h3>פסוק יד</h3>
וּמַלִילוּ בְּנֵי יוֹסֵף עִם יְהוֹשֻׁעַ לְמֵימַר מָדֵין יְהַבתְּ לַנָא אַחסָנְתָא חוּלָק חַד וְעַדבָּא חַד וַאֲנָא עַם סַגִּי עַד לִסגֵי בָּרְכַנִי יְיָ :
<h3>פסוק טו</h3>
וַאֲמַר לְהוֹן יְהוֹשֻׁעַ אִם עַם סַגִּי אַתּוּן סַקוּ לְכוֹן לְחֻרשָׁא וְתַתקֵין לָך תַּמָן אֲתַר בַּאֲרַע פְּרִזָאֵי וְגִבָּרַיָא אֲרֵי עָק לְכוֹן טוּרָא דְבֵית אֶפרָיִם :
<h3>פסוק טז</h3>
וַאֲמַרוּ בְּנֵי יוֹסֵף לָא יְסוֹפֵיק לַנָא טוּרָא וּרתִכִּין דְּבַרזְלָא בְּכָל כְּנַעֲנָאֵי דְּיָתְבִין בַּאֲרַע מֵישְׁרָא לִדִבבֵית שְׁאָן וְכַפרָנַהָא וּלדִבמֵישַׁר יִזרְעֶאל :
<h3>פסוק יז</h3>
וַאֲמַר יְהוֹשֻׁעַ לְבֵית יוֹסֵף לְאֶפרַיִם וְלִמנַשֶׁה לְמֵימַר עַם סַגִּי אַתּוּן וְחֵיל סַגִּי לְכוֹן לָא יְהֵי לְכוֹן עַדבָּא חַד :
<h3>פסוק יח</h3>
אֲרֵי טוּרָא יְהֵי לָך אֲרֵי חֻרשָׁא הוּא וּתתַקְנִנֵיהּ וִיהוֹן לָך מַפְּקָנוֹהִי אֲרֵי תְתָרְכוּן יָת כְּנַעֲנָאֵי אֲרֵי רְתִכִּין דְּבַרזְלָא לְהוֹן אֲרֵי תַקִיפִין אִנוּן :
<h2>פרק יח</h2>
<h3>פסוק א</h3>
וְאִתכְּנִישׁוּ כָּל כְּנִשׁתָּא דִבנֵי יִשׂרָאֵל לְשִׁילוֹ וְאַשׁרִיאוּ תַמָן יָת מַשׁכַּן זִמנָא וְאַרעָא אִתכְּבֵישַׁת קֳדָמֵיהוֹן :
<h3>פסוק ב</h3>
וְאִשׁתְּאַרוּ בִּבנֵי יִשׂרָאֵל דְּלָא פַלִיגוּ יָת אַחסָנַתהוֹן שִׁבעָה שִׁבטִין :
<h3>פסוק ג</h3>
וַאֲמַר יְהוֹשֻׁעַ לִבנֵי יִשׂרָאֵל עַד אִמַתִּי אַתּוּן מִתרַשְׁלִין לְמֵיעַל לְמֵירַת יָת אַרעָא דִּיהַב לְכוֹן יְיָ אֱלָהָא דַאֲבָהָתְכוֹן :
<h3>פסוק ד</h3>
הַבוּ לְכוֹן תְּלָתָה גֻברִין לְשִׁבטָא וְאַשׁלְחִנוּן וִיקוּמוּן וִיהָלְכוּן בְּאַרעָא וְיִכתְּבוּן יָתַהּ לְפוֹם אַחסָנַתהוֹן וְיֵיתוֹן לְוָתִי :
<h3>פסוק ה</h3>
וִיפַלְגוּן יָתַהּ לְשִׁבעָה חוּלָקִין דְּבֵית יְהוּדָה יְקוּמוּן עַל תְּחוּמְהוֹן מִדָּרוֹמָא וּדבֵית יוֹסֵף יְקוּמוּן עַל תְּחוּמְהוֹן מִצִפּוּנָא :
<h3>פסוק ו</h3>
וְאַתּוּן תִּכתְּבוּן יָת אַרעָא לְשִׁבעָה חוּלָקִין וְתֵתוֹן לְוָתִי הָלְכָא וְאַרמֵי לְכוֹן עַדבִּין הָכָא קֳדָם יְיָ אֱלָהַנָא :
<h3>פסוק ז</h3>
אֲרֵי לֵית חוּלָק לְלֵיוָאֵי בֵּינֵיכוֹן אֱלָהֵין מַתְּנָן דִּיהַב לְהוֹן יְיָ אִנִין אַחסָנַתהוֹן וְשֵׁיבַט גָּד וְשֵׁיבַט רְאוּבֵן וּפַלגוּת שִׁבטָא דִמנַשֶׁה קַבִּילוּ אַחסָנַתהוֹן מֵעִברָא לְיַרדְּנָא מַדנְחָא דִּיהַב לְהוֹן מֹשֶׁה עַבדָּא דַיְיָ :
<h3>פסוק ח</h3>
וְקָמוּ גֻברַיָא וַאֲזַלוּ וּפַקֵיד יְהוֹשֻׁעַ יָת דַּאֲזַלוּ לְמִכתַּב יָת אַרעָא לְמֵימַר אִיזִילוּ וְהַלִיכוּ בְאַרעָא וּכתוּבוּ יָתַהּ וְתוּבוּ לְוָתִי וְהָכָא אַרמֵי לְכוֹן עַדבִּין קֳדָם יְיָ בְּשִׁילוֹ :
<h3>פסוק ט</h3>
וַאֲזַלוּ גֻברַיָא וַעֲבַרוּ בְאַרעָא וּכתַבוּהָא לְקִרוַיָא לְשִׁבעָה חֻלָקִין עַל סִפרָא וַאֲתוֹ לְוָת יְהוֹשֻׁעַ לְמַשׁרִיתָא לְשִׁילוֹ :
<h3>פסוק י</h3>
וּרמָא לְהוֹן יְהוֹשֻׁעַ עַדבָּא בְּשִׁילוֹ קֳדָם יְיָ וּפַלֵיג תַּמָן יְהוֹשֻׁעַ יָת אַרעָא לִבנֵי יִשׂרָאֵל כְּפַלגָוָתְהוֹן :
<h3>פסוק יא</h3>
וּסלֵיק עֲדַב שִׁבטָא דִבנֵי בִניָמִן לְזַרעֲיָתְהוֹן וּנפַק תְּחוּם עַדבְּהוֹן בֵּין בְּנֵי יְהוּדָה וּבֵין בְּנֵי יוֹסֵף :
<h3>פסוק יב</h3>
וַהֲוָה לְהוֹן תְּחוּמָא לְרוּחַ צִפּוּנָא מִן יַרדְּנָא וְסָלֵיק תְּחוּמָא לְעֵיבַר יְרִיחוֹ מִצִפּוּנָא וְסָלֵיק בְּטוּרָא לְיַמָא וְהָוַן מַפְּקָנוֹהִי לְמִדבַּר בֵּית אָוֶן :
<h3>פסוק יג</h3>
וְעָבַר מִתַּמָן תְּחוּמָא לְלוּז דִּלעֵיבַר לוּז דָּרוֹמָא הִיא בֵּית אֵל וְנָחֵית תְּחוּמָא לְעַטרוֹת אַדָּר עַל טוּרָא דְּמִדָּרוֹמָא לְבֵית חוֹרוֹן אַרעָאָה :
<h3>פסוק יד</h3>
וְתָאַר תְּחוּמָא וּמִסתְּחַר לְרוּחַ מַערְבָא לְדָרוֹמָא מִן טוּרָא דְּעַל אַפֵּי בֵית חוֹרוֹן דָּרוֹמָא וְהָוַן מַפְּקָנוֹהִי עַל קִריַת בַּעַל הִיא קִריַת יְעָרִים קַרתָּא דִּבנֵי יְהוּדָה דָּא רוּחַ מַערְבָא :
<h3>פסוק טו</h3>
וְרוּחַ דָּרוֹמָא מִסְיָפֵי קִריַת יְעָרִים וְנָפֵיק תְּחוּמָא לְיַמָא וְנָפֵיק לְמַבּוּעַ מֵי נֶפתּוֹחַ :
<h3>פסוק טז</h3>
וְנָחֵית תְּחוּמָא לִסטַר טוּרָא דְּעַל אַפֵּי חִלַת בַּר הִנֹם דִּבמֵישַׁר גִּבָּרַיָא צִפּוּנָא וְנָחֵית לְחִלַת הִנוֹם דִּלעֵיבַר יְבוּס דָּרוֹמָא וְנָחֵית לְעֵין קָצְרָא :
<h3>פסוק יז</h3>
וְתָאַר מִצִפּוּנָא וְנָפֵיק לְעֵין שֶׁמֶשׁ וְנָפֵיק לִגלִילָא דְּלָקֳבֵיל מַסְקַנָא דַאֲדֻמִים וְנָחֵית לְאֶבֶן בֹּהַן בַּר רְאוּבֵן :
<h3>פסוק יח</h3>
וְעָבַר לְעֵיבַר לָקֳבֵיל מֵישְׁרָא צִפּוּנָא וְנָחֵית לְעַרבָת :
<h3>פסוק יט</h3>
וְעָבַר תְּחוּמָא לְעֵבַר בֵּית חָגלָה לְצִפּוּנָא וְהָוַן מַפְּקָנוֹהִי דִתחוּמָא לְכֵיף יַמָא דְמִלחָא לְצִפּוּנָא לִסיָפֵי יַרדְּנָא דָּרוֹמָא דֵּין תְּחוּם דָּרוֹמָא :
<h3>פסוק כ</h3>
וְיַרדְּנָא תְחוּמָא לֵיהּ לְרוּחַ קִדּוּמָא דָּא אַחסָנַת בְּנֵי בִניָמִין לִתחוּמַהָא סְחוֹר סְחוֹר לְזַרעֲיָתְהוֹן :
<h3>פסוק כא</h3>
וַהֲוַאָה קִרוַיָא לְשִׁבטָא דִּבנֵי בִניָמִין לְזַרעֲיָתְהוֹן יְרִיחוֹ וּבֵית חָגלָה וּמֵישַׁר קְצִיץ :
<h3>פסוק כב</h3>
וּבֵית מֵישְׁרָא וּצמָרַיִם וּבֵית אֵל :
<h3>פסוק כג</h3>
וְהָעַוִים וְהַפָּרָה וְעָפרָה :
<h3>פסוק כד</h3>
וּכפַר עַמוֹנָאָה וְעָפנִי וָגָבַע קִרוִין תַּרתַּא עַסרֵי וּפַצחֵיהוֹן :
<h3>פסוק כה</h3>
גֶּבַע וְרָמְתָא וּבאֵרוֹת :
<h3>פסוק כו</h3>
וּמִצפְּיָא וּכפִירָה וְמוֹצָה :
<h3>פסוק כז</h3>
וְרֶקֶם וְיִרפְּאֵל וְתַראֲלָה :
<h3>פסוק כח</h3>
וְצֵלַע וְאֶלֶף וִיבוּס הִיא יְרוּשׁלֶם גִּבעַת קִריַת קִרוִין אַרבַּע עַסרֵי וּפַצחֵיהוֹן דָּא אַחסָנַת בְּנֵי בִניָמִין לְזַרעֲיָתְהוֹן :
<h2>פרק יט</h2>
<h3>פסוק א</h3>
וּנפַק עַדבָּא תִניָנָא לְשִׁמעוֹן לְשִׁבטָא דִבנֵי שִׁמעוֹן לְזַרעֲיָתְהוֹן וַהֲוָת אַחסָנַתהוֹן בְּגוֹ אַחסָנַת בְּנֵי יְהוּדָה :
<h3>פסוק ב</h3>
וַהֲוָה לְהוֹן בְּאַחסָנַתהוֹן בְּאֵר שֶׁבַע וְשֶׁבַע וּמוֹלָדָה :
<h3>פסוק ג</h3>
וַחֲצַר שׁוּעָל וּבָלָה וָעָצֶם :
<h3>פסוק ד</h3>
וְאֶלתּוֹלַד וּבתוּל וְחָרמָה :
<h3>פסוק ה</h3>
וְצִקלַג וּבֵית הַמַרכָּבוֹת וַחֲצַר סוּסָה :
<h3>פסוק ו</h3>
וּבֵית לְבָאוֹת וְשָׁרוּחֶן קִרוִין תְּלָת עַסרֵי וּפַצחֵיהוֹן :
<h3>פסוק ז</h3>
עַיִן רִמוֹן וָעֶתֶר וְעָשָׁן קִרוִין אַרבַּע וּפַצחֵיהוֹן :
<h3>פסוק ח</h3>
וְכָל פַּצחַיָא דִּבסַחרָנוּת קִרוַיָא הָאִלֵין עַד בַּעֲלַת בְּאֵר רָמַת דָּרוֹמָא דָּא אַחסָנַת שִׁבטָא דִבנֵי שִׁמעוֹן לְזַרעֲיָתְהוֹן :
<h3>פסוק ט</h3>
מֵעֲדַב בְּנֵי יְהוּדָה אַחסָנַת בְּנֵי שִׁמעוֹן אֲרֵי הֲוָה חוּלָק בְּנֵי יְהוּדָה סַגִּי מִנְהוֹן וְאַחסִינוּ בְנֵי שִׁמעוֹן בְּגוֹ אַחסָנַתהוֹן :
<h3>פסוק י</h3>
וּסלֵיק עַדבָּא תְלִיתָאָה לִבנֵי זְבוּלוּן לְזַרעֲיָתְהוֹן וַהֲוָה תְּחוּם אַחסָנַתהוֹן עַד שָׂרִיד :
<h3>פסוק יא</h3>
וְסָלֵיק תְּחוּמְהוֹן לְיַמָא וּמַרעֲלָה וּמעָרַע בְּדַבָּשֶׁת וּמעָרַע בְּנַחלָא דְּעַל אַפֵּי יָקנְעָם :
<h3>פסוק יב</h3>
וְתָאֵיב מִשָׂרִיד לְקִדּוּמָא מַדנַח שִׁמשָׁא עַל תְּחוּם כִּסלֹת תָּבוֹר וְנָפֵיק לְדָברַת וְסָלֵיק לְיָפִיעַ :
<h3>פסוק יג</h3>
וּמִתַּמָן עָבַר לְקִדּוּמָא מַדנְחָא לְגִתָּא חֵפֶר לְעִתָּא קָצִין וְנָפֵיק לְרִמוֹן מְתוֹאָר וּמִתַּמָן מִסתְּחַר לְנֵיעָה :
<h3>פסוק יד</h3>
וּמִסתְּחַר לֵיהּ תְּחוּמָא מִצִפּוּנָא לְחַנָתוֹן וְהָוַן מַפְּקָנוֹהִי לְחִלַת יִפתַּח אֵל :
<h3>פסוק טו</h3>
וְקַטָת וְנַהֲלָל וְשִׁמרוֹן וְיִדאֲלָה וּבֵית לָחֶם קִרוִין תַּרתַּא עַסרֵי וּפַצחֵיהוֹן :
<h3>פסוק טז</h3>
דָּא אַחסָנַת בְּנֵי זְבוּלֻן לְזַרעֲיָתְהוֹן קִרוַיָא הָאִלֵין וּפַצחֵיהוֹן :
<h3>פסוק יז</h3>
לְיִשָּׁשׁכָר נְפַק עַדבָּא רְבִיעָאָה לִבנֵי יִשָּׁשׁכָר לְזַרעֲיָתְהוֹן :
<h3>פסוק יח</h3>
וַהֲוָה תְּחוּמְהוֹן לְיִזרְעֶאל וּכסוּלוֹת וְשׁוּנֵם :
<h3>פסוק יט</h3>
וַחֲפָרַיִם וְשִׁיאֹן וְנָחֲרַת :
<h3>פסוק כ</h3>
וְרַבִּית וְקִשׁיוֹן וְאָבֶץ :
<h3>פסוק כא</h3>
וְרֶמֶת וְעֵין גַּנִים וְעֵין חַדָּה וּבֵית פַּצֵץ :
<h3>פסוק כב</h3>
וּמעָרַע תְּחוּמָא בְתָבוֹר וְשַׁחֲצִימָה וּבֵית שֶׁמֶשׁ וְהָוַן מַפְּקָנוֹהִי דִתחוּמְהוֹן לְיַרדְּנָא קִרוִין שֵׁית עַסרֵי וּפַצחֵיהוֹן :
<h3>פסוק כג</h3>
דָּא אַחסָנַת שִׁבטָא דִבנֵי יִשָּׁשׁכָר לְזַרעֲיָתְהוֹן קִרוַיָא וּפַצחֵיהוֹן :
<h3>פסוק כד</h3>
וּנפַק עַדבָּא חֲמִישָׁאָה לְשִׁבטָא דִבנֵי אָשֵׁר לְזַרעֲיָתְהוֹן :
<h3>פסוק כה</h3>
וַהֲוָה תְּחוּמְהוֹן חֶלקַת וַחֲלִי וּבֶטֶן וְאַכשָׁף :
<h3>פסוק כו</h3>
וְאַלַמֶלֶך וְעַמעָד וּמִשׁאָל וּמעָרַע בְּכַרמְלָא לְיַמָא וּבשִׁיחוֹר לִבנָת :
<h3>פסוק כז</h3>
וְתָאֵיב מִמַדנַח שִׁמשָׁא לְבֵית דָּגוֹן וּמעָרַע בִּזבוּלוּן וּבחִלַת יִפתַּח אֵל לְצִפּוּנָא בֵּית מֵישְׁרָא וּנעִיאֵל וְנָפֵיק לְכָבוּל מִסְמָאלָא :
<h3>פסוק כח</h3>
וְעֶברוֹן וּרחֹב וְחַמוֹן וְקָנָה עַד צִידוֹן רַבְּתָא :
<h3>פסוק כט</h3>
וְתָאֵיב תְּחוּמָא לְרָמְתָא וְעַד קִרוִין כְּרִיכָן קִרוֵי תֻקפָּא וְתָאֵיב תְּחוּמָא לְחוֹסָה וְהָוַן מַפְּקָנוֹהִי לְיַמָא מֵעֲדַב אַכזִיב :
<h3>פסוק ל</h3>
וְעֻמָה וַאֲפֵק וּרחוֹב קִרוִין עַסרִין וְתַרתֵּין וּפַצחֵיהוֹן :
<h3>פסוק לא</h3>
דָּא אַחסָנַת שִׁבטָא דִבנֵי אָשֵׁר לְזַרעֲיָתְהוֹן קִרוַיָא הָאִלֵין וּפַצחֵיהוֹן :
<h3>פסוק לב</h3>
לִבנֵי נַפתָּלִי נְפַק עַדבָּא שְׁתִיתָאָה לִבנֵי נַפתָּלִי לְזַרעֲיָתְהוֹן :
<h3>פסוק לג</h3>
וַהֲוָה תְחוּמְהוֹן מֵחֵלֶף מֵאֵלוֹן בְּצַעֲנַנִים וַאֲדָמִי נֶקֶב וְיַבנְאֵל עַד לַקוּם וְהָוַן מַפְּקָנוֹהִי לְיַרדְּנָא :
<h3>פסוק לד</h3>
וְתָאֵיב תְּחוּמָא לְיַמָא לְאַזנוֹת תָּבוֹר וְנָפֵיק מִתַּמָן לְחוּקוֹק וּמעָרַע בִּזבוּלוּן מִדָּרוֹמָא וּבאָשֵׁר מְעָרַע מִמַערְבָא וּבִיהוּדָה יַרדְּנָא מַדנַח שִׁמשָׁא :
<h3>פסוק לה</h3>
וְקִרוִין כְּרִיכָן צִדִּים צֵר וְחַמַת רַקַת וְכִנָרֶת :
<h3>פסוק לו</h3>
וַאֲדָמָה וְרָמְתָא וְחָצוֹר :
<h3>פסוק לז</h3>
וְקֶדֶשׁ וְאֶדרֶעִי וְעֵין חָצוֹר :
<h3>פסוק לח</h3>
וְיִראוֹן וּמִגדַּל אֵל חֳרֵם וּבֵית עֲנָת וּבֵית שָׁמֶשׁ קִרוִין תְּשַׁע עַסרֵי וּפַצחֵיהוֹן :
<h3>פסוק לט</h3>
דָּא אַחסָנַת שִׁבטָא דִבנֵי נַפתָּלִי לְזַרעֲיָתְהוֹן קִרוַיָא וּפַצחֵיהוֹן :
<h3>פסוק מ</h3>
לְשִׁבטָא דִבנֵי דָן לְזַרעֲיָתְהוֹן נְפַק עַדבָּא שְׁבִיעָאָה :
<h3>פסוק מא</h3>
וַהֲוָה תְּחוּם אַחסָנַתהוֹן צָרעָה וְאֶשׁתָּאוֹל וְקִריַת שָׁמֶשׁ :
<h3>פסוק מב</h3>
וְשַׁעֲלַבִּין וְאַיָלוֹן וְיִתלָה :
<h3>פסוק מג</h3>
וְאֵלוֹן וְתִימנָתָה וְעֶקרוֹן :
<h3>פסוק מד</h3>
וְאֶלתְּקֵה וְגִבְּתוֹן וּבַעֲלָת :
<h3>פסוק מה</h3>
וִיהוּד וּבנֵי בְרַק וְגַת רִמוֹן :
<h3>פסוק מו</h3>
וּמֵי יַרקוֹן וְרַקוֹן עִם תְּחוּמָא דְּלָקֳבֵיל יָפוֹ :
<h3>פסוק מז</h3>
וּנפַק תְּחוּם בְּנֵי דָן מִנְהוֹן וּסלִיקוּ בְנֵי דָן וַאֲגִיחוּ קְרָבָא עִם לֶשֶׁם וּכבַשׁוּ יָתַהּ וּמחוֹ יָתַהּ לְפִתגָם דְּחֶרֶב וְאַחסִינוּ יָתַהּ וִיתִיבוּ בַהּ וּקרוֹ לְלֶשֶׁם דָּן כְּשׁוּם דָּן אֲבוּהוֹן :
<h3>פסוק מח</h3>
דָּא אַחסָנַת שִׁבטָא דִבנֵי דָן לְזַרעֲיָתְהוֹן קִרוַיָא הָאִלֵין וּפַצחֵיהוֹן :
<h3>פסוק מט</h3>
וְשֵׁיצִיאוּ לְאַחסָנָא יָת אַרעָא לִתחוּמַהָא וִיהַבוּ בְנֵי יִשׂרָאֵל אַחסָנָא לִיהוֹשֻׁעַ בַּר נוּן בּינֵיהוֹן :
<h3>פסוק נ</h3>
עַל מֵימְרָא דַיְיָ יְהַבוּ לֵיהּ יָת קַרתָּא דִּשׁאֵיל יָת תִּמנַת סֶרַח בְּטוּרָא דְאֶפרָיִם וּבנָא יָת קַרתָּא וִיתֵיב בַּהּ :
<h3>פסוק נא</h3>
אִלֵין אַחסָנָתָא דְּאַחסִינוּ אֶלעָזָר כָּהֲנָא וִיהוֹשֻׁעַ בַּר נוּן וְרֵישֵׁי אֲבָהָתָא לְשִׁבטַיָא דִבנֵי יִשׂרָאֵל בְּעַדבָּא בְּשִׁילוֹ קֳדָם יְיָ בִּתרַע מַשׁכַּן זִמנָא וְשֵׁיצִיאוּ מִלְפַלָגָא יָת אַרעָא :
<h2>פרק כ</h2>
<h3>פסוק א</h3>
וּמַלֵיל יְיָ עִם יְהוֹשֻׁעַ לְמֵימַר :
<h3>פסוק ב</h3>
מַלֵיל עִם בְּנֵי יִשׂרָאֵל לְמֵימַר הַבוּ לְכוֹן יָת קִרוֵי שֵׁיזָבוּתָא דְּמַלֵילִית עִמְכוֹן בִּידָא דְמֹשֶׁה :
<h3>פסוק ג</h3>
לְמִערַק לְתַמָן קָטוֹלָא דְּיִקטוֹל נַפשָׁא בְשָׁלוּ בְּלָא מַדְּעֵיהּ וְיִהוְיָן לְכוֹן לְשֵׁיזָבָא מִגָּאֵיל דְּמָא :
<h3>פסוק ד</h3>
וְיִערוֹק לַחֲדָא מִקִרוַיָא הָאִלֵין וִיקוּם בְּמַעֲלַנָא דִּתרַע קַרתָּא וִימַלֵיל קֳדָם סָבֵי קַרתָּא הַהִיא יָת פִּתגָמוֹהִי וְיִכנְשׁוּן יָתֵיהּ לְקַרתָּא לְוָתְהוֹן וְיִתְּנוּן לֵיהּ אֲתַר וְיִתֵּיב עִמְהוֹן :
<h3>פסוק ה</h3>
וַאֲרֵי יִרדּוֹף גָּאֵל דְּמָא בָּתְרוֹהִי וְלָא יִמסְרוּן יָת קָטוֹלָא בִּידֵיהּ אֲרֵי בְלָא מַדְּעֵיהּ קְטַל יָת חַברֵיהּ וְלָא סָנֵי הוּא לֵיהּ מֵאַתמָלִי וּמִדְּקַמוֹהִי :
<h3>פסוק ו</h3>
וְיִתֵּיב בְּקַרתָּא הַהִיא עַד דִּיקוּם קֳדָם כְּנִשׁתָּא לְדִינָא עַד דִּימוּת כָּהֲנָא רַבָּא דִּיהֵי בְּיוֹמַיָא הָאִנוּן בְּכֵין יְתוּב קָטוֹלָא וְייֵעוֹל לְקַרתֵּיהּ וּלבֵיתֵיהּ לְקַרתָּא דַּעֲרַק מִתַּמָן :
<h3>פסוק ז</h3>
וְזָמִינוּ יָת קֶדֶשׁ בְּגָלִילָא בְּטוּרָא דְבֵית נַפתָּלִי וְיָת שְׁכֶם בְּטוּרָא דְבֵית אֶפרָיִם וְיָת קִריַת אַרבַּע הִיא חֶברוֹן בְּטוּרָא דְבֵית יְהוּדָה :
<h3>פסוק ח</h3>
וּמֵעֵיבַר לְיַרדְּנָא דִירִיחוֹ מַדנְחָא יְהַבוּ יָת בֶּצֶר בְּמַדבְּרָא בְּמֵישְׁרָא מִשִׁבטָא דִראוּבֵן וְיָת רָמוֹת בְּגִלעָד מִשִׁבטָא דְגָד וְיָת גּוֹלָן בְּמַתנַן מִשִׁבטָא דִמנַשֶׁה :
<h3>פסוק ט</h3>
אִלֵין הֲוַאָה קִרוַיָא דִמזָמְנָן לְכָל בְּנֵי יִשׂרָאֵל וּלגִיוֹרַיָא דְּיִתגַּיְרוּן בֵּינֵיהוֹן לְמִערַק לְתַמָן כָּל דְּיִקטוֹל נַפשָׁא בְּשָׁלוּ וְלָא יְמוּת בְּיַד גָּאֵיל דְּמָא עַד דִּיקוּם קֳדָם כְּנִשׁתָּא :
<h2>פרק כא</h2>
<h3>פסוק א</h3>
וּקרִיבוּ רֵישֵׁי אֲבָהָת לֵיוָאֵי לְוָת אֶלעָזָר כָּהֲנָא וּלוָת יְהוֹשֻׁעַ בַּר נוּן וּלוָת רֵישֵׁי אֲבָהָת שִׁבטַיָא לִבנֵי יִשׂרָאֵל :
<h3>פסוק ב</h3>
וּמַלִילוּ עִמְהוֹן בְּשִׁילוֹ בְּאַרעָא דִכנַעַן לְמֵימַר יְיָ פַּקֵיד בִּידָא דְמֹשֶׁה לְמִתַּן לַנָא קִרוִין לְמִתַּב וְרַוחֵיהוֹן לִבעִירַנָא :
<h3>פסוק ג</h3>
וִיהַבוּ בְנֵי יִשׂרָאֵל לְלֵיוָאֵי מֵאַחסָנַתהוֹן עַל מֵימְרָא דַיְיָ יָת קִרוַיָא הָאִלֵין וְיָת רַוחֵיהוֹן :
<h3>פסוק ד</h3>
וּנפַק עַדבָּא לְזַרעֲיָת קְהָת וַהֲוָה לִבנֵי אַהֲרֹן כָּהֲנָא מִן לֵיוָאֵי מִשִׁבטָא דִיהוּדָה וּמִשִׁבטָא דְשִׁמעוֹן וּמִשִׁבטָא דְבִניָמִין בְּעַדבָּא קִרוִין תְּלָת עַסרֵי :
<h3>פסוק ה</h3>
וְלִבנֵי קְהָת דְּאִשׁתְּאַרוּ מִזַרעֲיָת שִׁבטָא דְאֶפרַיִם וּמִשִׁבטָא דְדָן וּמִפַּלגוּת שִׁבטָא דִמנַשֶׁה בְּעַדבָּא קִרוִין עֲסַר :
<h3>פסוק ו</h3>
וּלִבנֵי גֵרְשׁוֹן מִזַרעֲיָת שִׁבטָא דְיִשָּׁשׁכָר וּמִשִׁבטָא דְאָשֵׁר וּמִשִׁבטָא דְנַפתָּלִי וּמִפַּלגוּת שִׁבטָא דִמנַשֶׁה בְמַתנַן בְּעַדבָּא קִרוִין תְּלָת עַסרֵי :
<h3>פסוק ז</h3>
לִבנֵי מְרָרִי לְזַרעֲיָתְהוֹן מִשִׁבטָא דִראוּבֵן וּמִשִׁבטָא דְגָד וּמִשִׁבטָא דִזבוּלוּן קִרוִין תַּרתַּא עַסרֵי :
<h3>פסוק ח</h3>
וִיהַבוּ בְנֵי יִשׂרָאֵל לְלֵיוָאֵי יָת קִרוַיָא הָאִלֵין וְיָת רַוחֵיהוֹן כְּמָא דְפַקֵיד יְיָ בִּידָא דְמֹשֶׁה בְּעַדבָּא :
<h3>פסוק ט</h3>
וִיהַבוּ מִשִׁבטָא דִּבנֵי יְהוּדָה וּמִשִׁבטָא דִּבנֵי שִׁמעוֹן יָת קִרוַיָא הָאִלֵין דְּאִתפָּרַשָׁא בִשׁמָהָן :
<h3>פסוק י</h3>
וַהֲוָה לִבנֵי אַהֲרֹן מִזַרעֲיָת קְהָת מִבְּנֵי לֵוִי אֲרֵי לְהוֹן הֲוָה עַדבָּא קַדמוּתָא :
<h3>פסוק יא</h3>
וִיהַבוּ לְהוֹן יָת קִריַת אַרבַּע אֲבוּהוֹן דְּגִבָּרַיָא הִיא חֶברוֹן בְּטוּרָא דְבֵית יְהוּדָה וְיָת רַוחַהָא סַחרָנַהָא :
<h3>פסוק יב</h3>
וְיָת חֲקַל קַרתָּא וְיָת פַּצחַהָא יְהַבוּ לְכָלֵב בַּר יְפֻנֶה בְּאַחסָנְתֵיהּ :
<h3>פסוק יג</h3>
וְלִבנֵי אַהֲרֹן כָּהֲנָא יְהַבוּ יָת קִריַת שֵׁיזָבוּת קָטוֹלָא יָת חֶברוֹן וְיָת רַוחַהָא וְיָת לִבנָה וְיָת רַוחַהָא :
<h3>פסוק יד</h3>
וְיָת יַתִּר וְיָת רַוחַהָא וְיָת אֶשׁתְּמוֹעַ וְיָת רַוחַהָא :
<h3>פסוק טו</h3>
וְיָת חוֹלוֹן וְיָת רַוחַהָא וְיָת דְּבִיר וְיָת רַוחַהָא :
<h3>פסוק טז</h3>
וְיָת עַיִן וְיָת רַוחַהָא וְיָת יוּטָה וְיָת רַוחַהָא יָת בֵּית שֶׁמֶשׁ וְיָת רַוחַהָא קִרוִין תֵּישַׁע מִן תְּרֵין שִׁבטַיָא הָאִלֵין :
<h3>פסוק יז</h3>
וּמִשִׁבטָא דְבִניָמִין יָת גִּבעוֹן וְיָת רַוחַהָא יָת גֶּבַע וְיָת רַוחַהָא :
<h3>פסוק יח</h3>
יָת עֲנָתוֹת וְיָת רַוחַהָא וְיָת עַלמוֹן וְיָת רַוחַהָא קִרוִין אַרבַּע :
<h3>פסוק יט</h3>
כָּל קִרוֵי בְנֵי אַהֲרֹן כָּהֲנַיָא תְּלָת עַסרֵי קִרוִין וְרַוחֵיהוֹן :
<h3>פסוק כ</h3>
וּלזַרעֲיָת בְּנֵי קְהָת לֵיוָאֵי דְּאִשׁתְּאַרוּ מִבְּנֵי קְהָת וַהֲוַאָה קִרוֵי עַדבְּהוֹן מִשִׁבטָא דִּבנֵי אֶפרָיִם :
<h3>פסוק כא</h3>
וִיהַבוּ לְהוֹן יָת קִריַת שֵׁיזָבוּת קָטוֹלָא יָת שְׁכֶם וְיָת רַוחַהָא בְּטוּרָא דְבֵית אֶפרָיִם וְיָת גֶּזֶר וְיָת רַוחַהָא :
<h3>פסוק כב</h3>
וְיָת קִבצַיִם וְיָת רַוחַהָא וְיָת בֵּית חוֹרוֹן וְיָת רַוחַהָא קִרוִין אַרבַּע :
<h3>פסוק כג</h3>
וּמִשִׁבטָא דְדָן יָת אֶלתְּקֵא וְיָת רַוחַהָא יָת גִּבְּתוֹן וְיָת רַוחַהָא :
<h3>פסוק כד</h3>
יָת אַיָלוֹן וְיָת רַוחַהָא יָת גַּת רִמוֹן וְיָת רַוחַהָא קִרוִין אַרבַּע :
<h3>פסוק כה</h3>
וּמִפַּלגוּת שִׁבטָא דִמנַשֶׁה יָת תַּענַך וְיָת רַוחַהָא וְיָת גַּת רִמוֹן וְיָת רַוחַהָא קִרוִין תַּרתֵּין :
<h3>פסוק כו</h3>
כָּל קִרוַיָא עֲסַר וְרַוחֵיהוֹן לְזַרעֲיָת בְּנֵי קְהָת דְּאִשׁתְּאַרוּ :
<h3>פסוק כז</h3>
וְלִבנֵי גֵרְשׁוֹן מִזַרעֲיָת לֵיוָאֵי מִפַּלגוּת שִׁבטָא דִמנַשֶׁה יָת קִריַת שֵׁיזָבוּת קָטוֹלָא יָת גּוֹלָן בְּמַתנַן וְיָת רַוחַהָא וְיָת בְּעֶשׁתְּרָה וְיָת רַוחַהָא קִרוִין תַּרתֵּין :
<h3>פסוק כח</h3>
וּמִשִׁבטָא דְיִשָּׁשׁכָר יָת קִשׁיוֹן וְיָת רַוחַהָא יָת דָּבְרַת וְיָת רַוחַהָא :
<h3>פסוק כט</h3>
יָת יַרמוּת וְיָת רַוחַהָא וְיָת עֵין גַּנִים וְיָת רַוחַהָא קִרוִין אַרבַּע :
<h3>פסוק ל</h3>
וּמִשִׁבטָא דְאָשֵׁר יָת מִשׁאָל וְיָת רַוחַהָא יָת עַבדּוֹן וְיָת רַוחַהָא :
<h3>פסוק לא</h3>
יָת חֶלקָת וְיָת רַוחַהָא וְיָת רְחוֹב וְיָת רַוחַהָא קִרוִין אַרבַּע :
<h3>פסוק לב</h3>
וּמִשִׁבטָא דְנַפתָּלִי יָת קִריַת שֵׁיזָבוּת קָטוֹלָא יָת קֶדֶשׁ בְּגָלִילָא וְיָת רַוחַהָא וְיָת חַמֹת דּוֹר וְיָת רַוחַהָא וְיָת קַרתָּן וְיָת רַוחַהָא קִרוִין תְּלָת :
<h3>פסוק לג</h3>
כָּל קִרוֵי בְנֵי גֵרְשׁוֹן לְזַרעֲיָתְהוֹן תְּלָת עַסרֵי קִרוִין וְרַוחֵיהוֹן :
<h3>פסוק לד</h3>
וּלזַרעֲיָת בְּנֵי מְרָרִי לֵיוָאֵי דְאִשׁתְּאַרוּ מִן שִׁבטָא דִזבוּלוּן יָת יָקנְעָם וְיָת רַוחַהָא וְיָת קַרתָּה וְיָת רַוחַהָא :
<h3>פסוק לה</h3>
יָת דִּמנָה וְיָת רַוחַהָא יָת נַהלָל וְיָת רַוחַהָא קִרוִין אַרבַּע :
<h3>פסוק לו</h3>
וּמִשִׁבטָא דְגָד יָת קִריַת שֵׁיזָבוּת קָטוֹלָא יָת רָמוֹת בְּגִלעָד וְיָת רַוחַהָא וְיָת מַחֲנַיִם וְיָת רַוחַהָא :
<h3>פסוק לז</h3>
יָת חֶשׁבּוֹן וְיָת רַוחַהָא יָת יַעזֵר וְיָת רַוחַהָא כָּל קִרוַיָא אַרבַּע :
<h3>פסוק לח</h3>
כָּל קִרוַיָא לִבנֵי מְרָרִי לְזַרעֲיָתְהוֹן דְּאִשׁתְּאַרוּ מִזַרעֲיָת לֵיוָאֵי וַהֲוָה עַדבְּהוֹן קִרוִין תַּרתַּא עַסרֵי :
<h3>פסוק לט</h3>
כֹּל קִרוֵי לֵיוָאֵי בְּגוֹ אַחסָנַת בְּנֵי יִשׂרָאֵל קִרוִין אַרבְּעִין וְתַמנֵי וְרַוחֵיהוֹן :
<h3>פסוק מ</h3>
יִהוְיָן קִרוַיָא הָאִלֵין קְרֵי קְרֵי וְרַוחַהָא סַחרָנַהָא כֵּן לְכָל קִרוַיָא הָאִלֵין :
<h3>פסוק מא</h3>
וִיהַב יְיָ לְיִשׂרָאֵל יָת כָּל אַרעָא דְּקַיֵים לְמִתַּן לַאֲבָהָתְהוֹן וְאַחסְנוּהָא וִיתִיבוּ בַהּ :
<h3>פסוק מב</h3>
וַאֲנִיחַ יְיָ לְהוֹן מִסְחוֹר סְחוֹר כְּכֹל דְּקַיֵים לַאֲבָהָתְהוֹן וְלָא קָם אֱנָשׁ קֳדָמֵיהוֹן מִכָּל בַּעֲלֵי דְבָבֵיהוֹן יָת כָּל בַּעֲלֵי דְבָבֵיהוֹן מְסַר יְיָ בְּיַדהוֹן :
<h3>פסוק מג</h3>
לָא בְטֵיל פִּתגָמָא מִכֹּל פִּתגָמַיָא תָקְנַיָא דְּמַלֵיל יְיָ עִם בֵּית יִשׂרָאֵל כֻּלְהוֹן אִתקַיַמוּ :
<h2>פרק כב</h2>
<h3>פסוק א</h3>
בְּכֵין קְרָא יְהוֹשֻׁעַ לְשֵׁיבַט רְאוּבֵן וּלשֵׁיבַט גָּד וּלפַלגוּת שִׁבטָא דִמנַשֶׁה :
<h3>פסוק ב</h3>
וַאֲמַר לְהוֹן אַתּוּן נְטַרתּוּן יָת כָּל דְּפַקֵיד יָתְכוֹן מֹשֶׁה עַבדָּא דַיְיָ וְקַבֵּילתּוּן לְמֵימְרִי לְכֹל דְּפַקֵידִית יָתְכוֹן :
<h3>פסוק ג</h3>
לָא שְׁבַקתּוּן יָת אֲחֵיכוֹן דְּנָן יוֹמִין סַגִּיאִין עַד יוֹמָא הָדֵין וּנטַרתּוּן יָת מַטְרַת תַּפקֵידַת מֵימְרָא דַיְיָ אֱלָהֲכוֹן :
<h3>פסוק ד</h3>
וּכעַן אֲנִיחַ יְיָ אֱלָהֲכוֹן לַאֲחֵיכוֹן כְּמָא דְמַלֵיל לְהוֹן וּכעַן אִתפְּנוֹ וְאִיזִילוּ לְכוֹן לְקִרוֵיכוֹן לַאֲרַע אַחסָנַתכוֹן דִּיהַב לְכוֹן מֹשֶׁה עַבדָּא דַיְיָ בְּעִברָא דְּיַרדְּנָא :
<h3>פסוק ה</h3>
לְחוֹד אִסתְּמַרוּ לַחדָּא לְמֶעֱבַד יָת תַּפקֵידתָּא וְיָת אוֹרָיתָא דְּפַקֵיד יָתְכוֹן מֹשֶׁה עַבדָּא דַיְיָ לְמִרחַם יָת יְיָ אֱלָהֲכוֹן וְלִמהָך בְּכָל אוֹרחָן דְּתָקְנָן קֳדָמוֹהִי וּלמִטַר פִּקוֹדוֹהִי וּלאִתקָרָבָא לְדַחלְתֵיהּ וּלמִפלַח קֳדָמוֹהִי בְּכָל לִבְּכוֹן וּבכָל נַפשְׁכוֹן :
<h3>פסוק ו</h3>
וּבָרֵיכִנוּן יְהוֹשֻׁעַ וְשַׁלַחִנוּן וַאֲזַלוּ לְקִרוֵיהוֹן :
<h3>פסוק ז</h3>
וּלפַלגוּת שִׁבטָא דִמנַשֶׁה יְהַב מֹשֶׁה בְּמַתנַן וּלפַלגְהוֹן יְהַב יְהוֹשֻׁעַ עִם אֲחֵיהוֹן בְּעִברָא דְיַרדְּנָא לְמַערְבָא וְאַף אֲרֵי שַׁלַחִנוּן יְהוֹשֻׁעַ לְקִרוֵיהוֹן וּבָרֵיכִנוּן :
<h3>פסוק ח</h3>
וַאֲמַר לְהוֹן לְמֵימַר בְּנִכסִין סַגִּיאִין תּוּבוּ לְקִרוֵיכוֹן וּבִבעִירָא סַגִּי לַחדָּא בְּכַספָּא וּבדַהבָּא וּבִנחָשָׁא וּבבַרזְלָא וּבִלבוּשִׁין סַגִּי לַחדָּא פַּלִיגוּ בִזַת בַּעֲלֵי דְבָבֵיכוֹן עִם אֲחֵיכוֹן :
<h3>פסוק ט</h3>
וְתָבוּ וַאֲזַלוּ בְּנֵי רְאוּבֵן וּבנֵי גָד וּפַלגוּת שִׁבטָא דִמנַשֶׁה מִלְוָת בְּנֵי יִשׂרָאֵל מִשִׁילוֹ דִּבאַרעָא דִכנָעַן לְמֵיזַל לַאֲרַע גִּלעָד לַאֲרַע אַחסָנַתהוֹן דְּאַחסִינוּ בַהּ עַל מֵימְרָא דַיְיָ בִּידָא דְמֹשֶׁה :
<h3>פסוק י</h3>
וַאֲתוֹ לִגלִילֵי יַרדְּנָא דִּבאַרעָא דִכנָעַן וּבנוֹ בְנֵי רְאוּבֵן וּבנֵי גָד וּפַלגוּת שִׁבטָא דִמנַשֶׁה תַמָן מַדבְּחָא עַל יַרדְּנָא מַדבַּח רַב לְמִחזֵי :
<h3>פסוק יא</h3>
וּשׁמַעוּ בְנֵי יִשׂרָאֵל לְמֵימַר הָא בְנוֹ בְנֵי רְאוּבֵן וּבנֵי גָד וּפַלגוּת שִׁבטָא דִמנַשֶׁה יָת מַדבְּחָא לָקֳבֵיל אַרעָא דִכנַעַן בִּגלִילֵי יַרדְּנָא דִּלעֵיבַר בְּנֵי יִשׂרָאֵל :
<h3>פסוק יב</h3>
וּשׁמַעוּ בְּנֵי יִשׂרָאֵל וְאִתכְּנִישׁוּ כָּל כְּנִשׁתָּא דִבנֵי יִשׂרָאֵל לְשִׁילוֹ לְמִסַק עֲלֵיהוֹן לְחֵילָא :
<h3>פסוק יג</h3>
וּשׁלַחוּ בְנֵי יִשׂרָאֵל לְוָת בְּנֵי רְאוּבֵן וּלוָת בְּנֵי גָד וּלוָת פַּלגוּת שִׁבטָא דִמנַשֶׁה לַאֲרַע גִּלעָד יָת פִּינְחָס בַּר אֶלעָזָר כָּהֲנָא :
<h3>פסוק יד</h3>
וְעַסרָא רַברְבִין עִמֵיהּ רַבָּא חַד רַבָּא חַד לְבֵית אַבָּא לְכֹל שִׁבטַיָא דְיִשׂרָאֵל וּגבַר רֵישׁ בֵּית אֲבָהָתְהוֹן אִנוּן לְאַלפַיָא דְיִשׂרָאֵל :
<h3>פסוק טו</h3>
וַאֲתוֹ לְוָת בְּנֵי רְאוּבֵן וּלוָת בְּנֵי גָד וּלוָת פַּלגוּת שִׁבטָא דִמנַשֶׁה לַאֲרַע גִּלעָד וּמַלִילוּ עִמְהוֹן לְמֵימַר :
<h3>פסוק טז</h3>
כְּדֵין אֲמַרוּ כָּל כְּנִשׁתָּא דַיְיָ מָא שִׁקרָא הָדֵין דְּשַׁקַרתּוּן בְּמֵימַר אֱלָהָא דְיִשׂרָאֵל לִמתָב יוֹמָא דֵין מִבָּתַר פֻּלחָנָא דַיְיָ בְּמִבנֵיכוֹן לְכוֹן מַדבְּחָא לְמִמרַדכוֹן יוֹמָא דֵין בְּמֵימְרָא דַיְיָ :
<h3>פסוק יז</h3>
הַזְעֵיר לַנָא חוֹבָא דִפעוֹר דְּלָא אִדַּכִּינָא מִנֵיהּ עַד יוֹמָא הָדֵין וַהֲוָת מַחתָּא בִּכנִשׁתָּא דַיְיָ :
<h3>פסוק יח</h3>
וְאַתּוּן תְּתוּבוּן יוֹמָא דֵין מִבָּתַר פֻּלחָנָא דַיְיָ וִיהֵי אַתּוּן תִּמרְדוּן יוֹמָא דֵין בְּמֵימְרָא דַיְיָ וּמחַר עַל כָּל כְּנִשׁתָּא דְיִשׂרָאֵל יְהֵי רֻגזָא :
<h3>פסוק יט</h3>
וּברַם אִם מְסָאֲבָא אֲרַע אַחסָנַתכוֹן עֲבַרוּ לְכוֹן לַאֲרַע אַחסָנַת עַמָא דַיְיָ דִּשׁרָא תַמָן מַשׁכְּנָא דַיְיָ וְאַחסִינוּ בֵּינַנָא וּבמֵימְרָא דַיְיָ לָא תִמרְדוּן וּבַנָא לָא תִמרְדוּן בְּמִבנֵיכוֹן לְכוֹן מַדבְּחָא בָּר מִמַדבְּחָא דַּיְיָ אֱלָהַנָא :
<h3>פסוק כ</h3>
הֲלָא עָכָן בַּר זֶרַח שַׁקַר שְׁקַר בְּחֶרמָא וְעַל כָּל כְּנִשׁתָּא דְיִשׂרָאֵל הֲוָה רֻגזָא וְהוּא גֻּברָא חַד לָא מִית בְּחוֹבֵיהּ :
<h3>פסוק כא</h3>
וַאֲתִיבוּ בְּנֵי רְאוּבֵן וּבנֵי גָד וּפַלגוּת שִׁבטָא דִמנַשֶׁה וּמַלִילוּ עִם רֵישֵׁי אַלפַיָא דְיִשׂרָאֵל :
<h3>פסוק כב</h3>
אֵל אֱלֹהִים יְיָ אֵל אֱלֹהִים יְיָ קֳדָמוֹהִי גְלֵי וְיִשׂרָאֵל בְּסוֹפָא יֵידַע אִם בְּמִמרָד וְאִם בְּשַׁקָרָא שְׁקַר בְּמֵימְרָא דַיְיָ לָא תִפרְקִנַנָא יוֹמָא הָדֵין :
<h3>פסוק כג</h3>
לְמִבנֵי לַנָא מַדבְּחָא לִמתָב מִבָּתַר פֻּלחָנָא דַיְיָ וְאִם לְאַסָקָא עֲלוֹהִי עֲלָתָא וּמִנחָתָא וְאִם לְמֶעֱבַד עֲלוֹהִי נִכסַת קֻדשִׁין יְיָ הוּא יִתבַּע :
<h3>פסוק כד</h3>
וְאִם לָא מִיִצפָּא מִפִּתגָם עֲבַדנָא יָת דָּא לְמֵימַר מְחַר יֵימְרוּן בְּנֵיכוֹן לִבנַנָא לְמֵימַר לֵית לְכוֹן חוּלָק בְּמֵימְרָא דַיְיָ אֱלָהָא דְיִשׂרָאֵל :
<h3>פסוק כה</h3>
וּתחוּמָא יְהַב יְיָ בֵּינַנָא וּבֵינֵיכוֹן בְּנֵי רְאוּבֵן וּבנֵי גָד יָת יַרדְּנָא לֵית לְכוֹן חוּלָק בְּמֵימְרָא דַיְיָ וִיבַטְלוּן בְּנֵיכוֹן יָת בְּנַנָא בְּדִיל דְּלָא לְמִדחַל מִן קֳדָם יְיָ :
<h3>פסוק כו</h3>
וַאֲמַרנָא נַעֲבֵיד כְּעַן לַנָא לְמִבנֵי יָת מַדבְּחָא לָא לַעֲלָתָא וְלָא לְנִכסַת קֻדשַׁיָא :
<h3>פסוק כז</h3>
אֲרֵי סָהִיד הוּא בֵּינַנָא וּבֵינֵיכוֹן וּבֵין דָּרַנָא בָּתְרַנָא לְמִפלַח יָת פֻּלחָנָא דַיְיָ קֳדָמוֹהִי בַּעֲלָוָתַנָא וּבדִבחַנָא וּבנִכסַת קֻדשַׁנָא וְלָא יֵימְרוּן בְּנֵיכוֹן מְחַר לִבנַנָא לֵית לְכוֹן חוּלָק בְּמֵימְרָא דַיְיָ :
<h3>פסוק כח</h3>
וַאֲמַרנָא וִיהֵי אֲרֵי יֵימְרוּן לַנָא וּלדָרַנָא מְחַר וְנֵימַר חֲזוֹ יָת דְּמוּת מַדבְּחָא דַיְיָ דַּעֲבַדוּ אֲבָהָתַנָא לָא לַעֲלָתָא וְלָא לְנִכסַת קֻדשַׁיָא אֲרֵי סָהִיד הוּא בֵּינַנָא וּבֵינֵיכוֹן :
<h3>פסוק כט</h3>
חָס לַנָא מִלְמִחטֵי קֳדָמוֹהִי לְמִמרַד בְּמֵימְרָא דַיְיָ וְלִמתָּב יוֹמָא דֵין מִבָּתַר פֻּלחָנָא דַיְיָ לְמִבנֵי מַדבְּחָא לַעֲלָתָא לְמִנחָתָא וּלנִכסַת קֻדשַׁיָא בָּר מִמַדבְּחָא דַּיְיָ אֱלָהַנָא דִּקדָם מַשׁכְּנֵיהּ :
<h3>פסוק ל</h3>
וּשׁמַע פִּינְחָס כָּהֲנָא וְרַברְבֵי כְנִשׁתָּא וְרֵישֵׁי אַלפַיָא דְיִשׂרָאֵל דְּעִמֵיהּ יָת פִּתגָמַיָא דְּמַלִילוּ בְּנֵי רְאוּבֵן וּבנֵי גָד וּבנֵי מְנַשֶׁה וּשׁפַר בְּעֵינֵיהוֹן :
<h3>פסוק לא</h3>
וַאֲמַר פִּינְחָס בַּר אֶלעָזָר כָּהֲנָא לִבנֵי רְאוּבֵן וְלִבנֵי גָד וְלִבנֵי מְנַשֶׁה יוֹמָא דֵין יָדַענָא אֲרֵי בֵינַנָא שָׁריָא שְׁכִינְתָא דַיְיָ דְּלָא שַׁקַרתּוּן בְּמֵימְרָא דַיְיָ שִׁקרָא הָדֵין בְּכֵין שֵׁיזֵיבתּוּן יָת בְּנֵי יִשׂרָאֵל מִיַד מֵימְרָא דַיְיָ :
<h3>פסוק לב</h3>
וְתָב פִּינְחָס בַּר אֶלעָזָר כָּהֲנָא וְרַברְבַיָא מִלְוָת בְּנֵי רְאוּבֵן וּמִלְוָת בְּנֵי גָד מֵאֲרַע גִּלעָד לְאַרעָא דִכנַעַן לְוָת בְּנֵי יִשׂרָאֵל וַאֲתִיבוּ יָתְהוֹן פִּתגָמָא :
<h3>פסוק לג</h3>
וּשׁפַר פִּתגָמָא בְּעֵינֵי בְּנֵי יִשׂרָאֵל וְאוֹדִיאוּ קֳדָם יְיָ בְּנֵי יִשׂרָאֵל וְלָא אֲמַרוּ לְמִסַק עֲלֵיהוֹן לְחֵילָא לְחַבָּלָא יָת אַרעָא דִּבנֵי רְאוּבֵן וּבנֵי גָד יָתְבִין בַּהּ :
<h3>פסוק לד</h3>
וּקרוֹ בְּנֵי רְאוּבֵן וּבנֵי גָד לְמַדבְּחָא אֲרֵי סָהִיד הוּא בֵּינַנָא אֲרֵי יְיָ הוּא אֱלֹהִים :
<h2>פרק כג</h2>
<h3>פסוק א</h3>
וַהֲוָה לִזמַן יוֹמִין סַגִּיאִין בָּתַר דַּאֲנִיחַ יְיָ לְיִשׂרָאֵל מִכָּל בַּעֲלֵי דְבָבֵיהוֹן מִסְחוֹר סְחוֹר וִיהוֹשֻׁעַ סִיב עָל בְּיוֹמִין :
<h3>פסוק ב</h3>
וּקרָא יְהוֹשֻׁעַ לְכָל יִשׂרָאֵל לְסָבוֹהִי וּלרֵישׁוֹהִי וּלדַיָנוֹהִי וּלסָרְכוֹהִי וַאֲמַר לְהוֹן אֲנָא סַבִית עַלִית בְּיוֹמַיָא :
<h3>פסוק ג</h3>
וְאַתּוּן חֲזֵיתוֹן יָת כָּל דַּעֲבַד יְיָ אֱלָהֲכוֹן לְכָל עַמְמַיָא הָאִלֵין מִן קֳדָמֵיכוֹן אֲרֵי יְיָ אֱלָהֲכוֹן מֵימְרֵיהּ מְגִיחַ לְכוֹן :
<h3>פסוק ד</h3>
חֲזוֹ דְפַלֵיגִית לְכוֹן יָת עַמְמַיָא דְּאִשׁתְּאַרוּ הָאִלֵין בְּאַחסָנָא לְשִׁבטֵיכוֹן מִן יַרדְּנָא וְכָל עַמְמַיָא דְּשֵׁיצִיתִי וְיַמָא רַבָּא מַעֲלָנֵי שִׁמשָׁא :
<h3>פסוק ה</h3>
וַיְיָ אֱלָהֲכוֹן הוּא יְתַבְּרִנוּן מִן קֳדָמֵיכוֹן וִיתָרֵיך יָתְהוֹן מִן קֳדָמֵיכוֹן וְתֵירְתוּן יָת אֲרַעהוֹן כְּמָא דְמַלֵיל יְיָ אֱלָהֲכוֹן לְכוֹן :
<h3>פסוק ו</h3>
וְתִתַּקְפוּן לַחדָּא לְמִטַר וּלמֶעֱבַד יָת כָּל דִּכתִיב בִּספַר אוֹרָיתָא דְמֹשֶׁה בְּדִיל דְּלָא לְמִסטֵי מִנֵיהּ לְיַמִינָא וְלִסמָאלָא :
<h3>פסוק ז</h3>
בְּדִיל דְּלָא לְאִתעָרָבָא בְּעַמְמַיָא הָאִלֵין דְּאִשׁתְּאַרוּ הָאִלֵין עִמְכוֹן וּבשׁוּם טַעֲוָתְהוֹן לָא תִדכְּרוּן וְלָא תְקַיְמוּן וְלָא תִפלְחוּנוּנוּן וְלָא תִסגְּדוּן לְהוֹן :
<h3>פסוק ח</h3>
אֱלָהֵין בְּדַחלְתָא דַיְיָ אֱלָהֲכוֹן תִּדבְּקוּן כְּמָא דַעֲבַדתּוּן עַד יוֹמָא הָדֵין :
<h3>פסוק ט</h3>
וְתָרֵיך יְיָ מִן קֳדָמֵיכוֹן עַמְמִין רַברְבִין וְתַקִיפִין וְאַתּוּן לָא קָם אֱנָשׁ קֳדָמֵיכוֹן עַד יוֹמָא הָדֵין :
<h3>פסוק י</h3>
גֻּברָא חַד מִנְכוֹן יִרדּוֹף אַלפָא אֲרֵי יְיָ אֱלָהֲכוֹן מֵימְרֵיהּ מְגִיחַ לְכוֹן כְּמָא דְמַלֵיל לְכוֹן :
<h3>פסוק יא</h3>
וְתִסתַּמרוּן לַחדָּא לְנַפשָׁתְכוֹן לְמִרחַם יָת יְיָ אֱלָהֲכוֹן :
<h3>פסוק יב</h3>
אֲרֵי אִם מְתָב תְּתוּבוּן וְתִדבְּקוּן בִּשׁאָר עַמְמַיָא הָאִלֵין דְּאִשׁתְּאַרוּ הָאִלֵין עִמְכוֹן וְתִתחַתְּנוּן בְּהוֹן וְתִתעָרְבוּן בְּהוֹן וְאִנוּן יִתעָרְבוּן בְּכוֹן :
<h3>פסוק יג</h3>
מִדָּע תִּדְּעוּן אֲרֵי לָא יוֹסֵיף מֵימְרָא דַיְיָ אֱלָהֲכוֹן לְתָרָכָא יָת עַמְמַיָא הָאִלֵין מִן קֳדָמֵיכוֹן וִיהוֹן לְכוֹן לִתבָר וּלתַקלָא וּלסִיעָן נָטְלָן זֵין לְקִבלְכוֹן וּלמַשׁרְיָן מַקְפָנֵיכוֹן עַד דְּתֵיבְדוּן מֵעַל אַרעָא טָבְתָא הָדָא דִּיהַב לְכוֹן יְיָ אֱלָהֲכוֹן :
<h3>פסוק יד</h3>
וְהָא אֲנָא אָזֵיל יוֹמָא דֵין בְּאוֹרַח כָּל אַרעָא וְתִדְּעוּן בְּכָל לִבְּכוֹן וּבכָל נַפשְׁכוֹן אֲרֵי לָא בְטֵיל פִּתגָמָא חַד מִכֹּל פִּתגָמַיָא תָקְנַיָא דְּמַלֵיל יְיָ אֱלָהֲכוֹן עֲלֵיכוֹן כֻּלְהוֹן אִתקַיַמוּ לְכוֹן לָא בְטֵיל מִנְהוֹן פִּתגָמָא חַד :
<h3>פסוק טו</h3>
וִיהֵי כְּמָא דְאִתקַיַמוּ עֲלֵיכוֹן כָּל פִּתגָמַיָא תָקְנַיָא דְּמַלֵיל יְיָ אֱלָהֲכוֹן עֲלֵיכוֹן כֵּן יֵיתֵי יְיָ עֲלֵיכוֹן יָת כָּל פִּתגָמַיָא בִישַׁיָא עַד דִּישֵׁיצֵי יָתְכוֹן מֵעַל אַרעָא טָבְתָא הָדָא דִּיהַב לְכוֹן יְיָ אֱלָהֲכוֹן :
<h3>פסוק טז</h3>
בְּמִעבַּרכוֹן עַל קְיָמָא דַיְיָ אֱלָהֲכוֹן דְּפַקֵיד יָתְכוֹן וּתהָכוּן וְתִפלְחוּן לְטָעֲוָת עַמְמַיָא וְתִסגְּדוּן לְהוֹן וְיִתקַף רֻגזָא דַיְיָ בְּכוֹן וְתֵיבְדוּן בִּפרִיעַ מֵעַל אַרעָא טָבְתָא דִּיהַב לְכוֹן :
<h2>פרק כד</h2>
<h3>פסוק א</h3>
וּכנַשׁ יְהוֹשֻׁעַ יָת כָּל שִׁבטַיָא דְיִשׂרָאֵל לִשׁכֶם וּקרָא לְסָבֵי יִשׂרָאֵל וּלרֵישׁוֹהִי וּלדַיָנוֹהִי וּלסָרְכוֹהִי וְאִתעַתַּדוּ קֳדָם יְיָ :
<h3>פסוק ב</h3>
וַאֲמַר יְהוֹשֻׁעַ לְכָל עַמָא כִּדנָן אֲמַר יְיָ אֱלָהָא דְיִשׂרָאֵל בְּעֵיבַר פְּרָת יְתִיבוּ אֲבָהָתְכוֹן מֵעָלְמָא תֶּרַח אֲבוּהִי דְאַברָהָם וַאֲבוּהִי דְנָחוֹר וּפלַחוּ לְטָעֲוָת עַמְמַיָא :
<h3>פסוק ג</h3>
וּדבַרִית יָת אֲבוּכוֹן יָת אַברָהָם מֵעֵיבַר פְּרָת וְדַבַּרִית יָתֵיהּ בְּכָל אַרעָא דִכנָעַן וְאַסגִּיתִי יָת בְּנוֹהִי וִיהַבִית לֵיהּ יָת יִצחָק :
<h3>פסוק ד</h3>
וִיהַבִית לְיִצחָק יָת יַעֲקֹב וְיָת עֵשָׁו וִיהַבִית לְעֵשָׁו יָת טוּרָא דְשֵׁעִיר לְמֵירַת יָתֵיהּ וְיַעֲקֹב וּבנוֹהִי נְחַתוּ לְמִצרָיִם :
<h3>פסוק ה</h3>
וּשׁלַחִית יָת מֹשֶׁה וְיָת אַהֲרֹן וּמחֵית יָת מִצרָאֵי כְּמָא דַעֲבַדִית בֵּינֵיהוֹן וּבָתַר כֵּן אַפֵּיקִית יָתְכוֹן :
<h3>פסוק ו</h3>
וְאַפֵּיקִית יָת אֲבָהָתְכוֹן מִמִצרַיִם וַאֲתֵיתוֹן לְיַמָא וּרדַפוּ מִצרָאֵי בָּתַר אֲבָהָתְכוֹן בִּרתִכִּין וּבפָרָשִׁין לְיַמָא דְסוּף :
<h3>פסוק ז</h3>
וּצעִיקוּ קֳדָם יְיָ וְשַׁוִי קַבלָא בֵּינֵיכוֹן וּבֵין מִצרָאֵי וְאַיתִי עֲלֵיהוֹן יָת יַמָא וַחֲפָנוּן וַחֲזַאָה עֵינֵיכוֹן יָת דַּעֲבַדִית בְּמִצרָיִם וִיתֵבתּוּן בְּמַדבְּרָא יוֹמִין סַגִּיאִין :
<h3>פסוק ח</h3>
וַאֲעֵילִית יָתְכוֹן לַאֲרַע אֱמוֹרָאָה דְּיָתֵיב בְּעִברָא דְיַרדְּנָא וַאֲגִיחוּ קְרָבָא עִמְכוֹן וּמסַרִית יָתְהוֹן בְּיַדכוֹן וִירֵיתתּוּן יָת אֲרַעהוֹן וְשֵׁיצֵיתִנוּן מִן קֳדָמֵיכוֹן :
<h3>פסוק ט</h3>
וְקָם בָּלָק בַּר צִפּוֹר מַלכָּא דְמוֹאָב וַאֲגִיחַ קְרָבָא בְּיִשׂרָאֵל וּשׁלַח וּקרָא לְבִלעָם בַּר בְּעוֹר לִמלָט יָתְכוֹן :
<h3>פסוק י</h3>
וְלָא אֲבֵיתִי לְקַבָּלָא מִן בִּלעָם וּבָרֵיך בָּרָכָא יָתְכוֹן וְשֵׁיזֵיבִית יָתְכוֹן מִן יְדֵיהּ :
<h3>פסוק יא</h3>
וַעֲבַרתּוּן יָת יַרדְּנָא וַאֲתֵיתוֹן לִירִיחוֹ וַאֲגִיחוּ קְרָבָא בְכוֹן יָתְבֵי יְרִיחוֹ אֱמוֹרָאֵי וּפרִזָאֵי וּכנַעֲנָאֵי וְחִתָּאֵי וְגַרגִּישָׁאֵי חִוָאֵי וִיבוּסָאֵי וּמסַרִית יָתְהוֹן בְּיַדכוֹן :
<h3>פסוק יב</h3>
וּשׁלַחִית קֳדָמֵיכוֹן יָת עָרָעִיתָא וְתָרֵיכִית יָתְהוֹן מִן קֳדָמֵיכוֹן תְּרֵין מַלכֵי אֱמוֹרָאָה לָא בְחַרבָּך וְלָא בְקַשׁתָּך :
<h3>פסוק יג</h3>
וִיהַבִית לְכוֹן אַרעָא דְּלָא עֲמַלתּוּן בַּהּ וְקִרוִין דְּלָא בְנֵיתוֹן וִיתֵיבתּוּן בְּהוֹן כַּרמִין וְזֵיתִין דְּלָא נְצַבתּוּן אַתּוּן אָכְלִין :
<h3>פסוק יד</h3>
וּכעַן דְּחִילוּ מִן קֳדָם יְיָ וּפלַחוּ קֳדָמוֹהִי בְּשַׁלמוּתָא וּבקֻשׁטָא וְאַעדּוֹ יָת טָעֲוָתָא דִּפלַחוּ אֲבָהָתְכוֹן בְּעֵיבַר פְּרָת וּבמִצרַיִם וּפלַחוּ קֳדָם יְיָ :
<h3>פסוק טו</h3>
וְאִם בִּישׁ בְּעֵינֵיכוֹן לְמִפלַח קֳדָם יְיָ בְּחַרוּ לְכוֹן יוֹמָא דֵין קֳדָם מַן תִּפלְחוּן אִם יָת טָעֲוָתָא דִּפלַחוּ אֲבָהָתְכוֹן דְּמֵעֵיבַר פְּרָת וְאִם יָת טָעֲוָת אֱמוֹרָאֵי דְּאַתּוּן יָתְבִין בַּאֲרַעהוֹן בְּרַם אֲנָא וֶאֱנָשׁ בֵּיתִי נִפלַח קֳדָם יְיָ :
<h3>פסוק טז</h3>
וַאֲתֵיב עַמָא וַאֲמַר חָס לַנָא מִלְמִשׁבַּק יָת פֻּלחָנָא דַיְיָ לְמִפלַח לְטָעֲוָת עַמְמַיָא :
<h3>פסוק יז</h3>
אֲרֵי יְיָ אֱלָהַנָא הוּא דְאַסֵיק יָתַנָא וְיָת אֲבָהָתַנָא מֵאַרעָא דְמִצרַיִם מִבֵּית עַבדוּתָא וְדַעֲבַד לְעֵינַנָא יָת אָתַיָא רַברְבָתָא הָאִלֵין וְנַטרַנָא בְּכָל אוֹרחָא דְּהַלֵיכנָא בַהּ וּבכֹל עַמְמַיָא דַּעֲבַרנָא בֵּינֵיהוֹן :
<h3>פסוק יח</h3>
וְתָרֵיך יְיָ יָת כָּל עַמְמַיָא וְיָת אֱמוֹרָאָה יָתֵיב אַרעָא מִן קֳדָמַנָא אַף אֲנַחנָא נִפלַח קֳדָם יְיָ אֲרֵי הוּא אֱלָהַנָא :
<h3>פסוק יט</h3>
וַאֲמַר יְהוֹשֻׁעַ לְעַמָא לָא תִיכְלוּן לְמִפלַח קֳדָם יְיָ אֲרֵי אֱלָהָא קַדִּישָׁא הוּא אֵל קַנוֹא הוּא מִן קֳדָם דִּין דִּקשׁוֹט לָא יִשׁבּוֹק לְחוֹבֵיכוֹן וְלִחטָאֵיכוֹן :
<h3>פסוק כ</h3>
אֲרֵי תִשׁבְּקוּן יָת פֻּלחָנָא דַיְיָ וְתִפלְחוּן לְטָעֲוָת עַמְמַיָא וִיתוּב וְיַבאֵישׁ לְכוֹן וִישֵׁיצֵי יָתְכוֹן בָּתַר דְּאוֹטֵיב לְכוֹן :
<h3>פסוק כא</h3>
וַאֲמַר עַמָא לִיהוֹשֻׁעַ לָא אֱלָהֵין קֳדָם יְיָ נִפלַח :
<h3>פסוק כב</h3>
וַאֲמַר יְהוֹשֻׁעַ לְעַמָא סָהֲדִין אַתּוּן בְּנַפשָׁתְכוֹן אֲרֵי אַתּוּן בְּחַרתּוּן לְכוֹן יָת פֻּלחָנָא דַיְיָ לְמִפלַח קֳדָמוֹהִי וַאֲמַרוּ סָהֲדִין :
<h3>פסוק כג</h3>
וּכעַן אַעדּוֹ יָת טָעֲוָת עַמְמַיָא דְּבֵינֵיכוֹן וְאַפנוֹ יָת לִבְּכוֹן לְפֻלחָנָא דַיְיָ אֱלָהָא דְיִשׂרָאֵל :
<h3>פסוק כד</h3>
וַאֲמַרוּ עַמָא לִיהוֹשֻׁעַ יָת יְיָ אֱלָהַנָא נִפלַח וּלמֵימְרֵיהּ נְקַבֵּיל :
<h3>פסוק כה</h3>
וּגזַר יְהוֹשֻׁעַ קְיָם לְעַמָא בְּיוֹמָא הַהוּא וְשַׁוִי לֵיהּ קְיָם וְדִין בִּשׁכֶם :
<h3>פסוק כו</h3>
וּכתַב יְהוֹשֻׁעַ יָת פִּתגָמַיָא הָאִלֵין וְאַצנַע בִּספַר אוֹרָיתָא דַיְיָ וּנסֵיב אַבנָא רַבְּתָא וַאֲקִימַהּ תַּמָן תְּחוֹת אַלְתָא דִּבבֵית מַקדְּשָׁא דַיְיָ :
<h3>פסוק כז</h3>
וַאֲמַר יְהוֹשֻׁעַ לְכָל עַמָא הָא אַבנָא הָדָא תְּהֵי לַנָא כִתרֵין לוּחֵי אֶבֶן קְיָמָא אֲרֵי יָתַהּ עֲבַדנָא לְסָהֲדוּ אֲרֵי פִתגָמַיָא דִכתִיבִין עֲלַהּ מֵעֵין כָּל פִּתגָמַיָא דַיְיָ דְּמַלֵיל עִמַנָא וּתהֵי בְכוֹן לְדֻכרָן לְסָהֲדוּ דִּלמָא תְכַדְּבוּן קֳדָם אֱלָהֲכוֹן :
<h3>פסוק כח</h3>
וְשַׁלַח יְהוֹשֻׁעַ יָת עַמָא גְּבַר לְאַחסָנְתֵיהּ :
<h3>פסוק כט</h3>
וַהֲוָה בָּתַר פִּתגָמַיָא הָאִלֵין וּמִית יְהוֹשֻׁעַ בַּר נוּן עַבדָּא דַיְיָ בַּר מְאָה וַעֲסַר שְׁנִין :
<h3>פסוק ל</h3>
וּקבַרוּ יָתֵיהּ בִּתחוּם אַחסָנְתֵיהּ בְּתִמנַת סֶרַח דִּבטוּרָא דְבֵית אֶפרָיִם מִצִפּוּנָא לְטוּר גָּעַשׁ :
<h3>פסוק לא</h3>
וּפלַח יִשׂרָאֵל קֳדָם יְיָ כֹּל יוֹמֵי יְהוֹשֻׁעַ וְכֹל יוֹמֵי סָבַיָא דְּאוֹרִיכוּ יוֹמִין בָּתַר יְהוֹשֻׁעַ וְדִידַעוּ יָת כָּל עוּבָדָא דַיְיָ דַּעֲבַד לְיִשׂרָאֵל :
<h3>פסוק לב</h3>
וְיָת גַּרמֵי יוֹסֵף דְּאַסִיקוּ בְנֵי יִשׂרָאֵל מִמִצרַיִם קְבַרוּ בִשׁכֶם בְּאַחסָנַת חַקלָא דִּזבַן יַעֲקֹב מִן בְּנֵי חֲמוֹר אֲבוּהִי דִשׁכֶם בִּמאָה חֻרפָּן וַהֲווֹ לִבנֵי יוֹסֵף לְאַחסָנָא :
<h3>פסוק לג</h3>
וְאֶלעָזָר בַּר אַהֲרֹן מִית וּקבַרוּ יָתֵיהּ בְּגִבעֲתָא דְּפִנחָס בְּרֵיהּ דְּאִתיְהֵיבַת לֵיהּ בְּטוּרָא דְבֵית אֶפרָיִם :
