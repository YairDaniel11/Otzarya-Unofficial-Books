<h1>תרגום יונתן על צפניה</h1>
<h2>פרק א</h2>
<h3>פסוק א</h3>
פִּתגָם נְבוּאָה מִן קֳדָם יְיָ דַּהֲוָה עִם צְפַניָה בַּר כּוּשִׁי בַר גְּדַליָה בַּר אֲמַריָה בַּר חִזקִיָה בְּיוֹמֵי יֹאשִׁיָה בַר אָמוֹן מֶלֶך שִׁבטָא דְבֵית יְהוּדָה :
<h3>פסוק ב</h3>
שֵׁיצָאָה אַשֵׁיצֵי כוֹלָא מֵעַל אַפֵּי אַרעָא אֲמַר יְיָ :
<h3>פסוק ג</h3>
אֲסִיף אֱנָשָׁא וּבעִירָא אֲסִיף עוֹפָא דִשׁמַיָא וְנוּנֵי יַמָא עַל דִּסגִיאָה תַּקלַת רַשִׁיעַיָא וַאֲשֵׁיצֵי יָת אֱנָשָׁא מֵעַל אַפֵּי אַרעָא אֲמַר יְיָ :
<h3>פסוק ד</h3>
וַאֲרֵים גְּבוּרְתִי עַל אֱנָשׁ יְהוּדָה וְעַל כָּל יָתְבֵי יְרוּשׁלֶם וַאֲשֵׁיצֵי מִן אַתרָא הָדֵין יָת שְׁאָר בַּעלָא יָת שׁוּם פָּלְחֵיהוֹן עִם כּוּמרֵיהוֹן :
<h3>פסוק ה</h3>
וְיָת דְּסָגְדִין עַל אִיגָּרַיָא לְחֵילֵי שְׁמַיָא וְיָת דְּסָגְדִין דִּמקַיְימִין בִּשׁמָא דַייָ תָּיְבִין וְיָמַן בְּשׁוּם פְּתַכרֵיהוֹן :
<h3>פסוק ו</h3>
וְיָת דְּאִסתְּחַרוּ לְאַחרָא מִבָּתַר פֻּלחָנָא דַייָ וּדלָא תְבַעוּ יָת דַּחלְתָא דַייָ וּדלָא בְעוֹ מִן קֳדָמוֹהִי :
<h3>פסוק ז</h3>
סָפוּ כָל רַשִׁיעַיָא מִן קֳדָם יְיָ אֱלֹהִים אֲרֵי קָרִיב יוֹמָא דַעֲתִיד לְמֵיתֵי מִן קֳדָם יְיָ אֲרֵי אַתקֵין יְיָ קְטוֹל עָרַע מְזָמְנוֹהִי :
<h3>פסוק ח</h3>
וִיהֵי בְּיוֹם קַטלָא דַעֲתִיד לְמֵיתֵי מִן קֳדָם יְיָ וְאַסעַר עַל רַברְבַיָא וְעַל בְּנֵי מַלכָּא וְעַל כָּל דְּמִתרָגְשִׁין לְמִפלַח לְטָעֲוָתָא :
<h3>פסוק ט</h3>
וְאַסעַר עַל כָּל דִּמהַלְכִין בְּנִמוֹסֵי פְלִשׁתָּאֵי בְּעִדָּנָא הַהוּא דִּמלַן בֵּית רִבּוֹנְהוֹן חֲטוֹף וְנִכלִין :
<h3>פסוק י</h3>
וִיהֵי בְעִדָּנָא הַהוּא אֲמַר יְיָ קָל צְוַחתָּא מִתְּרַע נוּנַיָא וִילָלָא מִן עוּפלָא וּתבָרָא רַבָּא מִן גַּבשׁוּתָא :
<h3>פסוק יא</h3>
אֵילִילוּ דְּיָתְבִין בְּנַחלָא דְקִדרוֹן אֲרֵי אִתְּבַר כָּל עַמָא דְּדָמַן עוּבָדֵיהוֹן לְעוּבָדֵי עַמָא דְאַרעָא דִכנַעַן אִשׁתֵּיצִיאוּ כָּל עַתִּירֵי נִכסַיָא :
<h3>פסוק יב</h3>
וִיהֵי בְּעִדָּנָא הַהוּא אֲפַקֵיד בָּלוֹשִׁין וְיִבלְשׁוּן יָת יָתְבֵי יְרוּשׁלֶם כְּמָא דְבָלְשִׁין בְּנִברַשׁתָּא וְאַסעַר עַל גֻּברַיָא דְּשָׁלַן שְׁלֵיוָא עַל נִכסֵיהוֹן דְּאָמְרִין בְּלִבְּהוֹן לָא רַעֲוָא קֳדָם יְיָ לְאֵיטָבָא וְאַף לָא לְאַבאָשָׁא :
<h3>פסוק יג</h3>
וִיהוֹן נִכסֵיהוֹן לַעֲדַי וּבִירָניָתְהוֹן לְבִזָא וְיִבנוֹן בָּתִּין וְלָא יִתְּבוּן וְיִצְבוּן כַּרמִין וְלָא יִשׁתּוֹן יָת חַמרְהוֹן :
<h3>פסוק יד</h3>
קָרִיב יוֹמָא דַעֲתִיד לְמֵיתֵי מִן קֳדָם יְיָ רַבָּא קָרִיב וּמוֹחֵי לַחדָּא קָל יוֹמָא דַעֲתִיד לְמֵיתֵי מִן קֳדָם יְיָ דְּבֵיהּ מְרָר וּצוַח גִּיבָּרַיָא מִתקַטלִין :
<h3>פסוק טו</h3>
יוֹם תַּעֲבוּר יוֹמָא הַהוּא יוֹם עָקָא וְעִיוּק יוֹם רִגּוּשׁ וְאִתרְגוֹשָׁא יוֹם חֲשׁוֹך וּקבַל יוֹם עֲנָנָא וַאֲמִטְתָא :
<h3>פסוק טז</h3>
יוֹם שׁוֹפָר וְיַבָּבָא עַל קִרוַיָא כְרִיכָתָא וְעַל רָמָתָא מְנֻטְלָתָא :
<h3>פסוק יז</h3>
וְאַעֵיק לִבנֵי אֱנָשָׁא וִיהָכוּן כִּסמַן אֲרֵי קֳדָם יְיָ חָבוּ וְיִשׁתְּפֵיך דַּמהוֹן כְּעַפרָא וּנבֵילַתהוֹן כִּסחוּתָא :
<h3>פסוק יח</h3>
אַף כַּספְּהוֹן אַף דַּהבְּהוֹן לָא יִכּוֹל לְשֵׁיזָבוּתְהוֹן בְּיוֹם רֻגזָא דַייָ וּבאִישָׁת פּוֹרעָנוּתֵיהּ יְסוּפוּן כָּל רַשִׁיעֵי אַרעָא אֲרֵי גְמֵירָא בְרַם שֵׁיצָאָה יַעֲבֵיד עִם כָּל יָתְבֵי אַרעָא :
<h2>פרק ב</h2>
<h3>פסוק א</h3>
אִתכַּנַשׁוּ וְאֵיתוֹ וְאִתקָרַבוּ עַם דָּרָא דְּלָא חַמֵיד לִמתָב לְאוֹרָיתָא :
<h3>פסוק ב</h3>
עַד לָא תִּפּוֹק עֲלֵיכוֹן גְּזֵירַת בֵּית דִּינָא וּתהוֹן דָּמַן לִכמוֹצָא דְנָסְבָא רוּחָא וּכטוּלָא דְעָדֵי מִן קֳדָם יוֹמָא עַד לָא יֵיתֵי עֲלֵיכוֹן תְּקוֹף רֻגזָא דַייָ עַד לָא יֵיתֵי עֲלֵיכוֹן יוֹם רֻגזָא דַייָ :
<h3>פסוק ג</h3>
תְּבַעוּ יָת דַּחלְתָא דַייָ כָּל עִנוְתָנֵי אַרעָא דְּדִינֵי רְעוּתֵיהּ עֲבַדוּ תְּבַעוּ קֻשׁטָא תְּבַעוּ עִנוְתָנוּתָא מָא אִם יִתַּגַּן עֲלֵיכוֹן בְּיוֹם רֻגזָא דַייָ :
<h3>פסוק ד</h3>
אֲרֵי עַזָה שְׁבִיקָא תְהֵי וְאַשׁקְלוֹן לְצָדוּ אַשׁדּוֹד בְּטֵיהֲרָא יְתָרְכוּנַהּ וְעֶקרוֹן תִּתעֲקַר :
<h3>פסוק ה</h3>
יֵי דְּיָתְבִין בִּספַר יַמָא עַמָא דְּחַיָיבִין לְאִשׁתֵּיצָאָה גְּזֵירַת פִּתגָמָא דַייָ עֲלֵיכוֹן דְּיָתְבִין בִּכנַעַן אֲרַע פְּלִשׁתָּאֵי וְאַבְּדִינְכוֹן מִבְּלִי יָתִיב :
<h3>פסוק ו</h3>
וִיהֵי סְפַר יַמָא דֵּירָוָת בֵּית מִשׁרֵי רָעַיִן וְחֻטרִין דְּעָן :
<h3>פסוק ז</h3>
וִיהֵי עַדבָּא לִשׁאָרָא דְּבֵית יְהוּדָה עֲלֵיהוֹן יִתפַּרנְסוּן בְּבָתֵּי אַשׁקְלוֹן בְּרַמשָׁא יְבִיתוּן אֲרֵי יֵיעוֹל דֻּכרָנְהוֹן לְטָבָא קֳדָם יְיָ אֱלָהֲהוֹן וְיָתִיב גָּלְוָתְהוֹן :
<h3>פסוק ח</h3>
שְׁמִיעַ קֳדָמַי חִסוּדֵי מוֹאָב וְאִתרַברָבוּת בְּנֵי עַמוֹן דְּחַסִידוּ יָת עַמִי וְאִתרָרַבוּ עַל תְּחוּמְהוֹן :
<h3>פסוק ט</h3>
בְּכֵין קַיָים אֲנָא אֲמַר יְיָ צְבָאוֹת אֱלָהָא דְיִשׂרָאֵל אֲרֵי מוֹאָב כִּסדוֹם תְּהֵי וּבנֵי עַמוֹן כַּעֲמוֹרָא מַשׁמַט מַלוּחִין מַחפּוֹריָן דִּמלַח וְצָדוּ עַד עָלְמָא שְׁאָרָא דְעַמִי יִבְּזוּנוּנוּן וּשׁאָר שִׁבטַיָא יַחסְנוּנוּנוּן :
<h3>פסוק י</h3>
דָּא לְהוֹן חֲלָף אִתרַברָבוּתְהוֹן אֲרֵי חַסִידוּ וְאִתרָרַבוּ עַל עַמֵיהּ דַּייָ צְבָאוֹת :
<h3>פסוק יא</h3>
דְּחִילָא יְיָ אֲמַר לְמִפרַקהוֹן אֲרֵי אַמאֵיך יָת כָּל דַּחלַת אַרעָא וְיִבעוֹן מִן קֳדָמוֹהִי גְּבַר מֵאַתרֵיהּ כָּל נְגָוָת עַמְמַיָא :
<h3>פסוק יב</h3>
אַף אַתּוּן כּוּשָׁאֵי קְטִילֵי חַרבִּי תְּהוֹן :
<h3>פסוק יג</h3>
וִירִים מַחַת גְּבוּרְתֵיהּ עַל צִפּוּנָא וִיאַבֵּיד יָת אַתּוּרָאָה וִישַׁוֵי יָת נִינְוֵה לְצָדוּ אִשׁתְּמָמוּ כְּמַדבְּרָא :
<h3>פסוק יד</h3>
וְיִשׁרוֹן בְּגַוַהּ עֶדרִין דְּכָל חֵיוַת בָּרָא אַף קָתִין אַף קוּפדִּין בְּפִתּוּח תַּרעַהּ יְבִיתוּן קָל עוֹפָא דִמנַצֵיף בְּכַוָה חֲרוּבוּ תַרעַהּ וּטלָתַהּ סְתַרוּ :
<h3>פסוק טו</h3>
דָּא קַרתָּא תַקִיפְתָא דְּיָתְבָא לְרֻחצָן דְּאָמְרָא בְּלִבַּהּ אֲנָא וְלֵית בָּר מִנִי עוֹד אֵיכְדֵין הֲוָת לְצָדוּ בֵּית מִשׁרֵי חַיתָא כָּל דְּיִעבַּר עֲלַהּ יַכלֵי יְנִיד יְדֵיהּ :
<h2>פרק ג</h2>
<h3>פסוק א</h3>
יֵי דְמוֹחֲיָא וּמִתפַּרקָא קַרתָּא דְּמַסגְּיָא לְאַרגָּזָא :
<h3>פסוק ב</h3>
לָא שְׁמַעַת בְּקָל עַבדוֹהִי נְבִיַיָא וְלָא קַבֵּילַת אֻלפָן בְּמֵימְרָא דַייָ לָא אִתרְחֵיצַת וּלפֻלחָנָא דֶאֱלָהַהּ לָא אִתקָרַבַת :
<h3>פסוק ג</h3>
רַברְבַהָא בְגַוַהּ כְּאַריָוָן נָהֲמִין דַּיָינַהָא דֵּיבֵי רַמשָׁא לָא מוֹרְכִין לְצַפרָא :
<h3>פסוק ד</h3>
נְבִיֵי שִׁקרָא דִבגַּוַהּ בָּאֲשִׁין גֻּברִין שַׁקָרִין כָּהֲנַהָא מַפְּסִין קֻדשָׁא חָטְפִין בְּאוֹרָיתָא :
<h3>פסוק ה</h3>
יְיָ זַכָּאָה אֲמַר לְאַשׁרָאָה שְׁכִינְתֵיהּ בְּגַוַהּ לֵית קֳדָמוֹהִי לְמֶעֱבַד שְׁקַר הָא כְנֵיהוֹר צַפרָא דְאָזֵיל וְתָקֵין כֵּין דִּינֵיהּ נָפֵיק לְאַפרָשׁ לָא מִתעַכַּב וְלָא יָדְעִין עַוָלַיָא בַּהתָּא :
<h3>פסוק ו</h3>
שֵׁיצִיתִי עַמְמַיָא אַצדִּיאָה בִּירָניָתְהוֹן אַחרֵיבִית שׁוּקֵיהוֹן מִבְּלִי עָדֵי צַדִּיאָה קִרוֵיהוֹן מִבְּלִי אֱנָשׁ מִבְּלִי יָתִיב :
<h3>פסוק ז</h3>
אֲמַרִית בְּרַם תִּדחֲלוּן מִן קֳדָמַי תְּקַבְּלוּן אֻלפָן לָא יִפסוּק מְדוֹרְהוֹן מֵאֲרַע בֵּית שְׁכִינְתִי כָּל טָבוָון דַּאֲמַרִית לְהוֹן אַיתִי לְהוֹן בְּכֵין אַקדִּימוּ חַבִּילוּ כָּל עוּבָדֵיהוֹן :
<h3>פסוק ח</h3>
בְּכֵין סַבַּרוּ לְמֵימְרִי אֲמַר יְיָ לְיוֹם אִתגְּלָיוּתִי לִמדָן אֲרֵי דִינִי לְכַנָשָׁא עַמְמַיָא לְקָרָבָא מַלכְוָתָא לְמִשׁפַּך עֲלֵיהוֹן חִמתִּי כָּל תְּקוֹף רֻגזִי אֲרֵי בְּאִישָׁת פּוּרעָנוּתִי יְסוּפוּן כָּל רַשִׁיעֵי אַרעָא :
<h3>פסוק ט</h3>
אֲרֵי בְכֵין אֶשׁנֵי עַל עַמְמַיָא מַמלַל חַד בְּחִיר לְצַלָאָה כֻלְהוֹן בִּשׁמָא דַייָ לְמִפלַח קֳדָמוֹהִי כְּתַף חַד :
<h3>פסוק י</h3>
מֵעֵבֶר לְנַהֲרֵי הוֹדּוּ בְּרַחֲמִין יְתוּבָן גָּלְוָת עַמִי דְאִתַּגלִיאָה וִיהוֹן מֵיתַן לְהוֹן הָא כְקֻרבָּנִין :
<h3>פסוק יא</h3>
בְּעִדָּנָא הַהוּא לָא תִבַּהתִּין מִכָּל עוּבָדַך בִּישַׁיָא דִּמרֵידתּ בְּמֵימְרִי אֲרֵי בְכֵין אֲגַלֵי מִגַּוִיך תַּקִיפֵי תֻּשׁבַּחתִּיך וְלָא תוֹסְפִין לְאִתרַברָבָא עוֹד בְּטוּרָא דְקֻדשִׁי :
<h3>פסוק יב</h3>
וְאַשׁאַר בְּגַוִיך עַם עִנוְתָן וּמקַבֵּיל עֻלבָּן וְיִתרַחצוּן בִּשׁמָא דַייָ :
<h3>פסוק יג</h3>
שְׁאָרָא דְיִשׂרָאֵל לָא יַעבְּדוּן שְׁקַר וְלָא יְמַלְלוּן כַּדבִּין וְלָא יִשׁתְּכַח בְּפוּמְהוֹן לִישָׁן דְּנִכלִין אֲרֵי אִנוּן יִתפַּרנְסוּן וְיִשׁרוֹן וְלֵית דְּמַנִיד :
<h3>פסוק יד</h3>
שַׁבַּחִי כְּנִשׁתָּא דְצִיוֹן יַבַּעוּ יִשׂרָאֵל חֲדַא וּבוּעִי בְּכָל לֵב כְּנִשׁתָּא דִירוּשׁלֶם :
<h3>פסוק טו</h3>
אַגלִי יְיָ דַּיָינֵי שִׁקרָא מִגַּוִיך פַּלִי בַּעֲלֵי דְבָבַך מַלכֵּיהּ דְּיִשׂרָאֵל יְיָ אֲמַר לְאַשׁרָאָה שְׁכִינְתֵיהּ בְּגַוִיך לָא תִדחֲלִין מִן קֳדָם בִּישָׁא עוֹד :
<h3>פסוק טז</h3>
בְּעִדָּנָא הַהוּא יִתאֲמַר לִירוּשׁלֶם לָא תִדחֲלִין צִיוֹן לָא יִתרַשְׁלָן יְדַך :
<h3>פסוק יז</h3>
יְיָ אֱלָהִיך אֲמַר לְאַשׁרָאָה שְׁכִינְתֵיהּ בְּגַוִיך גִּיבָּר פָּרִיק יִחדֵּי עֲלַך בְּחֶדוָא יִכבּוֹשׁ עַל חוֹבַך בְּרַחמְתֵיהּ יְדוּץ עֲלַך בִּדיָץ :
<h3>פסוק יח</h3>
דַּהֲווֹ מְעַכְּבִין בִּיך זִמנֵי מוֹעֲדַך אַרחֵיקִית מִנִיך וָי עֲלֵיהוֹן עַל דַּהֲווֹ נָטְלִין זֵינְהוֹן לְקִבלִיך וּמחַסְדִין לִיך :
<h3>פסוק יט</h3>
הָאֲנָא עָבֵיד גְּמֵירָא עִם כָּל מְשַׁעבְּדַך בְּעִדָּנָא הַהוּא וְאֶפרוֹק יָת מְטֻלטְלַיָא וּמבֻדְרַיָא אֲקָרֵיב וַאֲשַׁוֵינוּן לְתֻשׁבְּחָא וּלשׁוֹם בְּכָל אֲרַע בַּהתַּתהוֹן :
<h3>פסוק כ</h3>
בְּעִדָּנָא הַהוּא אֲכַנֵישׁ יָתְכוֹן וּבעִדָּנָא הַהוּא אֲכַנֵישׁ יָתְכוֹן אֲרֵי אֶתֵּין יָתְכוֹן לְשׁוֹם וּלתֻשׁבְּחָא בְּכֹל עַמְמֵי אַרעָא כַּד אֲקָרֵיב יָת גָּלְוָתְכוֹן לְעֵינֵיכוֹן אֲמַר יְיָ :
